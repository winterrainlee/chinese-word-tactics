# 1. 북쪽 숲 묶음의 한 줄 방향

> **처음에는 버섯 하나 찾는 것도 낯설었던 소년이, 여러 사람의 부탁을 맡으며 북쪽 숲과 물길마을 주변 생활권에 점차 익숙해진다.**

북쪽 숲은 끝마을로 이어지는 지리적 전초가 아니다.

- 북쪽 숲: 물길마을 가까이의 생활권
- 끝마을: 길목과 관문 바깥길을 따라가는 별도 축

따라서 F8의 결말도 “숲 너머에는 무엇이 있을까?”가 아니라:

> **“이제 이 주변은 제법 익숙하다.”**

여야 한다.

# 2. 진행 구조

북쪽 숲은 본편처럼 8판을 한 줄로 강제하지 않는다.

```text
F1 월백버섯
  ↓
의뢰 게시판 설치
  ↓
┌─ F2 가려진 표식 → F3 돌아간 표지판 ─┐
│                                        │
└─ F4 닮은 잎 → F5 장인이 찾는 재료 ───┤
                                         ↓
                     F6 사라진 꾸러미 → F7 흔적이 멈춘 곳
                                         ↓
                                  F8 오늘의 숲길
```

기본 방향:

- F2와 F4는 게시판 설치 뒤 함께 열 수 있다.
- F3은 F2 후속.
- F5는 F4 후속.
- F6은 적어도 F2~F3의 방향·확인 어휘를 경험한 뒤 연다.
- F8은 주요 세 의뢰 묶음을 경험한 뒤 열리는 종합 의뢰다.

정확한 해금 조건은 구현 전에 확정한다.

# 3. 단어 계층

북쪽 숲에서는 단어를 두 층으로 나눈다.

## 3.1 새 핵심어

이번 묶음에서 새로 학습하는 B1 중심 어휘.

스테이지 목표 바로 아래의 주요 단어로 표시하고, 단어장에서도 북쪽 숲의 새 학습어로 기록한다.

## 3.2 복습어

이미 초급 단계에서 접했을 가능성이 높은 색·크기·모양·방향 표현.

예:

- 색: `綠色 / 深綠色 / 淺綠色 / 藍色 / 褐色`
- 모양: `長 / 短 / 圓 / 尖`
- 크기·굵기: `大 / 小 / 粗 / 細`
- 방향: `左 / 右 / 前 / 後`

이들은 새 개념 설명의 주인공이 아니다.

대신 실제 판의 관찰 정보로 사용한다.

예:

> `特徵`을 배우는 판에서  
> `深綠色 / 長 / 尖`을 읽어야 목표 식물을 구별한다.

즉:

> **새 핵심어가 사고의 틀이고, 쉬운 복습어가 실제 판단 재료다.**

복습어를 단어장에 어떻게 표시할지는 구현 단계에서 `복습` 태그 또는 재등장 기록 방식으로 별도 결정한다.

# 5. F1 — 북쪽 숲의 버섯

현재 구현된 C08을 그대로 사용한다.

핵심 역할:

- 자유 의뢰 루프 소개
- 북쪽 숲 첫 진입
- 1장 단어 재사용
- 게시판 설치

목표:

`在指定範圍內找月白菇，確認數量足夠，再退出森林。`

이 판에는 새 핵심어를 추가하지 않는다.

# 6. F2 — 잎에 가려진 표식

새 핵심어:

- `標記` — 표식
- `方向` — 방향
- `確認` — 확인하다

복습·재사용:

- `左 / 右`
- `位置 / 路線 / 距離`

## 이야기

길목 길지기가 게시판에 작은 부탁을 남긴다.

북쪽 숲 바깥쪽에 세워 둔 작은 표식 몇 개가 나뭇잎에 가려졌다는 이야기다.

소년에게 요구하는 것은 수리나 판단 권한이 아니다.

> “가서 어느 방향을 가리키는지만 확인해 줘.”

소년은 이미 한 번 북쪽 숲에 다녀왔으므로 이 정도 심부름은 자연스럽다.

## 판

6×6 안팎.

- 시작 위치
- 숲길 세 갈래
- 방향 표식 3개
- 멀리 보이는 기준물: 개울, 마을 쪽 길, 채집 구역

표식 하나는 잎에 일부 가려져 있다.

## 플레이

1. 표식에 접근한다.
2. 가려진 부분을 치우거나 가까이에서 살펴본다.
3. 표식이 가리키는 `方向`을 확인한다.
4. 주변 길과 기준물을 보고 세 표식을 모두 `確認`한다.
5. 다른 두 표식과 맞지 않는 하나를 찾아 표시해 둔다.

표식을 보는 것만으로 자동 정답 처리하지 않는다.

플레이어가 실제로 여러 방향과 주변 정보를 비교해야 한다.

## 목표 문장 후보

`確認三個標記的方向，找出不一致的那一個。`

## 실패

하드 실패 없음.

잘못된 표식을 선택하면:

> `這個方向和附近的路線沒有矛盾。再看看其他標記。`

처럼 판 정보를 다시 읽게 한다.

# 7. F3 — 돌아간 표지판

새 핵심어:

- `正確` — 정확하다 / 올바르다
- `指示` — 가리키다 / 안내하다

재사용:

- `標記 / 方向 / 確認 / 路線`

보조 표현:

- `看清楚`
- `不對`

## 이야기

F2에서 이상한 표식을 확인하고 나면, 실제로 표지판 하나가 축에서 돌아가 있다는 것을 알게 된다.

길지기는 멀리서 정답을 알려주지 않는다.

정상 표식 같은 정답 힌트는 따로 주지 않는다.

대신 표지판 옆에서 장터 쪽으로 실제 이어지는 길의 형태를 보고 스스로 올바른 방향을 찾을 수 있다.

## 판

F2와 같은 장소를 일부 재사용하되, 정상 표식을 비교 기준으로 남겨 두지 않는다.

플레이어가 “전에 본 곳”이라는 감각을 받을 수 있게 한다.

문제 표식은 네 방향 중 하나로 돌릴 수 있다.

## 플레이

1. 표지판 주변에서 장터 방향으로 이어지는 실제 `路線`의 형태를 본다.
2. 문제 표식에 다가가면 별도 선행 확인 없이 `方向`을 돌릴 수 있다.
3. 틀린 방향에서는 표지판과 길이 어떻게 맞지 않는지만 확인한다.
4. 표식이 실제 장터 길을 `正確`하게 `指示`하면 완료한다.

## 목표 문장 후보

`把轉歪的標記調回正確方向，讓它指示回鎮上的路。`

## 학습 역할

F2가 “정보를 읽는다”면 F3은 “읽은 정보가 맞는지 판단하고 고친다.”

`確認`은 여기서 바로 첫 재등장한다.

# 8. F4 — 닮은 잎

새 핵심어:

- `特徵` — 특징
- `相似` — 비슷하다
- `不同` — 다르다
- `分辨` — 구별하다

`相似 / 不同`은 서로를 함께 써야 의미가 분명해지는 하나의 대비 묶음으로 제시한다. 따라서 이 판은 핵심어가 네 개지만 학습 단위는 `特徵 → 相似/不同 → 分辨`의 세 단계로 유지한다.

복습어:

- `深綠色 / 淺綠色`
- `長`
- `圓`
- `尖`

재사용:

- `條件 / 符合 / 確認`

## 이야기

장인골 장인이 숲에서 나는 식물 한 종류를 찾고 있다.

하지만 소년은 그 식물을 모른다.

장인은 말로 이름만 알려 주지 않고 작은 견본 잎 하나를 보여 준다.

> “비슷한 잎이 많아. 색 하나만 보고 고르면 안 돼.”

이 의뢰의 첫 판은 **구별한 식물을 실제로 하나 챙기는 데까지** 진행한다. 다만 아직 작업 재료의 적합성을 판단하지는 않는다.

## 견본

예:

```text
顏色　深綠色
形狀　長
葉尖　尖
```

## 후보 식물

예:

- A: 깊은 초록 + 긴 잎 + 끝이 뾰족함
- B: 깊은 초록 + 둥근 잎
- C: 연한 초록 + 긴 잎 + 끝이 뾰족함
- D: 깊은 초록 + 짧은 잎 + 끝이 뾰족함

A만 견본의 세 특징이 모두 같은 정답 군락이다. 나머지는 각각 한 특징만 `不同`하게 해 차이를 언어로 확인할 수 있게 한다.

## 플레이

각 군락을 살펴보면 한국어 정답이 아니라 중국어 특징이 표시된다.

예:

```text
深綠色
葉子很長
前端尖
```

플레이어는 여러 `特徵`을 비교해 `相似`한 식물 사이에서 무엇이 `不同`한지 확인하고 목표를 `分辨`한다.

정답 군락을 제대로 확인하면 `이 식물 챙기기` 행동이 열린다. 실제로 표본 하나를 챙겨야 완료한다.

## 목표 문장 후보

`比較特徵，分辨相似和不同的地方，帶回和樣本相同的植物。`

## 실패

잘못된 식물을 선택해도 즉시 실패시키지 않는다.

“색은 같지만 모양이 `不同`하다”처럼 **어느 특징이 달랐는지** 보여주고 다시 선택할 수 있게 한다.

# 9. F5 — 장인이 찾는 재료

새 핵심어:

- `材料` — 재료
- `適合` — 적합하다
- `生長` — 자라다 / 생장하다

복습어 후보:

- `長 / 短`
- `粗 / 細`
- 필요시 `深 / 淺`

재사용:

- `特徵 / 分辨 / 條件 / 符合 / 數量`

## 이야기

F4에서 식물을 구별한 뒤 장인은 한 단계 더 설명한다.

> “같은 종류처럼 보여도 전부 재료로 쓰는 건 아니야.”

이번에는 실제 작업에 쓸 덩굴이나 가지를 구한다.

정확한 식물 이름은 배경어로 두고, 전문 식물 암기가 되지 않게 한다.

## 조건 예시

장인이 필요한 것은:

- 충분히 `長`다.
- 너무 굵지 않고 `細`다.
- 물가 가까이 `生長`한 건강한 줄기다.

F5에서는 F4와 달리 정답 견본 그림을 보여주지 않는다. 목표 영역에는 다음과 같은 **텍스트 작업 지시만** 둔다.

```text
需要兩根
長 · 細 · 生長在水邊
```

후보 재료의 실제 형태와 생장 위치는 판에서 직접 확인한다. 설명을 읽고 조건을 적용해야 하므로 F4보다 한 단계 어렵다.

## 판

후보 군락 4개.

두 군락 정도는 조건에 맞고, 플레이어는 필요한 `數量`만큼 골라 갈 수 있다.

하나의 정답 위치만 두지 않는다.

## 플레이

1. 군락의 특징을 확인한다.
2. 어디에서 자라는지 확인한다.
3. 작업 `材料`로 `適合`한지 판단한다.
4. 필요한 만큼 가져간다.

## 목표 문장 후보

`找出符合條件、適合做材料的藤條。`

## 학습 역할

F4:

> 닮은 것을 구별한다.

F5:

> 구별한 뒤 실제 목적에 적합한지 판단한다.

으로 한 단계 올라간다.

`相似 / 不同`도 여기서 즉시 재사용한다. 예를 들어 길이는 같지만 굵기가 `不同`하거나, 모양은 비슷하지만 `生長` 위치가 다르다는 식으로 피드백한다.

---

# 10. F6 — 사라진 꾸러미

새 핵심어:

- `遺失` — 잃어버리다
- `尋找` — 찾다
- `痕跡` — 흔적

복습어:

- `藍色`
- 필요시 `長 / 短`

재사용:

- `方向 / 位置 / 周圍 / 確認`

## 이야기

장터의 기존 인물 또는 행상 아주머니가 북쪽 숲길을 지나던 수레에서 작은 꾸러미 하나가 빠진 것 같다고 한다.

위험한 귀중품이 아니라 생활 물건 정도로 유지한다.

꾸러미는 **파란 천끈**으로 묶여 있었다.

마지막으로 본 위치만 알고 정확한 분실 지점은 모른다.

## 판

7×6 안팎.

- 마지막 확인 지점
- 세 갈래 숲길
- 여러 흔적 후보
  - 파란 천실
  - 수레바퀴 자국
  - 동물 발자국
  - 그냥 떨어진 잎이나 가지

마지막 확인 지점은 파란 실 자체가 아니라 눌린 풀·흙 같은 중립 표식으로 보여 준다. 파란 실 후보와 같은 그림을 투명도만 바꿔 재사용하지 않는다.

## 플레이

1. `最後看到的位置`에서 시작한다.
2. 주변을 `尋找`한다.
3. 발자국·바퀴 자국·파란 실이 비교 후보로 열린 이유를 확인하고 여러 `痕跡`의 특징을 본다.
4. 꾸러미와 관계있는 흔적을 따라 방향을 좁힌다.
5. 흔적이 이어지는 다음 수색 구역에 도달한다.

F4의 `特徵 / 分辨`을 자연스럽게 다시 사용할 수 있다.

## 목표 문장 후보

`從最後看到的位置開始，尋找和遺失的包裹有關的痕跡。`

## 완료

F6에서는 아직 꾸러미 자체를 찾지 않는다. 따라서 일반적인 “의뢰 완료”나 “꾸러미를 찾았다”로 닫지 않는다.

올바른 흔적이 이어지는 다음 구역을 발견하면 `추적 지점 도달`로 표시하고, `흔적을 따라 계속 찾기`로 F7에 연결한다.

마무리 정보에도 “꾸러미는 아직 보이지 않는다”를 명시해, 목표가 분실물 회수가 아니라 **다음 수색 구역을 찾는 것**이었음을 확인한다.

# 11. F7 — 흔적이 멈춘 곳

새 핵심어:

- `發現` — 발견하다
- `附近` — 부근 / 근처
- `留下` — 남기다

재사용:

- `痕跡 / 尋找 / 方向 / 距離 / 特徵 / 分辨`

복습 정보:

- 파란 천 조각
- 큰 나무 / 둥근 돌 등 쉬운 모양·크기 표현

## 이야기

F6에서 따라온 흔적이 작은 빈터에서 끊긴다.

소년은 “흔적이 없어졌으니 틀린 길”이라고 바로 돌아가지 않는다.

마지막 `痕跡`의 `附近`를 살펴보기 시작한다.

채집인은 숲 바깥쪽 길에서 기다린다. 소년이 꾸러미를 발견한 뒤 그 길로 돌아가야 하는 이유는, 회수한 물건을 주인에게 건네 의뢰를 마치기 위해서다.

## 판

중심에 마지막 흔적.

주변 3칸 범위에 여러 조사 대상:

- 큰 나무
- 둥근 바위
- 낮은 덤불
- 작은 물길

마지막 흔적과 낮은 덤불은 열린 빈터 안에서 `附近`로 느껴질 만큼 가깝게 두되, 서로 세 칸 떨어뜨려 한 보행 칸에서 둘을 동시에 조사할 수 없게 한다. 두 대상 사이를 막는 단독 바위나 수풀은 두지 않는다.

## 플레이

1. 마지막 흔적이 무엇을 `留下`았는지 다시 확인한다.
2. 그 `附近`의 대상들을 조사한다. 바위와 물길 비교는 선택 사항이며 정답 진행의 필수 체크리스트로 만들지 않는다.
3. 마지막 흔적을 확인했다면 덤불 가지에 새로 남은 천실이나 끊어진 끈을 `發現`할 수 있다. 확인 뒤에는 작은 파란 실이 덤불 위에 실제로 표시된다.
4. 덤불 아래 걸린 꾸러미를 찾는다.
5. 꾸러미를 챙긴다.
6. 채집인이 기다리는 숲길로 돌아가 건넨다.

## 목표 문장 후보

`在最後的痕跡附近尋找，發現並帶回遺失的包裹。`

## 학습 역할

F6이 선형적인 추적이라면 F7은:

> 마지막 정보 → 주변 범위 설정 → 추가 정보 발견

의 구조다.

향후 학술탑의 “근거를 모아 범위를 좁힌다”는 사고의 아주 쉬운 전단계가 될 수 있다.

# 12. F8 — 오늘의 숲길

새 핵심어:

- `情況` — 상황 / 상태
- `安全` — 안전하다
- `危險` — 위험하다

보조·복습 후보:

- `乾 / 濕`
- `寬 / 窄`

대규모 재사용:

- `確認`
- `方向 / 路線`
- `障礙`
- `通過 / 避開`
- `帶領`
- 필요시 `後退`

## 이야기

이 시점의 소년은 북쪽 숲 주변을 여러 번 오갔다.

북쪽 숲의 채집인이 부탁한다.

> “오늘 장터로 수레를 가져가야 하는데, 숲 바깥길 상태가 조금 달라졌다고 하더라. 네가 요즘 그 길들을 다녀봤으니 같이 한번 봐줄래?”

소년이 특별한 권한을 얻는 것이 아니다.

그저 **최근 그 길들을 여러 번 다녀본 사람**이기 때문에 채집인과 함께 현재 상태를 확인한다.

## 판

숲 바깥길에 세 경로가 있다.

예:

### 서쪽 짧은 길

- 마른 길
- 작은 쓰러진 가지가 `障礙`
- 치우면 수레도 안전하게 통과 가능

### 동쪽 긴 길

- 별다른 장애물 없음
- 조금 멀지만 처음부터 안전

### 가운데 경사길

- 젖어 있고 미끄러운 상태
- 사람은 조심해서 갈 수 있지만 현재 작은 수레에는 `危險`

정확한 지형은 구현 단계에서 조정한다.

길은 타일마다 같은 방향의 장식선을 얹지 않는다. 인접 경로에 맞춰 직선·모서리·갈림이 실제로 이어지는 숲길 형태로 그린다. 마른 길은 방향 없는 흙·자갈 질감, 젖은 길은 진흙·웅덩이 질감으로 구별한다. 바퀴 자국을 쓸 경우에도 해당 길의 진행 방향과 굽이에 맞춘다.

## 플레이

1. 경로별 `情況`을 직접 확인한다.
2. 어떤 곳이 현재 수레에 `安全`하고 어떤 곳이 `危險`한지 판단한다.
3. 다음 중 하나를 선택할 수 있다.
   - 서쪽 장애물을 치우고 짧은 길 이용
   - 동쪽의 긴 안전한 길 이용
4. 소년이 수레를 `帶領`해 출구까지 이동한다.

**두 가지 이상의 유효한 해결법**을 유지한다.

가운데 위험한 길로 시도해도 즉시 게임 오버시키지 않는다.

> `這段路現在對貨車太危險。可以退回去看看別的路。`

처럼 되돌릴 수 있게 한다.

## 목표 문장 후보

`確認每條路的情況，避開危險的地方，帶貨車安全通過。`

## 학습 역할

이 판은 북쪽 숲 묶음의 종합판이다.

- 표식을 확인한다.
- 방향과 경로를 읽는다.
- 상태의 특징을 본다.
- 위험한 곳을 구별한다.
- 기존 이동 어휘를 실제 행동에 다시 쓴다.

아직 `允許 / 禁止 / 限制`처럼 “규칙상 지나가도 되는가”를 묻지는 않는다.

그 문제는 끝마을 같은 이후 지역에 남겨 둔다.

# 13. 북쪽 숲의 후일담

F8 뒤에는 새로운 지역을 발견하지 않는다.

소년이 수레를 데려다주고 혼자 물길마을로 돌아온다.

연출 방향:

> 처음 월백버섯을 찾으러 왔을 때는 나무 사이가 모두 비슷해 보였다.  
> 이제는 어느 갈림길이 어디로 이어지고, 어느 표식 뒤에 무엇이 있는지 조금씩 알아본다.

중국어 대사 후보:

> `第一次來找月白菇的時候，我還覺得到處都差不多。`  
> `現在這幾條路，我好像都認得了。`

이후 소년은 별도의 안내 없이 익숙한 길을 따라 여관으로 돌아온다.

중요한 감정:

> **새 장소를 얻었다기보다, 원래 있던 장소가 익숙한 장소가 되었다.**

이것이 북쪽 숲 묶음의 서사적 보상이다.

# 15. 기존 1장 단어 회수

북쪽 숲 전체에서 다음 단어를 의도적으로 반복한다.

- `進入 / 退出`
- `距離 / 範圍`
- `路線 / 經由`
- `位置 / 周圍 / 障礙`
- `移動 / 前進 / 後退`
- `跟隨 / 帶領`
- `條件 / 符合`
- `數量 / 足夠 / 不足`
- `獲得`

북쪽 숲은 새 단어 묶음인 동시에 **1장 단어의 두 번째 생활 문맥**이어야 한다.

# 16. 구현 시 지켜야 할 것

1. 새 핵심어는 기본적으로 판당 2~3개로 제한한다. F4의 `相似 / 不同`처럼 명확한 대비쌍은 하나의 학습 묶음으로 제시할 때만 예외로 한다.
2. F1은 기존 구현을 유지한다.
3. 색·모양·크기 표현은 정의 퀴즈가 아니라 실제 관찰 정보로 사용한다.
4. 목표 바로 아래에는 새 핵심어를 우선 표시한다.
5. 복습어를 UI에서 핵심어와 똑같은 무게로 나열해 화면을 복잡하게 만들지 않는다.
6. 잘못된 선택은 가능한 한 “어떤 특징이 달랐는지”를 보여 주는 피드백으로 처리한다.
7. F4/F5의 식물 이름 자체는 전문 암기 대상이 아니다.
8. F6/F7은 숨은그림찾기가 아니라 단어로 탐색 범위를 줄이는 판이어야 한다.
9. F8은 통행 허가 판정이 아니라 현재 길 상태와 안전 판단이다.
10. F8에는 하나의 정답 경로만 두지 않는다.
11. 북쪽 숲 완료를 끝마을 해금의 강제 조건으로 만들지는 아직 확정하지 않는다.
12. 북쪽 숲과 끝마을은 월드맵상 다른 방향이라는 설정을 훼손하지 않는다.
