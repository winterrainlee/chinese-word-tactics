## G0 — 범위와 안정성

- 본편 학술탑·단어장·읽기 연습·저장·STAGES 배열·이야기·해금은 변경하지 않는다. 기존 03A/03B/04A 및 승인 이력 유지.
- 독립 경로의 03A/B/C는 모두 자유 진입하며 브라우저 메모리에서만 선택을 유지한다. 새로고침·목록 복귀는 해당 연구의 시험 상태를 초기화한다. 재플레이도 새 상태로 시작한다. localStorage/게임 진행 API를 사용하지 않는다.
- 실제 03A/03B의 안정 ID는 유지 대상이며 03C 본편 ID·해금·신규 이야기 확정은 통합 G0에서 다룬다. 시험용 task ID(a-/b-/c-)는 본편 진행 ID가 아니다.
- 03A 색인, 03B 도시락과 옛 지도, 03C 자료·판단의 문맥을 사용한다. 가게 주인, 다리 사진, 톱니 균열 등 연습 사례는 신규 세계 사실이 아니다. 정식 이야기 장면과 주음·공식 어휘 데이터는 통합 때 기존 계약에 맞춰 편집한다.

## G1/G2 — 과제 및 의미 행동

| 시험 ID | 표현/목적 | 행동 | 판단 결과 |
|---|---|---|---|
| a-premise | 既然…就… | 뒤의 관계 고르기 | 받아들인 전제에서 판단 |
| a-otherwise | 不然 | 갈림 선택 | 앞 행동 미실행의 귀결 |
| a-sequence | 然後 | 같은 앞 행동과 비교 | 이후 행동의 순서 |
| a-transfer | 要不然 | 새 문맥 | 미실행 시 가능성 |
| a-read | 복합 | 강조 없는 연속 독해 | 알맞은 행동 선택 |
| b-still | 仍然 | 정보별 분류 | 길 이용 지속, 이용자 수 미확인 |
| b-despite | 雖然…依然… | 두 정보의 변화/지속 표시 | 가게 주인 변화, 길 이용 지속 |
| b-concede | 固然…但是… | 이어질 관계 선택 | 앞의 타당함 인정과 한계 |
| b-even | 縱然…依然… | 가정/확인 사실 구분 | 가정적 양보에도 판단 유지 |
| b-read | 복합 | 강조 없는 연속 독해 | 변화·지속·가정의 통합 |
| c-evidence | 顯然 | 관찰/판단 분류 | 사진 관찰과 추론 구분 |
| c-inevitable | 如果…必然… | 관찰/조건부 판단 분류 | 균열 사실과 미래 귀결 구분 |
| c-confidence | 當然 | 출처/화자의 판단 분류 | 지도에 있는 내용과 쪽지 주장 |
| c-scope | 不盡然 | 정보 유지/제한 표시 | 전체 판단만 제한 |
| c-surprise | 居然·竟然·果然 대비 | 예상과 다른 방향 선택 | 결과의 가치와 기대 차이 구분 |
| c-read | 복합 | 강조 없는 연속 독해 | 근거가 뒷받침하는 보고 |

`model.js`에 원문·표지어·보기·행/열·정답 및 오독별 피드백을 명시한다. 세 기믹은 다음과 같이 구분한다. (1) route: 뒤가 공개되기 전 관계 선택 → 원문 공개 및 피드백. 오답 후에도 실제 원문을 확인하고 다시 판단. (2) matrix: 각 정보가 유지/변화/미확인 또는 판단의 유지/제한 중 어디에 속하는지 직접 표시. (3) evidence: 같은 분류 조작이지만 관찰과 주장/추론의 출처를 확인. 끝의 reading에는 앞선 문장을 그대로 반복하지 않는 새 연습 기록을 사용하며 강조와 도식·뜻 안내를 제거하고 원문 기반 행동/해석만 묻는다. 불필요한 구절 복사·시간 제한·숙련도 수치는 없다.

문장은 순서대로 보이며 뒤 구절의 실제 내용 맞히기는 요구하지 않는다. 仍然·依然, 居然·竟然의 문맥상 허용 대안을 배제하지 않는다. 정방향 읽기를 방해하지 않는지 보는 작은 시험판이므로 단계 전체를 본편 이야기나 그림으로 완성하지 않는다. 색만으로 결과를 표현하지 않고 선택 상태와 피드백 문구를 병용한다. 뜻 조회는 선택 사항이며 정답 자체는 알려주지 않는다.

## v0.2 — 학습과 적용의 구분

학습 화면에서는 표지어 뜻을 먼저 제공하고 완성된 원문과 의미 관계를 나란히 보여 준다. 비교할 표현이나 상황을 직접 바꾸면 원문과 의미 도식이 동시에 바뀐다. 정오답·숙련도·필수 비교 횟수는 없다. 이미 아는 표현은 바로 '적용으로'를 눌러 넘어갈 수 있다. 관찰 예문과 기존 적용 예문은 구별한다. 학습 화면이 기존 문제의 정답을 외우게 하는 사전 풀이가 되지 않도록 한다.

| 연구 | 무채점 학습 순서(해당 적용 바로 앞) | 경험 |
|---|---|---|
| 03A | 既然/如果 → 不然/然後 → 不然/要不然 | 전제와 조건, 조건 갈림과 시간 순서, 같은 의미 방향 비교 |
| 03B | 仍然/依然 → 固然/雖然 → 雖然/縱然 | 과거·현재의 변화와 지속을 나란히 보며, 인정과 가정적 양보를 비교 |
| 03C | 顯然/可能 → 必然/可能 → 當然의 응답·주장 → 전체 주장/不盡然 → 果然/居然/竟然 | 관찰과 추론, 조건부 판단, 화자의 확신, 판단 범위, 기대와 실제 비교 |

학습은 `kind:'lesson'`과 `variants`로 데이터화한다. 각 변형에 원문·표지어·뜻·주음·시각 구조·짧은 설명을 둔다. 도식은 flow(전제/관계/판단), fork(조건 갈림), timeline(과거/현재 상태), scope(주장과 범위)로 구분한다. 변형 전환은 정오답 상태와 분리하며 다음 화면 진입을 막지 않는다. 기존 적용의 판정·뒷구절 공개·최종 무강조 독해는 보존한다.

기존 03B와 03C 마지막 적용에서 설명의 일부(앞 사실 보존, 문판의 균열)를 명확하게 수정했다. 새 연습 예문은 세계 설정이 아니다. 비교어의 공식 등급·어휘 데이터 편입과 이야기 통합은 본편에서 별도 검증한다.

### v0.2 검수 기준
- 연구 시작은 문제 대신 관찰이다. 모든 신규 중심 표현은 첫 적용 전에 관찰할 수 있다.
- 버튼을 누르면 원문과 의미 도식·풀이가 함께 바뀌고 어느 선택도 오답으로 취급하지 않는다. 같은 방향의 유의어는 억지 차이를 만들지 않는다.
- 관찰을 건너뛸 수 있고 기존 적용 단계는 판정을 그대로 거친다. 마지막에는 강조 없는 새 복합 글을 읽는다.
- 03B/03C가 단순 분류 퀴즈를 넘어 상태와 판단의 차이를 먼저 경험하게 하는지 확인한다. 관찰 도식만 외우게 하지 않는다.
- 본편 저장을 사용하지 않으며, 브라우저 모바일 회귀에서 관찰 변형 전환·건너뛰기·16개 적용 과제·연속 독해를 확인한다.
