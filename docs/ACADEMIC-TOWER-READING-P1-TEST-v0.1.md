## G0 — 범위와 안정성

- 본편 학술탑·단어장·읽기 연습·저장·STAGES 배열·이야기·해금은 변경하지 않는다. 기존 03A/03B/04A 및 승인 이력 유지.
- 독립 경로의 03A/B/C는 모두 자유 진입하며 브라우저 메모리에서만 선택을 유지한다. 새로고침·목록 복귀는 해당 연구의 시험 상태를 초기화한다. 재플레이도 새 상태로 시작한다. localStorage/게임 진행 API를 사용하지 않는다.
- 실제 03A/03B의 안정 ID는 유지 대상이며 03C 본편 ID·해금·신규 이야기 확정은 통합 G0에서 다룬다. 시험용 task ID(a-/b-/c-)는 본편 진행 ID가 아니다.
- 03A 색인, 03B 도시락과 옛 지도, 03C 자료·판단의 문맥을 사용한다. 가게 주인, 다리 사진, 톱니 균열 등 연습 사례는 신규 세계 사실이 아니다. 정식 이야기 장면과 주음·공식 어휘 데이터는 통합 때 기존 계약에 맞춰 편집한다.

## G1/G2 — 과제 및 의미 행동

| 시험 ID | 표현/목적 | 행동 | 판단 결과 |
|---|---|---|---|
| a-premise | 既然…就… | 뒤의 관계 고르기 | 받아들인 전제에서 판단 |
| a-otherwise | 不然 | 갈림 선택 | 앞 행동 미실행의 귀결 |
| a-sequence | 然後 | 같은 앞 행동과 비교 | 이후 행동의 순서 |
| a-transfer | 要不然 | 새 문맥 | 미실행 시 가능성 |
| a-read | 복합 | 강조 없는 연속 독해 | 알맞은 행동 선택 |
| b-still | 仍然 | 정보별 분류 | 길 이용 지속, 이용자 수 미확인 |
| b-despite | 雖然…依然… | 두 정보의 변화/지속 표시 | 가게 주인 변화, 길 이용 지속 |
| b-concede | 固然…但是… | 이어질 관계 선택 | 앞의 타당함 인정과 한계 |
| b-even | 縱然…依然… | 가정/확인 사실 구분 | 가정적 양보에도 판단 유지 |
| b-read | 복합 | 강조 없는 연속 독해 | 변화·지속·가정의 통합 |
| c-evidence | 顯然 | 관찰/판단 분류 | 사진 관찰과 추론 구분 |
| c-inevitable | 如果…必然… | 관찰/조건부 판단 분류 | 균열 사실과 미래 귀결 구분 |
| c-confidence | 當然 | 출처/화자의 판단 분류 | 지도에 있는 내용과 쪽지 주장 |
| c-scope | 不盡然 | 정보 유지/제한 표시 | 전체 판단만 제한 |
| c-surprise | 居然·竟然·果然 대비 | 예상과 다른 방향 선택 | 결과의 가치와 기대 차이 구분 |
| c-read | 복합 | 강조 없는 연속 독해 | 근거가 뒷받침하는 보고 |

`model.js`에 원문·표지어·보기·행/열·정답 및 오독별 피드백을 명시한다. 세 기믹은 다음과 같이 구분한다. (1) route: 뒤가 공개되기 전 관계 선택 → 원문 공개 및 피드백. 오답 후에도 실제 원문을 확인하고 다시 판단. (2) matrix: 각 정보가 유지/변화/미확인 또는 판단의 유지/제한 중 어디에 속하는지 직접 표시. (3) evidence: 같은 분류 조작이지만 관찰과 주장/추론의 출처를 확인. 끝의 reading에는 강조와 도식·뜻 안내를 제거하고 원문 기반 행동/해석만 묻는다. 불필요한 구절 복사·시간 제한·숙련도 수치는 없다.

문장은 순서대로 보이며 뒤 구절의 실제 내용 맞히기는 요구하지 않는다. 仍然·依然, 居然·竟然의 문맥상 허용 대안을 배제하지 않는다. 정방향 읽기를 방해하지 않는지 보는 작은 시험판이므로 단계 전체를 본편 이야기나 그림으로 완성하지 않는다. 색만으로 결과를 표현하지 않고 선택 상태와 피드백 문구를 병용한다. 뜻 조회는 선택 사항이며 정답 자체는 알려주지 않는다.
