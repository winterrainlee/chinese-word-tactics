## 구현 범위

여행 메뉴의 단어장 다음에 ‘내 글 읽기’를 추가했다. 첫 여행 전에도 사용할 수 있다. 선택 제목 100자, 본문 5,000자는 Unicode 코드 포인트 기준이다. 초과 입력은 자르지 않고 읽기·저장을 보류한다. 일반 텍스트 노드로만 렌더링하며 원문, 줄바꿈, 이모지와 희귀 한자를 유지한다.

첫 글은 강조를 끄고 시작한다. 토글은 본문 DOM 재생성 없이 CSS 배경색만 바꾼다. 단일 연녹색, 22px 본문, 비대화형 표지어이며 분류·문법 해설은 표시하지 않는다. 같은 글의 수정과 화면 왕복에서는 토글을 유지한다. 다른 글을 새로 시작하려면 임시 글 삭제 후 입력한다.

전용 `chinese-word-tactics-reader-draft-v1` 키에 마지막 유효 글만 지연 저장한다. 저장 실패·잘못된 데이터는 읽기 기능을 막지 않는다. 삭제는 확인/취소를 제공한다. 게임 저장·백업·진행 초기화와 분리하며 외부 글을 서버에 전송하지 않는다. 입력 상태는 메모리에서도 유지한다.

화면 진입은 게임 진행을 변경하지 않는다. 기존 복귀 문맥을 재사용하고 `fieldView`, `readerView`를 복귀 매핑에 추가했다. 여관 책상 연결·파일/URL 수집·오디오·학습 판정은 범위 밖이다.

## 2026-11-14 Safari 상단 빈 공간 수정

사용자가 Safari에서 읽기 화면 위에 긴 빈 공간을 보고했다. 원인은 `readerView`가 `#app` 밖의 형제 요소였기 때문이다. 다른 뷰를 숨겨도 `#app`의 `min-height:100svh`가 남아 읽기 화면을 한 화면 아래로 밀었다. Safari 전용 문법 오류가 아니라 공통 DOM 배치 결함이다. 수정 전 공개 사이트의 DOM 측정에서도 뷰포트 936px, 빈 `#app` 높이 936px, 읽기 뷰 시작 위치 936px로 재현했다.

읽기 뷰를 다른 화면과 같은 `#app` 자식으로 옮겼다. 읽기 화면에서만 호스트 여백을 없애 기존 흰 배경·안전 영역·본문 너비를 유지한다. CSS 자원 버전도 갱신했다.

기존 검사는 버튼 클릭 시 자동 스크롤되어 이 결함을 놓쳤다. 이제 읽기 진입 직후, 추가 클릭 전에 375×667·390×844·1024×768에서 문서 상단 위치, 헤더의 첫 화면 노출, 초기 스크롤 0, 가로 넘침을 검사한다. 돌아간 뒤 읽기 뷰 높이가 0인지와 랜딩의 상단 위치도 검사한다. 이 검사는 Chromium·WebKit, 배포 전 및 공개 Pages에 모두 적용된다. 실제 iPhone Safari 재검수는 별도다.

검증: 수정 커밋 `75253e69d02c07a33849226f765a05dc2d69c406`. [배포 실행 43541256300](https://github.com/winterrainlee/chinese-word-tactics/actions/runs/43541256300)의 배포 전·후 읽기 Chromium/WebKit 검사가 통과했다. 공개 사이트 직접 진입 시 읽기 시작 위치 0px, 헤더 12px, 스크롤 0을 확인했다. 콘텐츠 게이트도 통과했다.

## 2026-11-14 선택형 문장부호 강조

읽기 화면에 ‘문장부호도 표시’ 스위치를 추가했다. 기본은 꺼져 있으며 ‘표지어 표시’와 독립적으로 작동한다. 전각 `，；：`만 표지어와 같은 옅은 연녹색으로 강조한다. `。？！、「」『』（ ）`와 반각 `,;:`는 이번 범위에서 제외한다. 문장부호는 읽는 리듬을 눈으로 확인하는 보조 표시이며, 의미 분할이나 해석 완료 지점의 판정이 아니다. 학습 효과는 아직 검증하지 않았다.

문장부호는 별도 표시용 span으로 감싸며 사전·검출기·표지어 수에 포함하지 않는다. 원문을 변경하거나 HTML로 해석하지 않는다. 두 토글 모두 CSS 배경만 전환하므로 토글할 때 본문 노드를 다시 만들지 않는다. 옵션은 모바일에서 줄바꿈될 수 있고 44px 터치 높이를 유지한다.

임시 글의 선택 필드 `showPunctuation`으로 설정을 보관한다. 기존 schemaVersion 1 저장에서 이 필드가 없으면 false로 읽으므로 글을 잃지 않는다. 수정·화면 왕복·새로고침에서는 선택을 유지하고, 임시 글 삭제 후 새 글에서는 꺼진 상태로 시작한다. 문장부호만 있는 글은 표지어 미검출 안내를 바꾸지 않는다.
