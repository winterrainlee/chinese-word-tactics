# 내 글 읽기 v0.1 구현과 후속 검토

작성: 2026-11-14 (Asia/Taipei). 기준 HEAD: `29b170bcf477438ec86298a4a06392abbe2e2b7d`.
사용자의 A1/A2 기준 구현 요청을 반영했다. [기획](MY-TEXT-READER-PLAN-v0.1.md)과 [분석 결과](READER-CNA-ANALYSIS-RESULT-2026-11-13.md)를 따른다. 이번 커밋은 `[skip ci]`로 본편 Pages 배포를 실행하지 않는다. 실제 Safari 검수는 미완료다.

## 구현 범위

여행 메뉴의 단어장 다음에 ‘내 글 읽기’를 추가했다. 첫 여행 전에도 사용할 수 있다. 선택 제목 100자, 본문 5,000자는 Unicode 코드 포인트 기준이다. 초과 입력은 자르지 않고 읽기·저장을 보류한다. 일반 텍스트 노드로만 렌더링하며 원문, 줄바꿈, 이모지와 희귀 한자를 유지한다.

첫 글은 강조를 끄고 시작한다. 토글은 본문 DOM 재생성 없이 CSS 배경색만 바꾼다. 단일 연녹색, 22px 본문, 비대화형 표지어이며 분류·문법 해설은 표시하지 않는다. 같은 글의 수정과 화면 왕복에서는 토글을 유지한다. 다른 글을 새로 시작하려면 임시 글 삭제 후 입력한다.

전용 `chinese-word-tactics-reader-draft-v1` 키에 마지막 유효 글만 지연 저장한다. 저장 실패·잘못된 데이터는 읽기 기능을 막지 않는다. 삭제는 확인/취소를 제공한다. 게임 저장·백업·진행 초기화와 분리하며 외부 글을 서버에 전송하지 않는다. 입력 상태는 메모리에서도 유지한다.

화면 진입은 게임 진행을 변경하지 않는다. 기존 복귀 문맥을 재사용하고 `fieldView`, `readerView`를 복귀 매핑에 추가했다. 여관 책상 연결·파일/URL 수집·오디오·학습 판정은 범위 밖이다.

## A1/A2에서 제품 규칙으로 선별한 내용

A0/A1/A2는 고정 실험 조건이다. 제품 사전 `0.1.0`은 **A2 전체 복사본이 아니며 기존 실험 수치를 제품 성능으로 사용하지 않는다.**

| 구분 | 적용 |
|---|---|
| 초기 후보 | 기획의 22개를 유지한다. 미출현 후보까지 검증된 것으로 주장하지 않는다. |
| A1 추가 12개 | 至於·其中·此外·接著·隨後·另一方面·儘管·由於·為了·因應·受惠於·首先 |
| A1 조건부 2개 | 針對·對於는 문두·문장부호 뒤로 제한한다. 문장 중간의 유효한 화제 설정은 누락될 수 있다. |
| A2 일부 | 但는 절 첫머리(但凡·但願 제외), 則는 특정 후행 어휘와 앞글자 제외, 若는 절 첫머리 + 같은 문장 쉼표 뒤 應/將/預計를 확인한다. 若干은 제외한다. |
| 알려진 오탐 | 廢除非核 내부 除非, 立即使用 내부 即使의 정확한 결합만 차단한다. 모든 廢除非/立即使를 넓게 차단하지 않는다. |
| 보류 | 得 전체, A2의 모든 짝표현, 독립 仍·並·也·後·再·就·才, 다의어 不過·結果·只是·包括·同時 |

짝표현은 단어 내부와 구문 성립을 충분히 확인하기 전까지 제품에서 사용하지 않는다. 이는 보고서 §8의 ‘A2 전체를 그대로 제품에 가져오지 않는다’는 권고를 따른다. 因為·甚至·也就是·隨著·除了·不論 등의 사후 발견 후보도 이번 A1/A2 제품 범위에는 자동 추가하지 않았다.

得는 긍정 후보 說得很清楚·跑得很快·做得不錯도 현재 표시하지 않는다. 기사 양성 사례가 없고 제한 허용목록의 일반화가 확인되지 않았기 때문이다. 覺得·得到·不得·의무/허용 得와 가능보어 看得懂도 강조하지 않는다.

사전 JSON은 출처 문서, 채택 근거, 내부 읽기 행동을 기록한다. 공식 TBCL 항목을 수정하거나 근거 없는 공식 ID를 만들지 않았다. `tools/build-reader-content.cjs`가 실행용 JS를 생성하며 Node 검사에서 원본과 동등성을 확인한다. 매칭 위치는 UTF-16, 왼쪽 우선·동일 시작 최장 우선·중첩 금지다.

## 제품 규칙 재측정

기존 동일 본문 20개·112문단·11,560 코드 포인트를 해시로 확인해 재측정했다. 기존 단일 Codex 검토의 잠정 정답을 재사용했으며 독립 인간 검토나 학습 효과 시험이 아니다. 유보 검출은 TP/FP 분모에서 제외했다.

| 자료층 | TP | FP | FN | 유보 검출 | 정밀도 | 재현율 | 강조 글자 비율 |
|---|---:|---:|---:|---:|---:|---:|---:|
| A 요약 | 11 | 0 | 27 | 0 | 100% | 28.9% | 0.77% |
| B 원문 | 73 | 1 | 81 | 1 | 98.6% | 47.4% | 1.36% |
| 전체 | 84 | 1 | 108 | 1 | 98.8% | 43.8% | 1.24% |

A1의 TP56/FP4보다 검출을 늘렸지만, A2의 TP120/FP4보다 보수적으로 선별해 누락이 늘었다. 남은 FP와 유보가 있으므로 무오탐을 주장하지 않는다. [문단별 측정](../data/reader-runtime-eval-v0.1.json)에 본문이나 발췌는 포함하지 않았다.

```sh
node tools/build-reader-content.cjs --check
node --test tests/reader.test.cjs
node tools/verify-content.cjs
# 동일하게 추출한 본문은 저장소 밖에서 제공한다.
node tools/reader-runtime-eval.cjs /private/texts.json
python tests/smoke_reader.py
```

실행 확인: 새 Node 검사 7개 및 전체 콘텐츠 게이트(403개 Node 검사와 감사) 통과, 동일 본문 재측정 완료. 기획 단계의 Python 평가 스크립트와 정답은 변경하지 않았다.

미검증: 브라우저 검사는 환경 제약으로 실행하지 못했다. Playwright 브라우저 다운로드가 실패했고, 설치된 Chromium은 로컬 소켓 생성 권한 오류로 시작하지 못했다. `tests/smoke_reader.py`에는 Chromium/WebKit의 입력·안전 출력·토글 DOM/크기 유지·초과 입력·삭제·재로딩·저장 실패·복귀·하위 경로 검사를 작성했으나 통과했다고 표시하지 않는다. 실기기 Safari, 5,000자 렌더링 체감, 화면/스크롤/선택 보존의 실제 확인과 Pages 검수는 후속으로 남는다.

## 외부 오픈소스 후속 검토 후보

아래는 2026-11-13 조사한 공식 문서·저장소를 바탕으로 한 후보이며 실행 의존성을 추가하지 않았다. 라이브러리 속도·정확도 비교는 미측정이다. 로컬 신경망도 AI이므로 검증 도구에서 사용하는 것과 제품에 탑재하는 것을 구분한다.

후속 실험은 현 제품 규칙 → jieba 경계 검사 → Stanza 문맥 정보 순서로 분리한다. FP 감소뿐 아니라 새 FN, 강조 밀도, 실행 부담을 같은 정답에 비교한다. 원문 번체와 위치를 유지하고 다른 날짜·서사·설명문을 별도 평가한다. 사용자 켬/끔 독해 시험 전에는 학습 효과를 주장하지 않는다.
