# 따라온 단어들 — 디자인 원칙 v0.3

작성: 2026-10-05. 범위: 랜딩, 세계와 장소, 생활 공간, 이야기, 플레이, 기록, 제품 도구 전체.
상태: 전체 디자인 감사에서 추출한 공통 기준. 기존 화면을 일괄 변경했다는 뜻이 아니다.
근거: [전체 디자인 감사](DESIGN-AUDIT-v0.1.md), [콘텐츠 구조](GAME-CONTENT-FRAMEWORK-v0.1.md), [v0.2 상세 원칙](DESIGN-PRINCIPLES-v0.2.md).

## 1. 한 페이지 디자인 DNA

**조용한 여행 세계 안에서, 필요한 말과 변화가 또렷하게 드러난다.**

최상위 가치는 **simple & clarity**다. 인터페이스를 해독하는 수고는 줄이고, 단어의 의미를 판단하거나 세계를 탐색하는 일은 플레이어에게 남긴다. 단순함은 요소 수가 적다는 뜻이 아니다. 필요한 정보를 찾기 위해 더 많은 창을 열어야 한다면 단순해진 것이 아니다. 명확함은 다음 정답을 알려주는 것이 아니다.

| DNA | 지켜야 할 경험 | 피해야 할 반례 |
|---|---|---|
| D1. 장소가 먼저다. | 지도에서는 갈 곳을 고르고, 방에서는 머물며, 탑에서는 연구한다. 화면의 목적이 형태를 만든다. | 모든 장소에 목표·진행률·완료 버튼을 얹어 과제 목록으로 만든다. |
| D2. 큰 관계가 먼저 읽힌다. | 제목·정렬·여백·면으로 장소, 원본, 작업, 선택지의 위계를 드러낸다. | 문장마다 선을 그어 원본과 작업 영역의 큰 경계를 묻어버린다. |
| D3. 조작과 복귀는 예측할 수 있다. | 같은 뜻의 선택·실행·조회·닫기·돌아가기는 같은 문법을 쓴다. | 작은 의뢰 실행 버튼보다 큰 닫기 버튼을 더 강조하거나, 뒤로 간 뒤 원래 맥락을 잃는다. |
| D4. 말과 변화는 경험에 붙는다. | 학습 중에는 의미가 행동과 결과에, 생활에서는 사물과 흔적에 연결된다. | 같은 퍼즐의 단어 이름만 바꾸거나 결과와 관계없는 성공 문구만 띄운다. |
| D5. 도움은 가까이, 중복은 적게 둔다. | 뜻·세부 정보는 가까이서 열고 돌아온다. 판단에 필요한 정보는 숨기지 않는다. | 목표·선택·상태·설명에서 같은 사실을 반복하거나, 줄이기 위해 필수 조건까지 접는다. |
| D6. 분위기는 조용하고 상태는 또렷하다. | 따뜻한 밝은 면, 짙은 글자, 절제된 강조를 공유하되 지역의 재질과 풍경은 다르게 둔다. | 전 화면을 베이지 카드로 맞추거나, 장식색 때문에 선택·잠금·완료가 구분되지 않는다. |

선택지가 여럿인 상황에서 하나를 임의로 더 강조하지 않는다. 쉬어가는 화면에는 항상 할 일을 채워 넣지 않는다. 시간 압박, 가짜 숙련도, 출석·파밍 같은 장식은 도입하지 않는다.

## 2. 공통과 다양성의 경계

공통화는 세 층으로 한다. **게임 공통 계약 → 화면 역할의 문법 → 장소의 개성** 순이다. 위층의 가독성·조작성을 아래층의 연출이 침범하지 않는다.

| 게임 전체에서 공유한다. | 화면 유형에 따라 달라진다. | 장소별로 자유롭게 표현한다. |
|---|---|---|
| 정보 위계의 논리, 행동 역할, 상태 의미, 뜻 조회의 접근성, 터치 바닥값, 복귀 계약 | 지도 탐색, 사물 발견, 대사 읽기, 전술 조작, 문장 작업, 기록 색인, 설정 목록 | 재질·배경·실루엣·지역 그림·내용에 필요한 공간 배치 |

학술탑의 타공판·금속 레일·하늘은 지역의 개성이다. 다른 지역에 복제하지 않는다. 원본과 사용자 작업을 먼저 구별하는 위계는 공통 원칙의 좋은 적용이다. 곁가지 연구의 좁은 옆방과 완료 체크는 유지한다. 모든 지역에 격자나 같은 카드 크기를 요구하지 않는다.

## 3. 화면 역할별 계약

| 유형 | 주역과 첫 질문 | 유지할 것 | 상시 화면에서 덜어낼 것 |
|---|---|---|---|
| 랜딩 | 여행의 첫인상. 시작할까, 이어갈까? | 제목, 한 장면, 분명한 시작·재개, 조용한 보조 진입 | 기능 홍보 카드, 학습 통계, 설명을 위한 긴 부제 |
| 월드맵·장소 입구 | 세계의 공간 관계. 어디로 갈까? | 연결된 풍경, 읽히는 지명, 가능한 장소와 잠금 이유, 진행 변화 | 반복 사용법, 지도와 경쟁하는 운영 설명, 기본 카드 격자로의 환원 |
| 여관·소년의 방 | 생활과 귀환. 무엇이 놓여 있고 무엇이 남았나? | 방의 공간감, 자연스러운 사물 진입, 실제 여행에서 남은 기념물 | 전체 수집률, 모든 물건의 상시 설명, 의무적 다음 과제 |
| 이야기 | 인물·대사·사건. 무슨 일이 일어났나? | 중국어 대사, 요청 시 번역, 화자 구분, 명확한 이전·다음 | 대사보다 강한 메뉴, 매 대사마다 반복하는 조작 안내 |
| 전술판·장치판 | 상황과 변화. 무엇을 선택하고 어떻게 바꿀까? | 짧은 목표, 주요 단어, 안정된 판, 판단값, 근처 피드백, 되돌리기 | 이미 판에 보이는 상태의 반복 설명, 빈 카드 |
| 학술탑 작업대 | 읽기와 판단. 원본은 무엇이고 어디를 고칠까? | 원본/작업 면의 큰 경계, 충분한 한자 크기, 선택/확정/판정 분리 | 문장마다 외곽선, 정답 요약 중복, 이전 문제의 잔류 판정 |
| 여정 | 사건과 기록. 무엇을 했고 어디를 다시 볼까? | 장·장소·의뢰의 관계, 실제 상태, 재방문 위치 | 지역 허브의 전체 복제, 항상 펼친 운영 설명, 반복 상태 라벨 |
| 단어장 | 경험을 다시 연결하는 색인. 어떤 말과 비교할까? | 표제·주음·뜻·용례·비교의 위계, 찾기와 복귀 | 단어마다 같은 카드, 발견을 숙련으로 보이게 하는 장식 |
| 설정·공통 메뉴·보조 창 | 필요한 도구. 무엇이 바뀌며 어떻게 돌아갈까? | 명확한 기능명, 저장 위치·파괴적 행동 설명, 확인·취소·복귀 | 도구를 세계관 용어로 감춰 모호하게 만들기, 모든 행의 과도한 중첩 상자 |

학습은 제품의 목적이지만 모든 화면에 직접적인 학습 행동을 요구하지 않는다. 분위기·휴식·공간 기억에 기여하는 여백과 그림은 기능 없는 장식으로 취급하지 않는다.

## 4. 시각 언어

### 색과 재질은 이름보다 역할을 공유한다

기존의 밝은 종이색 바탕, 짙은 글자, 녹색 계열 주요 행동을 출발점으로 삼는다. 정확한 색값을 전 지역에 강제하지 않는다. 배경·콘텐츠 면·작업 면·떠 있는 보조 창의 역할을 구별하고, 텍스트와 상태의 대비를 우선한다. 탑의 짙은 헤더처럼 다른 면을 쓰면 그 위 글자와 아이콘도 함께 검토한다.

녹색 하나로 현재 위치·선택·정답·완료를 모두 대신하지 않는다. 체크, 선택 테두리, 문구, 활성 상태를 함께 써서 의미를 구분한다. 본선 완료와 개별 선택 연구의 완료도 같은 체크 의미를 유지한다.

### 글자와 여백이 구조를 만든다

페이지명, 작업 영역명, 본문, 보조 정보의 역할을 먼저 정한다. 역할이 다른 제목을 모두 같은 픽셀 크기로 맞추지 않는다. 학술탑의 큰 영역명과 단어장의 큰 한자 표제는 서로 다른 기능을 가진다.

기본 분리 수단은 여백·정렬·글자 위계다. 선과 면은 필요한 큰 관계에 사용한다. 카드·테두리·그림자는 독립된 조작물이나 실제 경계를 표현할 때 사용한다. 기존 v0.2의 컨테이너 인플레이션 방지 원칙을 이어간다.

지도 지명, 행동 이름, 다음 선택을 가르는 수량은 보조 장식이 아니다. 화면에 맞추기 위해 먼저 줄여서는 안 된다. 한글·번체·주음의 크기와 줄높이는 역할별로 정하고, 긴 문장은 문장부호와 의미 단위를 먼저 활용해 줄을 나눈다.

### 그림의 화풍까지 같을 필요는 없다

랜딩의 단순한 그림, 지도의 지형, 방의 생활 공간, 전술판의 명료한 기호는 서로 다른 밀도를 가질 수 있다. 일관성은 한 화풍으로 재제작하기보다 바탕·글자·조작물·강조색의 관계에서 먼저 찾는다. 그림 교체는 사용자가 느끼는 단절을 확인한 뒤 별도 결정한다.

## 5. 공통 상호작용 계약

| 의미 | 공통 규칙 |
|---|---|
| 실행·다음 진행 | 화면의 실제 목적에 맞는 행동을 강조한다. 동등한 복수 선택은 동등하게 표현한다. |
| 닫기·취소 | 실행과 경쟁하지 않는다. 단독 확인만 필요한 경우와 실제 선택지가 있는 경우를 구분한다. 큰 초록 버튼을 모든 닫기의 기본값으로 삼지 않는다. |
| 이전 화면·상위 장소 | 실제 목적지를 일관되게 표시한다. 뒤로가기의 시간 순서와 상위 장소로 나가는 행동을 혼동하지 않는다. 열었던 목록의 펼침·스크롤·선택을 가능한 한 보존한다. |
| 뜻·참고 조회 | 실행·정답 선택과 다른 표식을 쓴다. 작게 보여도 터치 영역은 44×44px 이상으로 확보한다. 읽은 뒤 진행이나 선택을 잃지 않고 돌아온다. |
| 선택과 판정 | 선택은 정답이 아니다. 필요한 작업은 선택→검토→확정→판정으로 구별하며 잘못된 선택을 지우지 않는다. |
| 완료·잠금·비활성 | 실제 상태에서 파생한다. 추천을 잠금으로, 발견을 숙련으로, 상설 묶음 완료를 장소 전체 완료로 바꾸지 않는다. |
| 보조 창 | 명확한 제목·닫기·복귀를 제공한다. 중요한 내용과 마지막 조작이 스크롤로 접근 가능해야 한다. 모달 포커스·키보드 복귀는 시각 검수와 별도로 확인한다. |

표식의 보이는 크기와 누르는 영역은 분리할 수 있다. 작은 체크나 아이콘을 위해 큰 카드를 만들 필요는 없지만, 터치 영역을 줄여서 공간 문제를 해결하지 않는다. 정밀 드래그가 필수가 되지 않게 하고 단순 탭 대안을 우선한다.

## 6. 언어와 정보의 노출

중국어는 학습 대상·원본·대사의 언어이고, 한국어는 사용자의 조작·길 찾기·필요한 도움의 언어다. 모든 한국어를 숨기거나 모든 중국어를 상시 번역하지 않는다. 설정·백업·잠금 이유처럼 학습이 아닌 도구의 안전한 사용에 필요한 설명은 명확하게 남긴다.

같은 사실은 기본 화면에서 대표 위치를 가진다. 다만 비교를 위해 두 대상을 함께 보거나, 원본과 작업을 대조하거나, 위험 행동을 확인하는 반복은 허용한다. 하나의 사실이 서로 다른 값으로 표시되지 않게 동일한 상태에서 파생한다.

새 문장을 넣기 전에 현재 판단, 장소의 이해, 감정의 호흡 중 무엇을 맡는지 정한다. 지운 뒤 첫 조작이나 상황 해석이 더 어려워지면 삭제하지 않는다. 도움을 접은 결과 열기·닫기가 늘어나는지도 함께 확인한다.

## 7. 화면 높이와 움직임

전술 핵심 흐름은 기존 375×640 viewport와 620px 세로 예산, 44px 터치 바닥값을 유지한다. 375×812, 375×667, 360×640도 함께 비교한다. 상세 기준은 [v0.2 §5.4](DESIGN-PRINCIPLES-v0.2.md#54-전술-스테이지-진행-화면)를 따른다.

이 예산을 모든 페이지의 고정 높이로 확대하지 않는다. 지도·기록·설정은 목적에 맞는 문서 스크롤을 허용한다. 긴 글이 있는 학술탑은 안정된 셸 안의 읽기 영역을 사용할 수 있다. 대신 핵심 조작이 잘리거나, 복귀할 때 위치가 사라지거나, 중첩 스크롤의 경계가 모호해지는지 확인한다.

판은 행동 전후에 안정적으로 유지한다. 이야기의 번역, 설정의 오류·복원 미리보기, 지도 표식 추가도 각각 가장 정보가 많은 상태로 검수한다. 등장 애니메이션 중 캡처한 화면을 최종 가독성 결함으로 오인하지 않는다. 정지 화면과 전환 중 상태를 구분하고 reduced-motion 설정도 별도로 확인한다.

## 8. 문서와 구현에 적용하는 순서

이 문서는 전체 공통 디자인 판단의 진입점이다. v0.2를 삭제하지 않는다. 이번에 다시 정의한 전체 범위와 공통 판단은 v0.3을 우선하고, v0.2 §5.4의 상세 전술 예산·판단 정보 규칙 및 §10의 단어장 상세 기준은 구체적인 보충 계약으로 이어간다. v0.2의 당시 실행 우선순위는 현재 미완료 목록으로 해석하지 않는다.

학술탑의 재질·옆방·원본/작업 영역은 [학술탑 UI 가이드](ACADEMIC-TOWER-UI-GUIDE-v0.1.md), 방은 [여관 가이드](INN-HUB-DESIGN-v0.2.md)를 따른다. 신규 기능 개발 게이트와 기기 승인은 [개발 표준](REGION-STAGE-DEVELOPMENT-STANDARD-v0.1.md)을 유지한다.

수정은 **역할 정의 → 대표 화면 비교 → 실제 상태 검증 → 필요한 범위 공통화** 순으로 한다. 전역 CSS부터 바꾸거나 새 프레임워크를 도입하지 않는다. 같은 의미의 규칙에 실제로 두 사용처가 생겼을 때만 작은 공통 규칙을 만든다. 현재 파일명과 최종 스타일의 책임이 같다고 가정하지 말고 전체 로딩 순서와 최종 적용값을 확인한다.

완료 기준은 “같은 모양이 되었는가”가 아니다. **처음 보는 장소에서도 조작과 결과를 이해하며, 장소마다 다른 일을 하고 있다고 느끼는가**다. 자동검사는 잘림·터치·상태 복귀를, 시각 검수는 위계·중복·개성·휴식의 여지를, 사용자 검수는 이해와 재미를 맡는다.
