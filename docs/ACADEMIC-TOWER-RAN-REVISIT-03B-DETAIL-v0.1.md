## 0. 이 편의 핵심 계약

**이야기의 출발은 감사 인사이지 의뢰가 아니다.** 소년은 새 표식이나 재난을 들고 오지 않는다. 연구원은 소년을 연구 보조원으로 채용하지 않는다. 처음에는 그저 서로 반가워하고, 책상에 있던 자료가 눈에 들어와 대화가 연구로 이어진다.

**첫 방문의 출입 규칙이 그대로 유효하다.** 문지기는 소년을 알아보지만 방문 목적·만날 사람을 확인한다. 연구원이 자신의 연구실 방문을 맡고 방문부에 기록한다. 수리패는 통행증이 아니며 보관실 자유 출입이나 탑 전용 자격을 얻지 않는다. 첫 방문의 어색함과 대비되는 친숙함을 대사로 보여 주되 절차를 없애지 않는다.

**플레이 순서를 강제하지 않는다.** 03B는 03A 다음에 시작하지만 본선 05 완료와 무관하다. 05 결과 이전이라면 소년에게 개인 기록 칸·관찰 카드가 아직 없을 수 있다. 03B 어느 장면도 그 보상을 필수 소품으로 삼지 않는다. 본선 05·04A·후속 본편은 03B 완료 여부에 영향받지 않는다.

**연구의 결과는 작은 공동 해설이다.** 연구원은 옛 지도를 읽고, 소년은 자신이 경험한 현재 마을을 이야기한다. 특정 시기·구역의 자료를 마을 전체의 진실로 확장하지 않는다. 표식 발광이나 미스터리 해명 없이도 한 편으로 끝난다.

## 2. G1 — 학습 목표, 어휘의 역할, 한 편의 행동

상황 한 문장: **옛 지도를 보게 된 소년은 자신이 알고 있는 지금의 마을과 기록을 대조하고, 남아 있는 사실과 기록자가 당연하게 여긴 추론을 구별해 연구원과 짧은 해설을 고친다.**

03A가 `然`의 글자 단서에서 표현 전체의 뜻을 발견하는 편이었다면, 03B는 `然` 표현을 **역사·지리 자료를 읽는 실제 상황 속에서 사용**하는 편이다. 공통 글자 찾기·글자 위치 분류·기존 일곱 표현 퀴즈를 되풀이하지 않는다.

| 중심 표현 | 이번 문맥의 역할 | 의미 → 화면 행동 → 남는 해석 |
|---|---|---|
| `仍然` | 과거의 한 요소가 현재도 이어짐 | 옛 설명과 현장 말 사이에서 **지속된 대상만** 짚음 → 마을 전체가 똑같다는 결론을 피함 |
| `突然` | 예상하지 못한 시점에 일이 일어남 | 접어 둔 종이가 갑자기 빠지는 **읽기 전용 이야기 장면**으로 체험. 뜻 확인 버튼·강제 시험 없음 |
| `當然` | 기록자가 당연하다고 여기는 평가·주장 | 지도가 직접 보여 준 정보와 쪽지 작성자의 단정을 구별 → `當然` 자체를 거짓 표시로 보지 않음 |
| `固然` | 앞 설명의 타당한 일부를 인정하며 새 관점을 보탬 | 지도에 그려진 수로 옆 공방의 사실을 남기고 시장 경험을 덧붙임 → 근거를 보존한 해설 |
| `不盡然` | 말이 전적으로 그렇지는 않음 | `全鎮`으로 확대된 메모의 적용 범위를 바로잡음 → 부분적인 사실은 남김 |

다섯 표현은 한 에피소드의 중심어라는 예외로 묶는다. **한 과제에서 신규 중심어를 1개, 최대 2개만 집중**해서 다룬다. 전체가 동일한 객관식 다섯 개가 되지 않도록 읽기·대상 선택·추론 구분·설명 추가·범위 수정의 행동을 다르게 한다. 03A의 `雖然 / 然而 / 既然 / 不然 / 果然 / 竟然 / 然後`는 필요할 때 대사에 자연스럽게 재등장하되 의무 복습 채점 대상으로 추가하지 않는다.

### 언어상의 비약을 금지한다

- `仍然`은 해당 사실이 지속됨을 말한다. 큰 장애나 극적인 변화를 항상 전제하지 않는다.
- `突然`과 `竟然`은 각각 사건의 갑작스러운 발생과 화자의 뜻밖이라는 평가를 나타내므로 동의어 시험을 만들지 않는다.
- `當然`은 화자가 당연히 여기는 뜻이지, 그 말을 쓴 주장이 자동으로 틀렸다는 표시가 아니다.
- `固然`은 이번에는 인정하고 덧붙이는 쓰임을 택한다. 본래 그러하다는 용법도 있으며 항상 `固然 A，但是 B`로만 한정하지 않는다.
- `不盡然`은 전부 부정이 아니다. 확인된 일부를 남기고 넓게 확장한 판단을 제한한다.

## 3. 이야기의 연속성·인물 관계

### 3.1 현재 구현과 반드시 일치시킬 것

1. 첫 입장 `academic-tower-arrival`에서 문지기는 외부인의 보관실 접근을 막고 연구원이 **자기 연구실** 방문을 등록해 책임졌다.
2. 01~03·03A에서 소년은 기록을 읽는 데 도움을 받고 직접 가설을 세워 보았다. 03A 완료만으로 연구원의 손님으로 다시 찾아올 인간관계는 충분하다.
3. 본선 05의 `academic-tower-turn-result`에서 **첫 관찰 카드**와 **소년에게 남겨 둔 기록 칸**을 받으며 “그럼 다시 와도 되나요?”라고 묻는다. 03B가 먼저 열릴 수 있으므로 이 장면은 03B의 전제가 아니다.
4. 월드맵에서 학술탑은 완결·격파 장소가 아니라 계속 돌아올 수 있는 상설 연구 장소다. 소년은 외지인에서 물길마을에 돌아올 자리가 생긴 여행자로 성장했다.
5. 기존 04A 보존안에서도 문지기에게 인사하고 방문 기록을 남기는 관례가 이어진다. 03B도 이를 앞서 무효화하지 않는다.
6. 강제 달력 진행이 없다. ‘사흘 뒤’, ‘오늘도’, ‘오랜만’과 같이 경과 시간을 플레이에 고정하는 표현은 쓰지 않는다.

**03B의 감정 변화는 ‘선생과 학생’에서 ‘서로에게 물을 것이 있는 지인’으로 한 걸음 움직이는 정도**다. 호감도 점수·새 직함·공식 협력 계약·탑의 비밀 열쇠는 추가하지 않는다.

### 3.2 도입 story: 《그냥 인사하러 왔어요》

공통 이야기 화면의 기존 초상·화자·중국어 원문·선택적 한국어 뜻·주음·이전/다음 조작을 재사용한다. 아직 보지 않은 연구 내용이나 `03B` 목표 단어 목록을 도입 내비게이션에 미리 노출하지 않는다. 아래는 게임에 넣을 수 있도록 작성한 **대사 초안**이다.

| 화자 | 중국어(번체) | 한국어 |
|---|---|---|
| 서술 | `少年又來到學術塔門前。這次他沒有帶來新的記錄。` | 소년이 다시 학술탑 문 앞에 왔다. 이번에는 새 기록을 가져오지 않았다. |
| 문지기 | `是你啊。這次要找哪一位？` | 전에 왔던 아이구나. 이번엔 누구를 찾니? |

| 문지기 | `我先替你問一聲。進去還是要登記。` | 계신지 먼저 물어볼게. 들어가려면 방문 등록은 해야 하고. |
| 서술 | `研究員從裡面走了出來，看見少年，停下了腳步。` | 안에서 나온 연구원은 소년을 보고 걸음을 멈췄다. |
| 연구원 | `怎麼了？又遇到讀不懂的記錄了嗎？` | 무슨 일이니? 또 읽기 어려운 기록을 만났어? |
| 소년 | `沒有啦。上次真的幫了我很多，所以想跟你說聲謝謝。` | 아니에요. 지난번에 정말 많이 도와주셔서 감사하다고 말씀드리고 싶었어요. |
| 연구원 | `……原來是這樣。進來坐一下吧。` | ……그랬구나. 들어와서 잠깐 앉을래? |

| 소년 | `咦？桌上這張是三溪鎮的舊地圖嗎？` | 어? 책상에 있는 이거 물길마을 옛 지도예요? |
| 연구원 | `是啊。我在核對舊圖旁的註記。你認得上面的地方？` | 맞아. 옛 지도 옆의 설명을 확인하고 있었어. 여기가 어딘지 알아보겠니? |
| 소년 | `好像是往市集的那條路。我走過那裡！` | 장터로 가는 그 길 같은데요. 저 거기 가 봤어요! |

**도입의 정확한 끝:** 연구원이 미리 준비한 과제를 건네는 대신 소년이 지도를 보고 먼저 반응한다. 연구원은 “네가 본 지금의 길은 어땠니?”라고 묻고, 첫 자료 비교로 전환한다.

이야기에서 소년이 감사 인사를 끝냈더라도 방문의 목적이 연구로 소급 변경되지 않는다. 연구원은 장인골에 보낼 자료를 또 억지로 만들지 않는다.

### 3.3 도중 장면과 관계 진전

- `T1`: 소년은 현재의 길을 이야기하고 연구원은 옛 지도에 없는 **지금의 정보**를 소년에게 묻는다.
- `T2`: 종이가 갑자기 빠져나오고 둘 다 조금 놀란다. 웃어도 되지만 숨겨진 주문·표식·큰 사건으로 만들지 않는다.
- `T3~T5`: 소년이 옛 메모를 그대로 믿지 않고 자신의 시장 경험을 말한다. 연구원도 그 말을 검토할 가치가 있는 **자료**로 받아들인다.
- `T6`: 두 사람은 **공동 해설**을 남긴다. 소년이 구술한 현재 정보와 연구원이 보관한 옛 자료는 출처를 섞지 않는다.

| 연구원 | `舊圖告訴我上面畫了什麼，你卻知道現在的人怎麼走。` | 옛 지도는 그때 무엇을 그렸는지 알려 주고, 너는 사람들이 지금 어떻게 다니는지 알잖아. |
| 소년 | `不過我也只看過一部分。另一處歇腳的地方還在不在，我不知道。` | 그래도 저도 일부만 봤어요. 다른 쉼터가 아직 남아 있는지는 모르겠고요. |
| 연구원 | `那就先留著這個問題。不是每一張註記都要有答案。` | 그럼 그 질문은 남겨 두자. 모든 메모에 답이 있어야 하는 건 아니니까. |
| 서술 | `研究員把共同寫好的註記夾回地圖封套。少年起身道別，出門時照樣留下離開的記錄。` | 연구원은 함께 쓴 해설을 지도 봉투에 끼워 넣었다. 소년은 작별 인사를 하고, 나갈 때는 평소처럼 방문부에 퇴실을 남겼다. |

03B를 먼저 하고 나중에 본선 05를 보는 경우에도 이 결과는 소년 전용 칸·관찰 카드를 전제하지 않는다. 본선 05에서 ‘다시 와도 되나요?’라고 물어도 **새 관찰 카드를 받아 미래의 연구 기록을 더 가져와도 되는지** 묻는 문맥으로 읽힌다. 구현 전 대사 순서 회귀에서 어색한 반복이 느껴지면 본선 05의 해당 한 문장만 조건부 윤문하는 별도 판단을 남기되, 이 설계만으로 본선 대사를 자동 변경하지 않는다.

## 4. 이번 이야기의 창작 사료와 사실의 범위

진짜 역사 문헌이 아니다. 03B 내부에서만 사용하는 **가상의 마을 옛 지도와 작성자 불명의 종이**다. 실제 대만 역사나 실재 지리의 증거로 표시하지 않는다.

| 자료 ID | 자료와 화면의 출처 표시 | 중국어 원문 | 자료가 직접 말하는 것 |
|---|---|---|---|
| `old-map` | 오래된 물길마을 지도·범례 | `舊圖上標著一條通往市集的路，路旁畫著兩處歇腳的地方。` | 지도에 장터 방향 길과 두 곳의 쉬어 가는 장소가 그려져 있음 |
| `boy-now` | 소년이 직접 본 지금의 길 | `那條路現在仍然有人走。不過，我只看見一處歇腳的地方。` | 길에는 지금도 사람이 다님; 소년은 쉼터 하나만 봄 |
| `map-workshops` | 지도 근처의 다른 표기 | `水道旁畫著幾間工坊。` | 수로 옆 몇몇 공방을 그림에 나타냄 |
| `loose-margin` | 접힌 종이·작성 시기 미상 | `水道旁有幾間工坊，當然全鎮的人都靠水道生活。` | 앞쪽은 지도와 부합할 수 있지만 `當然` 뒤 마을 전체에 관한 단정은 작성자의 판단 |
| `boy-market` | 소년의 장터 방문 경험 | `我在市集也看過各種買賣，不能只看水道旁的工坊。` | 소년이 장터에서 다른 생활 활동을 보았음. 그 자체로 수로와 무관하다고 확정하지는 않음 |

사료 해석에서 지킬 사항:

- 옛 지도에 그려진 두 곳의 쉼터가 **실제로 같은 시기에 존재했는지**는 지도 표현 이상의 확정 사실로 넓히지 않는다.
- 소년이 지금 한 곳밖에 보지 못했다는 것은 다른 하나가 **없어졌다**는 증거가 아니다.
- `loose-margin` 종이의 작성자·작성 연대·지도와의 정확한 시차는 모른다. 지도 바로 옆에 있었다는 이유만으로 지도와 같은 시대의 공식 해설로 취급하지 않는다.
- 1장의 길목·장인골·장터 방문 경험은 재사용해도 되지만, 미확정한 물줄기 이름·마을 창건자·특정 역사 연도·표식 비밀을 새로 확정하지 않는다.
- 이번 작은 소재(지도상의 길과 쉬어 가는 곳)는 03B 안의 창작 자료다. 월드맵에 새 상설 위치를 만들거나 영구 여행지로 등록할 필요는 없다.

## 5. G2 — 내부 작업 6개와 실제 원문

03B는 **전역 스테이지 1개, 내부 작업 6개**를 사용한다. 의미 판단은 네 개(`T1/T3/T4/T5`)이고 `T2`는 이야기만, `T6`는 전체 읽기·정리만 맡는다. 네 의미 판단은 중국어 기록의 **서로 다른 대상**을 다루며, 관계 이름을 차례로 외워 누르게 하지 않는다.

| task ID | 장면 | 유형 | 유일한 필수 행동 |
|---|---|---|---|
| `village-path` (T1) | 남아 있는 길·仍然 | 과거/현재 비교 | 현재까지 이어지는 구절을 중국어 기록에서 선택 |
| `village-paper` (T2) | 갑자기 나온 쪽지·突然 | 읽기 전용 돌발 사건 | 이야기 읽고 계속하기 |
| `village-assumption` (T3) | 당연한 설명?·當然 | 사실/평가 구별 | 지도 사실이 아니라 작성자 단정인 부분 선택 |
| `village-concession` (T4) | 인정하면서 보태기·固然 | 해설의 다른 측면 추가 | 앞 사실을 남기는 중국어 보충 문장 선택 |
| `village-scope` (T5) | 전부 그렇지는 않아·不盡然 | 과도한 범위 수정 | 원본이 아니라 공동 해설 초안의 확대된 표현을 직접 선택해 고침 |
| `village-reread` (T6) | 둘이 쓴 해설 | 완성된 기록 재독 | 번체 원문을 한 번에 펼쳐 읽고 결과로 이동 |

### T1 `village-path` — 길은 지금도 있을까?

원문: `old-map`과 `boy-now`를 한 장의 조사 자료로 묶어 보여 준다.

질문: **소년이 직접 확인한 ‘지금도 이어지는 것’은 어느 부분일까?**

| 후보 중국어 구절 | 판정 | 설명 |
|---|---|---|
| `那條路現在仍然有人走。` | 채택 (`road-used`) | 사람이 지금도 그 길을 다닌다는 직접 경험 |
| `路旁的兩處歇腳處現在都還在。` | 과장 (`two-rests`) | 두 곳 모두 남아 있다는 말은 현재 자료로 확인되지 않음 |
| `舊圖上的景物仍然完全一樣。` | 일반화 (`all-unchanged`) | 길의 지속이 주변 모든 풍경의 불변을 뜻하지 않음 |

모바일 입력: 중국어 구절 세 개 중 하나를 탭하면 **나의 관찰 메모**에 미확정으로 놓는다. ‘관찰 확인’으로 판정하며, 정답 전에는 체크나 완성선을 그리지 않는다. 자료의 한국어 뜻은 별도 ‘뜻 보기’로 자유롭게 볼 수 있다. 선택 후 화면에는 `仍然`이 **길에 대해서만** 붙는다고 표시한다.

오답: 선택을 지우지 않고 “소년이 직접 본 건 길을 다닌 사람이야. 보지 못한 나머지까지 있다고 말하지 않았어.”처럼 해당 과장을 짚는다. 완료 뒤에도 다른 쉼터의 현재 상태는 물음표로 남긴다.

### T2 `village-paper` — 이게 왜 갑자기 나와? ㅋㅋㅋ

읽기 전용 장면:

> 서술: `研究員剛把地圖的一角翻起來，一張摺好的紙突然滑了出來。`  
> 연구원이 지도의 한쪽을 들추자 접어 둔 종이 한 장이 갑자기 미끄러져 나왔다.
>
> 소년: `這張紙怎麼突然跑出來了？`  
> 이 종이는 왜 갑자기 튀어나오는 거예요?
>
> 연구원: `咦？我也不知道它什麼時候夾進去的。`  
> 어? 나도 언제 끼워진 건지 모르겠는데.

장면을 터치해서 `突然`을 맞히게 하지 않는다. `竟然`보다 좋은 정답이라고 억지 비교하지도 않는다. 쪽지가 누군가의 비밀 명령이나 다음 본편을 여는 열쇠가 되지 않는다. ‘계속 읽기’ 한 번으로 T3에 들어간다.

### T3 `village-assumption` — 그건 지도에 적힌 사실일까?

원본: `map-workshops`의 지도 표기와 `loose-margin`의 접힌 쪽지를 **서로 다른 출처**로 구분해 보여 준다.

질문: **쪽지에 적힌 말 중, 지도의 사실만으로는 확인할 수 없는 판단은?**

- 선택 대상 A — `水道旁畫著幾間工坊。` (지도에 그려진 정보)
- 선택 대상 B — `當然全鎮的人都靠水道生活。` (작성자가 당연하다고 여기는 확대된 판단, 채택)

대상 B를 탭하면 ‘나의 검토 메모’에 `作者的判斷，還不是地圖證明的事。`를 작성한 것으로 미리보기한다. 확정 후 단정임을 표시하되 **원래 쪽지 문장을 삭제하거나 거짓말로 몰지 않는다.** 대상 A를 누르면 “그건 지도에 그려진 부분이야. ‘全鎮’이라고 말한 근거를 따로 찾아봐.”라고 설명한다.

`當然` 자체는 상황에 따라 참인 말을 강조할 수 있다. 이번 오류는 **이 지도만으로 `全鎮`까지 결론 낸 범위**에 있다. 중국어를 읽기 전에 한국어 번역으로 정답 표시를 선노출하지 않는다.

### T4 `village-concession` — 맞는 말은 남겨 두고

연구원은 옛 지도에 수로 옆 공방이 그려졌다는 사실을 인정한다. 소년은 자신이 다녀온 장터의 다른 생활 모습을 말한다.

원문 초안: `舊圖上固然畫著水道旁的幾間工坊，但＿＿。`

질문: **옛 지도에 그려진 공방을 없애지 않으면서 함께 적을 만한 내용은?**

| 선택할 중국어 구절 | 판정·의미 |
|---|---|
| `市集上也有各種買賣，不能只看水道旁的工坊。` | 채택 (`market-perspective`). 지도에 그려진 공방을 남기며 새로운 관찰을 보탬 |
| `所以全鎮的人只靠水道生活。` | `all-water`. 일부 공방의 기록을 전체로 확대함 |
| `水道旁的工坊根本不存在。` | `erase-workshops`. 앞에서 남긴 지도 사실까지 지워 버림 |

조작: 아래 보충 구절 하나를 탭하면 **나의 해설 초안**에 문장 전체가 조합되어 미리 보인다. `固然`을 한 번 더 고르게 하지 않는다. 판정은 중국어 보충 구절의 근거가 이번 자료에 있는지로 한다. “수로 옆에 공방이 그려졌다는 사실은 남겨야 해. 장터에서 네가 본 것까지 함께 적어 보자.”처럼 정오답 모두 원문과 연결해서 보여 준다.

중국어 문체는 연구원의 기록용 문장이므로 소년의 일상 대사보다 약간 문어적이어도 된다. `固然`의 다른 용법까지 이번 한 문장에서 일반화하지 않는다.

### T5 `village-scope` — 꼭 전부 그런 건 아니지

공동 해설의 **잘못된 임시 초안**을 먼저 읽는다. 원본 사료가 아니다.

> `舊圖證明全鎮的人都靠水道生活。`  
> 옛 지도가 물길마을 사람 모두 수로에 의지해 생활한다는 걸 증명한다.

질문: **어느 판단을 그대로 남겨 두면 지나친 결론이 될까?**

- 고쳐야 할 메모 조각: `全鎮的人都靠水道生活` (`overbroad`, 채택)
- 보존할 지도 사실: `水道旁畫著幾間工坊` (`mapped-workshops`, 미채택)
- 보존할 소년의 관찰: `市集上也有各種買賣` (`market-witness`, 미채택)

플레이어는 **고칠 초안 조각 하나만 직접 탭**한다. 정답이면 원본 지도의 정보는 손대지 않고 **나의 해설 초안**에서만 해당 과장을 취소선으로 표시한다. 수정된 해설을 다음과 같이 보여 준다.

> `舊圖顯示水道旁有幾間工坊。可是，不能只憑這張圖就說全鎮的人都靠水道生活。`

소년의 말: `這張紙的說法也不盡然。至少，現在的市集不只有水道旁的工坊。`  
그 종이에 적힌 말이 전부 맞는 건 아니네요. 적어도 지금 장터에는 수로 옆 공방만 있는 게 아니니까요.

오답 중 지도 사실을 지우면 “수로 옆에 공방이 그려졌다는 건 남겨야 해. 고칠 건 마을 사람 모두에 대한 단정이야.”라고 설명한다. 시장 관찰을 지우면 “그것도 소년이 직접 본 내용이야. 두 자료를 모두 남겨 보자.”라고 안내한다. 이 문장은 `不盡然`을 무조건 ‘틀렸다’로 치환하는 퀴즈가 아니다.

### T6 `village-reread` — 두 사람이 함께 읽는 기록

지금까지 **확인한 것 / 소년의 경험 / 아직 모르는 것**을 출처 라벨과 함께 한 장에 다시 읽는다. 원본과 공동 해설이 뒤섞이지 않게 큰 영역을 분리한다.

완성 공동 해설 초안(중국어):

> `舊圖標著一條通往市集的路，還畫了水道旁的幾間工坊。少年說，那條路現在仍然有人走；他只看見一處歇腳的地方，另一處是否還在，還不知道。舊圖上固然畫著水道旁的幾間工坊，但少年在市集也看過各種買賣。只憑這張舊圖就說全鎮的人都靠水道生活，這樣的說法不盡然。`

이 메모는 현재 확인한 것 이상을 확정하지 않는다. `突然`은 문서의 역사 사실이 아니라 앞 장면의 자연스러운 사건으로 남고, `當然`은 쪽지 작성자의 어투였음을 되돌아볼 수 있다. 원본 기록 3개와 작성자 미상 쪽지는 재열람 가능하게 둔다.

‘함께 쓴 해설 확인’ 한 번으로 결과 story에 이어진다. 이 버튼은 **독해 능력 점수나 읽은 사실의 증명**으로 삼지 않으며 두 번째 정답 확인 버튼을 붙이지 않는다.

## 6. 화면·조작 상세 계약

- 03B는 기존 타공판·연구실 책상·원본 종이 면 스타일을 쓰되 새로운 지형 전술 격자를 만들지 않는다.
- **원본 기록 / 나의 해설**을 가장 먼저 구분한다. T2의 읽기 장면에는 정답을 입력할 작업면을 만들지 않는다. T1·T3·T4·T5의 실제 판단에만 작업면을 보여 준다.
- 자료는 출처(옛 지도/끼워진 쪽지/소년의 증언/내 해설)를 제목·여백·텍스트 라벨로 구분한다. 중국어 길고 짧은 문장마다 테두리를 둘러 카드가 난립하게 하지 않는다.
- 단계마다 원문 핵심 구절은 **번체**로 보여 주고, 한국어는 요청 시 펼치는 뜻·짧은 조작 안내·정오답 피드백에 둔다. 한글 보기만 눌러 정답을 맞힐 수 있게 원문과 판단 대상을 분리하지 않는다.
- 자유 뜻 조회(표현별 주음·뜻·짧은 설명)는 벌점이 없다. 뜻 조회 자체가 답을 고르거나 진행을 바꾸지 않는다. 이미 읽기 화면에 제공한 뜻을 같은 위치에서 또 다른 ‘뜻 다시 보기’ 패널로 중복하지 않는다.
- 정답 전에는 미선택 상태로 시작한다. **선택 → 내용 미리보기 → 확정 → 해당 근거 피드백**을 유지한다. 고르기만으로 정답을 확정하거나 초록 체크를 주지 않는다.
- 오답도 선택을 남겨 놓고 바로 바꿀 수 있다. 되돌리기·새로고침·다음에 이어하기가 현재 과제만 복구한다. 정답 위치를 고정한 색/자리 암기로 통과하지 않도록 선택 순서는 저장된 seed에 따라 섞되 텍스트·정답 ID는 안정적으로 유지한다.
- `仍然`에 붙는 현재 구절, `當然`에 붙는 주장, `固然` 뒤에 보탤 중국어 구절, `不盡然`이 제한하는 초안 **그 자체가 입력 대상**이어야 한다.
- 정밀 드래그는 필수가 아니다. iPhone 13 mini 기준 44×44px, 375×812 / 375×667 / 375×640 / 360×640, safe-area·키보드·주소창, 긴 문장·번역 펼침·피드백 상황의 가로 넘침과 손가락 가림을 검사한다.
- 진행 표시는 `1/6`부터 `6/6`까지의 작업 위치를 보여 줄 수 있지만, T2·T6을 언어 정답으로 계산하지 않는다. 반복 횟수나 정답 속도를 숙련도 점수로 환산하지 않는다.

- `src/academic-tower.css`: 원본/해설 위계만 필요한 범위로 확대. 중복 카드 디자인이나 새로운 전역 UI 도입은 금지.
- `src/lexicon-content.js` / 어휘 생애주기 편집 데이터: 중심 표현의 출처·발음과 기존 단어 노출 상태를 점검. 공식 원자료 자체는 수정하지 않음.

### 7.2 임시 상태와 영구 상태

기존 저장 외곽 `stage/story/milestone` 포맷을 유지한다. 03B 전용 진행 상태는 **기존 `meaning-links/1` 방식을 우선 재사용**한다. 설계상 필요한 필드는 아래와 같다.

| 필드 | 용도 |
|---|---|
| `taskIndex` / `phase` | 현재 내부 작업 번호와 `work / review / complete` 상태. 읽기 전용도 안정 task ID로 판별 |
| `answers` | task ID에 매핑된 확정 판단만 보존 |
| `placements` 또는 `relation` | 현재 미확정 구절 선택·관계. 기존 순수 상태 규칙을 따라 둘 중 필요한 것만 사용 |
| `lastCheck` | 직전 정오답과 한국어 근거 피드백 |
| `optionOrder` 또는 동등한 안정 seed | 선택지의 표시 순서를 재접속 시 유지하는 데 필요할 때만 사용 |
| `seenStories` / `completedStages` (전역 기존 필드) | 03A 선행 충족, 03B 최초 결과 열람과 완료 상태 관리 |

구현 전에는 기존 `meaning-links/1`가 읽기 전용 task·선택지 셔플·직접 타깃 선택을 어떻게 정규화하는지 코드와 대조한다. **필드가 이미 있는데 새로운 별도 저장 구조를 중복 생성하지 않는다.** 새 스키마가 필요하다면 이 문서와 마이그레이션 검사를 먼저 수정한다.

- 최초 완료에서 `academic-tower-turn-03b-ran-village`만 `completedStages`에 추가한다. `academic-tower-turn-foundation`을 건드리지 않는다.
- 결과 story는 첫 완료에 한 번만 자동 연결하며 나중에 별도 재열람한다. 03B 완료 뒤 결과 story가 아직 읽히지 않았으면 재진입 시 결과 확인을 우선하고 스테이지를 새로 풀게 하지 않는다.
- 미완료 중단·새로고침은 읽던 내부 과제로 되돌아간다. 원본·뜻 조회는 자유롭게 다시 열 수 있다. 오답 미확정 선택도 유효한 경우 유지한다.
- 구형 저장에는 03B 기록이 없으므로 다른 스테이지의 저장을 이 새로운 stage에 잘못 붙이지 않는다. 03A 완료·결과 열람, 본선 05 완료/미완료 등 **기존 기록을 변경 없이 해석**한다.
- 재플레이는 최초 결과·어휘 발견·보상·본선 milestone을 재발생시키지 않는다.
- 연구실·여정·월드에서 시작한 플레이의 복귀 위치는 실제 출발 맥락을 유지하되 03B **첫 결과**는 학술탑 허브로 돌아온다.
