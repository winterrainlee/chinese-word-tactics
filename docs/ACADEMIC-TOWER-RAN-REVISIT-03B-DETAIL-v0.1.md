## 0. 이 편의 핵심 계약

**이야기의 출발은 도시락을 곁들인 감사 인사이지 의뢰가 아니다.** 소년은 새 표식이나 재난 대신 여관에서 싸 온 작은 도시락을 가져온다. 연구원은 소년을 연구 보조원으로 채용하지 않는다. 도시락은 부탁의 대가나 출입 허가를 얻기 위한 선물이 아니라 감사의 표시다. 연구원이 고맙게 받아 주고, 소년이 책상의 지도를 보며 대화가 연구로 이어진다.

**첫 방문의 출입 규칙이 그대로 유효하다.** 문지기는 소년을 알아보지만 방문 목적·만날 사람을 확인한다. 연구원이 자신의 연구실 방문을 맡고 방문부에 기록한다. 수리패는 통행증이 아니며 보관실 자유 출입이나 탑 전용 자격을 얻지 않는다. 첫 방문의 어색함과 대비되는 친숙함을 대사로 보여 주되 절차를 없애지 않는다.

**플레이 순서를 강제하지 않는다.** 03B는 03A 다음에 시작하지만 본선 05 완료와 무관하다. 05 결과 이전이라면 소년에게 개인 기록 칸·관찰 카드가 아직 없을 수 있다. 03B 어느 장면도 그 보상을 필수 소품으로 삼지 않는다. 본선 05·04A·후속 본편은 03B 완료 여부에 영향받지 않는다.

**연구의 결과는 작은 공동 해설이다.** 연구원은 옛 지도를 읽고, 소년은 자신이 경험한 현재 마을을 이야기한다. 특정 시기·구역의 자료를 마을 전체의 진실로 확장하지 않는다. 연구가 끝나면 두 사람이 도시락을 나눠 먹는다. 표식 발광이나 미스터리 해명 없이도 한 편으로 끝난다.

## 2. G1 — 학습 목표, 어휘의 역할, 한 편의 행동

상황 한 문장: **옛 지도를 보게 된 소년은 자신이 알고 있는 지금의 마을과 기록을 대조하고, 남아 있는 사실과 기록자가 당연하게 여긴 추론을 구별해 연구원과 짧은 해설을 고친다.**

03A가 `然`의 글자 단서에서 표현 전체의 뜻을 발견하는 편이었다면, 03B는 `然` 표현을 **역사·지리 자료를 읽는 실제 상황 속에서 사용**하는 편이다. 공통 글자 찾기·글자 위치 분류·기존 일곱 표현 퀴즈를 되풀이하지 않는다.

| 중심 표현 | 이번 문맥의 역할 | 의미 → 화면 행동 → 남는 해석 |
|---|---|---|
| `仍然` | 과거의 한 요소가 현재도 이어짐 | 옛 설명과 현장 말 사이에서 **지속된 대상만** 짚음 → 마을 전체가 똑같다는 결론을 피함 |
| `突然` | 예상하지 못한 시점에 일이 일어남 | 접어 둔 종이가 갑자기 빠지는 **읽기 전용 이야기 장면**으로 체험. 뜻 확인 버튼·강제 시험 없음 |
| `當然` | 소년의 자연스러운 긍정 응답과 쪽지 작성자의 확신 | 도입의 무리 없는 용법과 별개로, 지도 사실과 쪽지 작성자가 당연하게 여기는 주장을 구별함 |
| `固然` | 앞 설명의 타당한 일부를 인정하며 새 관점을 보탬 | 지도에 그려진 수로 옆 공방의 사실을 남기고 시장 경험을 덧붙임 → 근거를 보존한 해설 |
| `不盡然` | 옛 지도는 지금의 마을에 전혀 쓸모없다는 평가를 부분적으로 반박 | 옛 지도만으로 지금 전체를 설명할 수는 없지만 비교 자료로서의 쓰임은 남김 |

다섯 표현은 한 에피소드의 중심어라는 예외로 묶는다. **한 과제에서 신규 중심어를 1개, 최대 2개만 집중**해서 다룬다. 전체가 동일한 객관식 다섯 개가 되지 않도록 읽기·대상 선택·추론 구분·설명 추가·범위 수정의 행동을 다르게 한다. 03A의 `雖然 / 然而 / 既然 / 不然 / 果然 / 竟然 / 然後`는 필요할 때 대사에 자연스럽게 재등장하되 의무 복습 채점 대상으로 추가하지 않는다.

### 언어상의 비약을 금지한다

- `仍然`은 해당 사실이 지속됨을 말한다. 큰 장애나 극적인 변화를 항상 전제하지 않는다.
- `突然`과 `竟然`은 각각 사건의 갑작스러운 발생과 화자의 뜻밖이라는 평가를 나타내므로 동의어 시험을 만들지 않는다.
- `當然`은 화자가 당연히 여기는 뜻이지, 그 말을 쓴 주장이 자동으로 틀렸다는 표시가 아니다.
- `固然`은 이번에는 인정하고 덧붙이는 쓰임을 택한다. 본래 그러하다는 용법도 있으며 항상 `固然 A，但是 B`로만 한정하지 않는다.
- `不盡然`은 전부 부정이 아니다. 확인된 일부를 남기고 넓게 확장한 판단을 제한한다.

## 3. 이야기의 연속성·인물 관계

### 3.1 현재 구현과 반드시 일치시킬 것

1. 첫 입장 `academic-tower-arrival`에서 문지기는 외부인의 보관실 접근을 막고 연구원이 **자기 연구실** 방문을 등록해 책임졌다.
2. 01~03·03A에서 소년은 기록을 읽는 데 도움을 받고 직접 가설을 세워 보았다. 03A 완료만으로 연구원의 손님으로 다시 찾아올 인간관계는 충분하다.
3. 본선 05의 `academic-tower-turn-result`에서 **첫 관찰 카드**와 **소년에게 남겨 둔 기록 칸**을 받으며 “그럼 다시 와도 되나요?”라고 묻는다. 03B가 먼저 열릴 수 있으므로 이 장면은 03B의 전제가 아니다.
4. 월드맵에서 학술탑은 완결·격파 장소가 아니라 계속 돌아올 수 있는 상설 연구 장소다. 소년은 외지인에서 물길마을에 돌아올 자리가 생긴 여행자로 성장했다.
5. 기존 04A 보존안에서도 문지기에게 인사하고 방문 기록을 남기는 관례가 이어진다. 03B도 이를 앞서 무효화하지 않는다.
6. 강제 달력 진행이 없다. ‘사흘 뒤’, ‘오늘도’, ‘오랜만’과 같이 경과 시간을 플레이에 고정하는 표현은 쓰지 않는다.

**03B의 감정 변화는 ‘선생과 학생’에서 ‘서로에게 물을 것이 있는 지인’으로 한 걸음 움직이는 정도**다. 호감도 점수·새 직함·공식 협력 계약·탑의 비밀 열쇠는 추가하지 않는다.

### 3.2 도입 story: 《도시락을 싸 왔어요》

공통 이야기 화면의 기존 초상·화자·중국어 원문·선택적 한국어 뜻·주음·이전/다음 조작을 재사용한다. 새 연구 목록을 먼저 제시하거나 03B 학습 퀴즈를 예고하지 않는다. 소년이 처음 방문할 때 **연구원의 이름을 모른 채** 찾아왔던 것과 대비해, 이제 ‘지난번에 도와주신 분’을 방문할 수 있다. 아래는 도시락 소품을 반영한 **대사 초안**이며 확정 원고는 아니다.

| 화자 | 중국어(번체) | 한국어 |
|---|---|---|
| 서술 | `少年又來到學術塔門前，手裡提著一個用布包好的小飯盒。這次，他不是來查記錄的。` | 소년이 천으로 감싼 작은 도시락을 들고 다시 학술탑 문 앞에 섰다. 이번에는 기록을 찾으러 온 게 아니었다. |
| 문지기 | `是你啊。這次要找哪一位？` | 전에 왔던 아이구나. 이번엔 누구를 찾니? |

| 문지기 | `我先替你問一聲。進去還是要登記。` | 계신지 먼저 물어볼게. 들어가려면 방문 등록은 해야 하고. |

| 연구원 | `怎麼了？又遇到讀不懂的記錄了嗎？` | 무슨 일이니? 또 읽기 어려운 기록을 만났어? |

| 서술 | `研究員在訪客簿上記好名字，帶少年走進自己的研究室，把飯盒放在沒有文件的小桌上。` | 연구원은 방문부에 이름을 적고 소년을 자기 연구실로 데려갔다. 도시락은 자료가 없는 작은 탁자에 조심스럽게 놓았다. |
| 소년 | `裡面只有麵包和水果。不知道你喜不喜歡。` | 안에는 빵하고 과일밖에 없는데, 좋아하실지 모르겠어요. |
| 연구원 | `謝謝。待會兒一起吃吧。` | 고마워. 조금 이따 같이 먹자. |
| 소년 | `咦？桌上這張是三溪鎮的舊地圖嗎？` | 어? 책상에 있는 이거 물길마을 옛 지도예요? |

| 연구원 | `那這回得向你請教了。現在那條路是什麼樣子？` | 그럼 이번엔 내가 물어봐야겠네. 그 길은 지금 어때? |

도시락은 **소년이 직접 손으로 챙긴 작은 식사**지만, 요리를 직접 했다는 설정까지 확정하지 않는다. 빵과 과일은 현재 마을에서 구하기 무리 없는 소박한 음식으로 둔다. 도시락을 싸는 일은 여관의 미구현 주방 조작·구매·일일 식사 시스템을 요구하지 않는다. 현대적인 `便當`은 중국어 대사의 자연스러운 생활 표현일 뿐, 새로운 필수 단어장 목표나 재료 제작 과제가 아니다.

도입에서 **선물 → 연구원의 감사 → 소년이 지도를 발견**하는 순서를 보존한다. 문지기에게 음식을 내보여서 통행 허가를 받는 장면은 아니다. 도시락은 기록에 얼룩이 생기지 않도록 연구 자료와 다른 탁자에 둔다. 질문을 던지는 마지막 대사는 **연구원이 소년에게 현재의 길을 묻는 순간**이다. 소년이 감사 인사를 한 목적은 연구로 소급 변경되지 않는다.

### 3.3 도중 이야기 — 연구 작업과 인물 대화는 **다른 화면**

**실제 플레이 감수에 따른 확정 변경:** 정답 설명에 붙어 있던 `task.reaction`(화자·대사)을 전부 제거한다. 학술탑 작업대는 원본 / 나의 해석 / 검토 근거만 담당한다. 인물 간 대화·표정·웃음·서사 진행은 **기존 StoryRuntime의 공통 이야기 화면**으로 전환해 보여 준다. 별도 대화 카드나 새로운 대화 UI를 만들지 않는다.

| 순서 | 화면 | 사건·학습 |
|---|---|---|
| 도입 | 공통 이야기 화면 | 도시락 감사 방문 → 소년이 지도 발견 |
| T1 `仍然` | 학술탑 작업대 | 옛 길과 현재 증언 비교. 성공 피드백은 자료 근거만 |
| **장면 A / T2 `突然`** | **공통 이야기 화면** | 연구원이 소년에게 배우기 시작함 → 종이가 갑자기 떨어져 둘이 웃음. **선택·채점 없음** |
| T3 `當然` | 작업대 | 옛 기록의 표시와 저자의 확신 분리 |
| T4 `固然` | 작업대 | 옛 공방 표시는 보존하고 현재 장터 경험 추가 |
| **장면 B** | **공통 이야기 화면** | 연구원이 소년의 현장 경험을 듣고 서로 대등하게 기록을 함께 쓰기로 함. **선택·채점 없음** |
| T5 `不盡然` | 작업대 | 옛 지도는 전혀 쓸모없다는 과도한 판단을 수정 |
| T6 공동 해설 | 작업대(읽기만) | 중국어 해설과 출처를 재독. 화자 대사 제거 |
| 결말 | 공통 이야기 화면 | 소년이 `不盡然`으로 판단을 돌아본 후 도시락을 함께 먹음 |

**장면 A 원문:**
1. 연구원 — `原來你真的走過。那我不能只看舊圖了。` / 정말 다녀왔구나. 옛 지도만 보고 있을 수는 없겠네.
2. 서술 — `研究員剛翻開地圖的一角，一張摺好的紙突然滑了出來。` / 연구원이 지도를 펼치자 접힌 종이가 갑자기 빠져나왔다.
3. 소년 — `這張紙怎麼突然跑出來了？` / 이 종이는 왜 갑자기 나와요?
4. 연구원 — `咦？我明明記得已經整理好了……` / 어? 분명 다 정리했다고 생각했는데….
5. 서술 — `少年忍不住笑了一下。研究員也笑了，把紙攤開。` / 소년이 웃음을 참지 못하자 연구원도 피식 웃으며 종이를 펼쳤다.

**장면 B 원문:**
1. 소년 — `剛才那張紙說得那麼肯定，怎麼會知道全鎮的事呢？` / 아까 쪽지는 그렇게 자신 있게 말하던데, 마을 전체를 어떻게 알았을까요?
2. 연구원 — `你說得對。原來現在的市集還有那麼多買賣。` / 그러네. 지금 장터에는 다양한 거래가 있구나.
3. 소년 — `你沒去看過嗎？` / 연구원님은 가 보신 적 없어요?
4. 연구원 — `舊記錄我看得多，現在的市集倒是你比較熟。這一段就一起寫吧。` / 옛 기록은 내가 많이 봤지만 지금 장터는 네가 더 잘 알겠네. 이 부분은 함께 적자.

장면 B는 T5의 옛 지도가 `完全沒有參考價值`라는 다음 판단에 대한 답을 선노출하지 않는다. T5 성공 후 소년의 `完全沒用了？也不盡然吧。`는 결과 story로 옮긴다. 정답 하나마다 이야기 화면을 띄우는 게 아니라 **의미 있는 장면 전환 두 번만 사용**한다.

### 3.3A 저장·복귀·재플레이

- 전역 `stage`는 기존 `academic-tower-turn-03b-ran-village` 하나다. 6개 내부 `task.id`, 원문, 정답, 완료 기록, 03A 선행/04A 비필수 관계를 유지한다.
- `meaning-links/1` 저장에 이 스테이지 전용 `phase:'scene'`, `sceneId`, `sceneIndex`, `seenScenes`를 추가한다. **이야기 대사 인덱스까지 저장**하므로 새로고침·메뉴로 이동 후 복귀는 대화 도중으로 돌아온다.
- T1 성공 `review`의 다음은 T2 `village-paper` 이야기 A로 이동한다. 이야기 완료 때 T2의 답을 기록하고 T3로 진입한다.
- T4 성공 `review`의 다음은 T5에 앞서 이야기 B를 열고, 이야기 완료 후 T5 작업을 시작한다.
- 재플레이는 새 임시 상태로 시작하고 공통 이야기 화면의 `건너뛰기`를 두 중간 장면에 제공한다. 이미 얻은 결과 story·아이템·본선 완료는 반복 지급하지 않는다.
- 기존 03B 미완료 저장은 의미 답안이 유지된다. 예전 T2 읽기 작업 중이었다면 이야기 A로, 이미 T5에서 아직 답을 고르지 않았다면 이야기 B로 연결한다. **기완료 03B나 뒤쪽 저장을 초기화하지 않는다.**
- 중간 이야기 두 개는 별도 여정 필수 story 노드가 아니다. 도입과 결말은 기존 여정에서 다시 볼 수 있고, 중간 장면은 03B 재플레이로 다시 볼 수 있다. 주음·번역 표시·초상은 현재의 공통 이야기 화면 설정을 따른다.

도시락은 **새 보상·호감도 상승·소모 아이템으로 등록하지 않는다.** 마지막 나눠 먹는 순간은 감사의 마음을 연구원이 받아 주고 서로에게 도움을 주고받는 관계로 변화했다는 감정적 마무리다. 지도에 음식을 놓거나 기록을 먹으면서 정리하는 장면으로 만들지 않는다.

03B를 먼저 하고 나중에 본선 05를 보는 경우에도 이 결과는 소년 전용 칸·관찰 카드를 전제하지 않는다. 본선 05에서 ‘다시 와도 되나요?’라고 물어도 **새 관찰 카드를 받아 미래의 연구 기록을 더 가져와도 되는지** 묻는 문맥으로 읽힌다. 구현 전 대사 순서 회귀에서 어색한 반복이 느껴지면 본선 05의 해당 한 문장만 조건부 윤문하는 별도 판단을 남기되, 이 설계만으로 본선 대사를 자동 변경하지 않는다.

## 4. 이번 이야기의 창작 사료와 사실의 범위

진짜 역사 문헌이 아니다. 03B 내부에서만 사용하는 **가상의 물길마을 옛 지도·지도 옆 주석·끼워진 쪽지·봉투 평가**다. 실제 대만 역사나 실재 지리의 증거로 표시하지 않는다.

| 자료 ID | 화면에 보일 출처 | 중국어 원문 | 자료가 직접 말하거나 주장하는 것 |
|---|---|---|---|
| `old-map` | 오래된 지도와 지도 가장자리의 옛 메모 | `舊圖上標著一條通往市集的路，路旁畫著兩處歇腳的地方。圖邊寫著：「這條路常有人走。」` | 지도에는 장터로 가는 길과 쉬어 가는 곳 두 곳이 그려져 있고, 지도 옆의 *작성자 미상 메모*는 길을 자주 이용했다고 주장 |
| `boy-now` | 소년이 직접 본 지금의 길 | `我走過那條路，路上還有人來往。不過，我只看見一處歇腳的地方。` | 소년이 길을 직접 걸었고 지금도 길을 다니는 사람을 봄. 쉼터는 **하나만 봤을 뿐**, 다른 하나가 없어졌다는 뜻이 아님 |
| `map-workshops` | 옛 지도에서 확인할 수 있는 공방 표시 | `水道旁畫著幾間工坊。` | 수로 옆에 공방 몇 곳이 지도에 그려져 있음 |
| `loose-margin` | 갑자기 빠져나온 접힌 쪽지·작성 시점 미상 | `水道旁有幾間工坊，鎮上的買賣當然都離不開水道。` | 공방이 있다는 사실을 바탕으로 **마을의 모든 거래가 수로와 관련 있다는 생각**을 덧붙인 작성자 미상의 주장 |
| `boy-market` | 소년의 현재 장터 경험 | `我在市集也看過各種買賣。光看舊圖上的工坊，還不知道現在全鎮的樣子。` | 소년은 장터에서 여러 거래를 봄. 이것만으로 옛날 장터의 생활이나 오늘날의 수로 의존을 단정하지 않음 |
| `folder-opinion` | 자료 봉투에 나중에 덧쓴 평가·작성자 미상 | `這張舊圖太舊了，對現在的三溪鎮已經完全沒有參考價值。` | 옛 지도가 **오늘날에는 전혀 쓸모없다**는, 확인이 필요한 과도한 평가 |

사료 해석에서 지킬 사항:

- 오래된 지도는 **지도에 무엇이 표시됐는지**를 알려 준다. 주석의 작성 시기·정확성은 별도로 확인하지 않았다. 길의 당시 이용은 '옛 메모의 주장'으로 출처를 남긴다.
- 소년이 오늘날 쉼터 하나만 봤다는 것은 다른 하나가 없어졌다는 증거가 아니다.
- `loose-margin` 쪽지의 작성자·연대·지도와의 실제 시차는 모른다. 지도와 같은 시대의 공식 해설로 취급하지 않는다.
- 현재의 장터에 여러 거래가 있다는 사실도 ‘그 거래가 수로와 **전혀 무관하다**’는 증거는 아니다. **현재와 과거, 그림과 현장 증언을 섞어서 같은 시대의 전체 사실로 만들지 않는다.**
- 1장의 길목·장인골·장터 방문 경험은 재사용하되 미확정한 물줄기 이름·마을 창건자·특정 역사 연도·표식 비밀을 확정하지 않는다.
- 이 작은 지도 소재를 새 상설 월드 장소나 공식 세계사로 옮기지 않는다.

## 5. G2 — 내부 작업 6개와 실제 원문

03B는 **전역 스테이지 1개, 내부 작업 6개**를 사용한다. 의미 판단은 네 개(`T1/T3/T4/T5`)이고 `T2`는 이야기만, `T6`는 전체 읽기·정리만 맡는다. 네 의미 판단은 중국어 기록의 **서로 다른 대상**을 다루며, 관계 이름을 차례로 외워 누르게 하지 않는다.

### 5.0 누가 쓰고, 누가 검토하는가 — 사용자 플레이 피드백 반영

**원본의 작성자, 작업면 문장의 실제 주인, 플레이어가 수행할 조작**은 서로 다른 개념이다. ‘나의 해설 초안’이라는 일반 UI 이름을 쓰면 소년이 틀린 결론을 썼는지 연구원의 메모를 고치는지 구별할 수 없다. 03B에서는 아래 역할을 명시하며, 이후 학술탑 스테이지에도 같은 질문을 먼저 적용한다.

| task | 원본 출처 | 작업면 이름/실제 주체 | 지시문이 요청하는 행동 |
|---|---|---|---|
| T1 `仍然` | 작성자 미상 옛 지도 메모 + 소년의 현재 목격 | **소년의 비교 메모** · 소년이 남길 문장 | 소년이 직접 본 사실에 근거해 **무엇이 지금도 이어지는지** 하나 고르기 |
| T2 `突然` | 연구실에서 방금 일어난 일 | **작업면 없음** · 소년과 연구원의 대화 | 별도 이야기 화면에서 읽고 진행, 채점 없음 |
| T3 `當然` | 지도에 그려진 사실 + 작성자 미상의 쪽지 | **소년의 검토 표시** · 소년이 원본 속 주장 표시 | 소년이 그 쪽지에서 작성자의 단정 부분만 표시. **원본 글을 고치지 않음** |
| T4 `固然` | 옛 지도 공방 표기 + 소년의 장터 경험 | **연구원의 해설 초안** · 연구원이 시작, 소년이 보탬 | 연구원이 써 둔 앞문장 `固然…但＿＿`에 소년의 경험으로 뒷부분을 이어 쓰기 |
| T5 `不盡然` | **봉투에 적힌 작성자 미상 평가** | **봉투 평가의 검토문** · 연구원이 원래 주장을 검토용으로 옮겨 정리 | 다른 사람의 주장을 공동 해설에 옮기기 전에 지나친 부분을 표시. **소년·연구원의 잘못된 결론이 아님** |
| T6 공동 해설 | 옛 지도 + 소년의 경험 + 출처 미상의 주장 | **두 사람이 함께 쓴 최종 해설** | 두 사람의 기록을 함께 읽고 마무리 |

T4의 앞부분은 **선택 전에 실제 중국어 초안으로 보이게** 한다. 새 문장 뒷부분 선택만 강요하면서 시작 문장을 숨기지 않는다. 선택 후에는 전체 문장을 하나의 미리보기로 표시하고, 선택 전후 같은 문장을 중복 카드로 쌓지 않는다.

T5의 `這張舊圖很舊，所以…`는 봉투의 의견을 연구원이 **검토를 위해 요약한 문장**이다. 원래 봉투의 중국어 문장을 그대로 복사한 인용문도, 두 사람이 합의한 최종 해설도 아니다. 따라서 작업면은 ‘나의 해설 초안’이 아니라 '봉투 평가의 검토문'으로 표시하고, 무엇을 검토 중인지 한 줄로 설명한다. 과장은 검토문에서만 고치고 출처가 되는 봉투의 원문은 그대로 둔다.

**UI 데이터 계약:** 03B 각 판단 task가 `workLabel`(작업면 이름), `question`(해당 주체의 실제 행동), `confirmLabel`(확정 행동), 필요한 경우 `workContext`(출처/작성 관계를 밝히는 짧은 배경), `draftLabel`(기존 검토 문구의 성격), `workKind`(기존 시각 위계)를 가진다. 렌더러는 이를 그대로 보여 주고 선택·정답 ID와 저장 스키마를 건드리지 않는다. 이 정보를 없는 데도 ‘나의’라고 자동 추측하지 않는다.



| task ID | 장면 | 유형 | 유일한 필수 행동 |
|---|---|---|---|
| `village-path` (T1) | 남아 있는 길·仍然 | 소년의 비교 메모 | 소년이 목격한 지금의 사실과 연결해 기록할 문장 선택 |
| `village-paper` (T2) | 갑자기 나온 쪽지·突然 | **공통 이야기 화면 A** | 짧은 장면 읽기만, 완료 시 자동으로 T3로 이동 |
| `village-assumption` (T3) | 당연한 설명?·當然 | 소년의 검토 표시 | 소년이 쪽지에서 작성자의 단정만 표시 |
| `village-concession` (T4) | 인정하면서 보태기·固然 | 연구원의 해설 초안 | 연구원 초안의 앞문장을 보고 소년의 현장 경험으로 이어 쓴 뒤 이야기 B로 이동 |
| `village-scope` (T5) | 전부 그렇지는 않아·不盡然 | 봉투 평가의 검토문 | 연구원이 옮겨 적은 남의 평가에서 과장을 고침. 둘의 결론 아님 |
| `village-reread` (T6) | 둘이 쓴 해설 | 완성된 기록 재독 | 번체 원문을 한 번에 펼쳐 읽고 결과로 이동 |

### T1 `village-path` — 길은 지금도 있을까?

원본은 `old-map`과 `boy-now`다. 옛 지도·옆 메모는 *옛 기록*, 소년의 말은 *현재의 목격*이라는 출처를 분명히 표시한다. **원본에는 `仍然`을 포함한 정답 문장을 넣지 않는다.** 옛 자료와 소년의 말을 비교해야 의미가 완성된다.

질문: **소년이 자신이 본 지금의 길을 `仍然`을 써서 기록한다면, 어느 문장을 남길 수 있을까?**

| 새로 작성할 중국어 메모 | 판정 | 설명 |
|---|---|---|
| `通往市集的那條路現在仍然有人走。` | 채택 (`road-used`) | 옛 메모에는 길 이용이 언급되고 현재 소년도 그 길에서 사람을 봄 |
| `路旁兩處歇腳的地方現在仍然都在。` | 과장 (`two-rests`) | 지금 소년은 한 곳만 봤음. 다른 곳이 남아 있는지는 모름 |
| `那條路現在仍然每天都跟以前一樣熱鬧。` | 일반화 (`same-crowd`) | 어느 시대에 얼마나 붐볐는지는 비교할 자료가 없음 |

**셋 다 `仍然`을 포함한다.** 따라서 단어 글자나 정답 위치가 아니라, '무엇이 예전과 지금에 걸쳐 이어지는가'를 골라야 한다. 과거 주석 자체의 진실을 검증한 것으로 과장하지 않는다.

모바일 입력: 중국어 관찰 메모 세 개 중 하나를 탭해 **소년의 비교 메모**에 미확정으로 놓는다. 확정 뒤 `仍然`이 **길의 이용**에 붙는다는 근거만 작업대에 보여 준다. 연구원의 반응은 다음 공통 이야기 화면에서 나온다. 단어의 한국어 뜻 조회는 자유롭지만 선택 전에 옳은 중국어 메모를 번역으로 표시하지 않는다.

오답은 그대로 두고 “소년이 실제로 봤다고 한 건 길과 그 길을 다닌 사람이야. 쉼터 두 곳이나 매일 같은 붐빔은 확인하지 못했어.”처럼 구체적으로 설명한다. 완료 후에도 다른 쉼터의 현재 상태는 미확인으로 남는다.

### T2 `village-paper` — 이게 왜 갑자기 나와? ㅋㅋㅋ

기존 연구 작업대 대신 **공통 이야기 화면 A로 진행**한다. **정답 버튼이나 퀴즈는 없다.** 연구원이 지도를 정리하다 뜻밖에 빠져나온 쪽지를 보고 잠시 당황하는 평범한 순간이다.

> 서술: `研究員剛翻開地圖的一角，一張摺好的紙突然滑了出來。`  
> 연구원이 지도의 한쪽을 들추자 접어 둔 종이 한 장이 갑자기 미끄러져 나왔다.
>
> 소년: `這張紙怎麼突然跑出來了？`  
> 이 종이는 왜 갑자기 튀어나오는 거예요?
>
> 연구원: `咦？我明明記得已經整理好了……`  
> 어? 분명 정리해 놨다고 생각했는데….
>
> 서술: `少年忍不住笑了一下。研究員也笑了，把紙攤開。`  
> 소년이 웃음을 참지 못하자 연구원도 피식 웃고 종이를 펼쳤다.

`突然`의 발생은 이 장면에서 이미 경험한다. `竟然`과 배타적인 정답을 겨루지 않는다. 쪽지는 비밀 명령이나 마법 열쇠가 아니며 **다음 장면에서 읽을 `loose-margin`**일 뿐이다. '계속 읽기' 한 번으로 T3에 들어간다.

### T3 `village-assumption` — 그건 지도에 적힌 사실일까?

원본 `map-workshops`과 `loose-margin`을 출처별로 나눠 보여 준다. 소년이 도입에서 `當然認得！`라고 자연스럽게 대답한 것과 달리, 이 쪽지의 `當然`은 **작성자의 확신을 나타낼 뿐 그 확신을 증명하지 않는다.**

질문: **소년이 쪽지에 검토 표시를 한다면, 어디를 작성자의 ‘당연하다’는 주장으로 표시해야 할까?**

- 후보 A — `水道旁畫著幾間工坊。` (`map-fact`, 지도에 보이는 표시)
- 후보 B — `鎮上的買賣當然都離不開水道。` (`author-claim`, 채택: 작성자의 전체 주장)
- 후보 C — `舊圖標著通往市集的路。` (`map-path`, 지도에 보이는 표시)

세 구절 모두 중국어로 보여 주고, 선택 후에도 **원본 지도와 작성자 미상 쪽지를 구분한 채 보존**한다. 선택은 '저자 판단으로 표시할 구절'에 붙으며 문장을 지우거나 그 견해가 틀렸다고 단정하지 않는다.

성공: 소년 `這張紙說得好肯定，可是它怎麼知道全鎮的事？` / “이 쪽지는 엄청 자신 있게 말하네요. 그런데 마을 전체를 어떻게 아는 거죠?”라는 짧은 반응을 보여 준다. 기록 메모는 `這是作者的看法，不是舊圖直接證明的事。`로 정리한다.

다른 구절을 선택한 오답은 “그건 지도에 실제로 표시된 길/공방이야. 쪽지의 ‘都’가 어디까지 넓혔는지 봐.”라고 설명한다. **`當然`이 들어갔기 때문에 거짓이라는 판정은 금지**한다.

### T4 `village-concession` — 맞는 말은 남겨 두고

원본 `map-workshops`와 `boy-market`을 함께 제시한다. 연구원은 옛 지도가 **과거 수로 주변 공방을 표시했다는 사실**을 인정하고, 소년은 **현재 장터**에서 본 거래를 더한다. 둘의 관찰 시점이 다르므로 ‘옛 마을에 분명히 장터가 있었다’, ‘현재 공방은 다 사라졌다’고 단정하면 안 된다.

연구원이 작업 면에 적기 시작한 문장: `舊圖上固然畫著水道旁的幾間工坊，但＿＿。`

질문: **연구원이 적어 둔 앞문장에 소년이 본 지금 장터 이야기를 이어 쓰려면?**

| 선택할 중국어 뒷부분 | 판정·의미 |
|---|---|
| `現在的市集也有各種買賣，不能只憑舊圖推斷今天全鎮的生活。` | 채택 (`present-market`). 과거 지도의 사실을 남기고 **현재에 관한 별도 관찰**을 더함 |
| `這表示舊時全鎮的人一定都住在工坊附近。` | `old-only-workshops`. 옛날 마을 전체의 생활을 지도 일부에서 만들어 냄 |
| `圖上的那幾間工坊現在一定全都消失了。` | `all-gone`. 현재 공방의 존재 여부는 소년이 말한 적 없음 |

조작: 화면에 제시된 **연구원의 해설 초안**(`舊圖上固然畫著…，但＿＿。`)을 보고 뒤에 붙일 중국어 구절 하나를 탭한다. 이미 문장에 있는 `固然`을 다시 고르지 않는다. 성공 문장은 다음과 같다.

> `舊圖上固然畫著水道旁的幾間工坊，但現在的市集也有各種買賣，不能只憑舊圖推斷今天全鎮的生活。`

연구원의 반응과 소년에게 배우는 장면은 **T4 다음의 공통 이야기 화면 B**에서 다룬다. 작업대에서는 데이터 해석·문장 연결의 근거만 표시한다.

오답은 원문을 보존하고 “수로 옆에 공방이 그려졌다는 사실은 남기자. 장터의 현재 생활을 덧붙이는 데서 멈춰야 해.”처럼 추론의 넘친 범위를 짚는다. `固然`의 다른 뜻과 문장 패턴을 하나의 어원 공식으로 만들지 않는다.

### T5 `village-scope` — 꼭 전부 그런 건 아니지

T3에서 검토한 ‘온 마을의 거래는 수로에 의존한다’는 문장을 **다시 눌러 정답을 반복하지 않는다.** 새로운 `folder-opinion`은 반대 방향의 지나친 단정이야. 이번에는 옛 지도가 **지금의 마을을 이해하는 데 완전히 쓸모없다**는 견해를 검토한다.

봉투의 원본 평가:

> `這張舊圖太舊了，對現在的三溪鎮已經完全沒有參考價值。`

연구원은 작성자 미상의 봉투 평가를 공동 해설에 넣어도 되는지 판단하려고 **검토용으로 요약한 문장**을 적는다. 이것은 원래 자료의 말이지 소년이나 연구원이 내린 결론이 아니다. 원본 평가와 별도로 **'봉투 평가의 검토문'**을 제시한다.

> `這張舊圖很舊，所以對現在的三溪鎮已經完全沒有參考價值。`

질문: **봉투의 의견을 공동 해설에 옮기기 전에, 검토문에서 어느 단정을 고쳐야 할까?**

- `這張舊圖很舊` (`old-fact`, 유지)
- `對現在的三溪鎮` (`present-target`, 해설의 대상, 유지)
- `完全沒有參考價值` (`no-value`, 고칠 부분)

**연구원이 옮겨 적은 검토문에서 고칠 부분 하나를 직접 탭**한다. 정답이면 `完全沒有參考價值`에만 취소선을 긋고 아래 해설을 추가한다. 원본 봉투의 평가는 변하지 않는다.

> `舊圖雖然不能告訴我們現在每個地方的樣子，但至少能用來對照那條通往市集的路。`

소년: `完全沒用了？也不盡然吧。至少那條路現在還有人走。`  
“완전히 쓸모없다고요? 꼭 그런 건 아니죠. 적어도 그 길은 지금도 사람들이 다니잖아요.”

`不盡然`은 ‘옛 지도에 적힌 것은 전부 정확하다’가 아니다. **오늘날 전체를 설명하기에는 부족하지만, 비교해 볼 가치는 남아 있다**는 의미다. 오답으로 ‘옛 지도는 오래됐다’를 고르면 “오래된 건 맞아. 그렇다고 지금과 비교할 단서까지 없다는 뜻은 아니야.”라고 알려 준다.

### T6 `village-reread` — 두 사람이 함께 읽는 기록

지금까지 **옛 자료의 표기·누군가의 평가 / 소년의 현재 경험 / 아직 모르는 것**을 출처 라벨과 함께 한 장에 다시 읽는다. 옛 지도와 지금 관찰의 시차를 없애지 않는다. 새 기호 배치나 추가 뜻 선택은 없다.

완성 공동 해설 초안(중국어):

> `舊圖標著一條通往市集的路，圖旁還記著那條路常有人走，並畫了水道旁的幾間工坊。少年說，那條路現在仍然有人走；他只看見一處歇腳的地方，另一處是否還在，尚不知道。舊圖上固然畫著水道旁的工坊，但今天的市集也有各種買賣，不能只憑舊圖就說全鎮的買賣都離不開水道。有人說舊圖對今天毫無參考價值，這樣的說法也不盡然；至少，我們可以拿那條路和現在的情況對照。`

T3의 쪽지에 있는 `當然`은 작성자의 확신이라는 출처 표시를 붙여 다시 펼쳐 볼 수 있다. `突然`은 지도상의 옛 사건이 아니라 종이가 빠져나온 **지금 연구실의 장면**으로만 남는다. 03A의 글자 분해·뜻 반복 퀴즈를 붙이지 않는다.

‘함께 쓴 해설 확인’ 한 번으로 결과 story에 이어진다. 읽었다는 버튼이 독해 실력이나 숙련도를 증명하지는 않는다. 결과에서 연구원이 옛 자료를 더 잘 이해하게 된 만큼, 소년 역시 **모르는 것은 모른다고 적는 태도**를 배웠다는 점을 남긴다.

## 6. 화면·조작 상세 계약

- 03B는 기존 타공판·연구실 책상·원본 종이 면 스타일을 쓰되 새로운 지형 전술 격자를 만들지 않는다.
- **원본 기록 / 나의 해설**을 가장 먼저 구분한다. T2의 읽기 장면에는 정답을 입력할 작업면을 만들지 않는다. T1·T3·T4·T5의 실제 판단에만 작업면을 보여 준다.
- 자료는 출처(옛 지도/끼워진 쪽지/소년의 증언/내 해설)를 제목·여백·텍스트 라벨로 구분한다. 중국어 길고 짧은 문장마다 테두리를 둘러 카드가 난립하게 하지 않는다.
- 단계마다 원문 핵심 구절은 **번체**로 보여 주고, 한국어는 요청 시 펼치는 뜻·짧은 조작 안내·정오답 피드백에 둔다. 한글 보기만 눌러 정답을 맞힐 수 있게 원문과 판단 대상을 분리하지 않는다.
- 자유 뜻 조회(표현별 주음·뜻·짧은 설명)는 벌점이 없다. 뜻 조회 자체가 답을 고르거나 진행을 바꾸지 않는다. 이미 읽기 화면에 제공한 뜻을 같은 위치에서 또 다른 ‘뜻 다시 보기’ 패널로 중복하지 않는다.
- 정답 전에는 미선택 상태로 시작한다. **선택 → 내용 미리보기 → 확정 → 해당 근거 피드백**을 유지한다. 고르기만으로 정답을 확정하거나 초록 체크를 주지 않는다. **T1·T3·T4·T5의 짧은 인물 반응은 성공 피드백 안에 함께 표시**해 별도 이야기 확인 클릭을 추가하지 않는다.
- 오답도 선택을 남겨 놓고 바로 바꿀 수 있다. 되돌리기·새로고침·다음에 이어하기가 현재 과제만 복구한다. 정답 위치를 고정한 색/자리 암기로 통과하지 않도록 선택 순서는 저장된 seed에 따라 섞되 텍스트·정답 ID는 안정적으로 유지한다.
- `仍然`에 붙는 현재 구절, `當然`에 붙는 주장, `固然` 뒤에 보탤 중국어 구절, `不盡然`이 제한하는 초안 **그 자체가 입력 대상**이어야 한다.
- 정밀 드래그는 필수가 아니다. iPhone 13 mini 기준 44×44px, 375×812 / 375×667 / 375×640 / 360×640, safe-area·키보드·주소창, 긴 문장·번역 펼침·피드백 상황의 가로 넘침과 손가락 가림을 검사한다.
- 진행 표시는 `1/6`부터 `6/6`까지의 작업 위치를 보여 줄 수 있지만, T2·T6을 언어 정답으로 계산하지 않는다. 반복 횟수나 정답 속도를 숙련도 점수로 환산하지 않는다.

### 7.2 임시 상태와 영구 상태

기존 저장 외곽 `stage/story/milestone` 포맷을 유지한다. 03B 전용 진행 상태는 **기존 `meaning-links/1` 방식을 우선 재사용**한다. 설계상 필요한 필드는 아래와 같다.

| 필드 | 용도 |
|---|---|
| `taskIndex` / `phase` | 현재 내부 작업 번호와 `work / review / complete` 상태. 읽기 전용도 안정 task ID로 판별 |
| `answers` | task ID에 매핑된 확정 판단만 보존 |
| `placements` 또는 `relation` | 현재 미확정 구절 선택·관계. 기존 순수 상태 규칙을 따라 둘 중 필요한 것만 사용 |
| `lastCheck` | 직전 정오답과 한국어 근거 피드백 |
| `optionOrder` 또는 동등한 안정 seed | 선택지의 표시 순서를 재접속 시 유지하는 데 필요할 때만 사용 |
| `seenStories` / `completedStages` (전역 기존 필드) | 03A 선행 충족, 03B 최초 결과 열람과 완료 상태 관리 |

구현 전에는 기존 `meaning-links/1`가 읽기 전용 task·선택지 셔플·직접 타깃 선택을 어떻게 정규화하는지 코드와 대조한다. **필드가 이미 있는데 새로운 별도 저장 구조를 중복 생성하지 않는다.** 새 스키마가 필요하다면 이 문서와 마이그레이션 검사를 먼저 수정한다.

- 최초 완료에서 `academic-tower-turn-03b-ran-village`만 `completedStages`에 추가한다. `academic-tower-turn-foundation`을 건드리지 않는다.
- 결과 story는 첫 완료에 한 번만 자동 연결하며 나중에 별도 재열람한다. 03B 완료 뒤 결과 story가 아직 읽히지 않았으면 재진입 시 결과 확인을 우선하고 스테이지를 새로 풀게 하지 않는다.
- 미완료 중단·새로고침은 읽던 내부 과제로 되돌아간다. 원본·뜻 조회는 자유롭게 다시 열 수 있다. 오답 미확정 선택도 유효한 경우 유지한다.

- 재플레이는 최초 결과·어휘 발견·보상·본선 milestone을 재발생시키지 않는다.
- 연구실·여정·월드에서 시작한 플레이의 복귀 위치는 실제 출발 맥락을 유지하되 03B **첫 결과**는 학술탑 허브로 돌아온다.

| 처음 초안의 위험 | 실제 플레이에서 일어나는 일 | 이번 문서의 보완 |
|---|---|---|
| T1의 원본 `boy-now`에 이미 `仍然`을 사용한 정답 문장이 있었다 | 플레이어가 읽기보다 원문을 그대로 복사한다 | 원본은 옛 메모·지금 관찰, 세 보기는 모두 `仍然`을 써서 **지속된 대상**을 가려내게 변경 |
| `突然`까지 맞히게 하면 작은 웃음이 시험으로 끊긴다 | 자연스러운 일상 장면이 채점 노동이 된다 | 읽기 전용 T2 유지, 인물의 소소한 실수를 함께 웃도록 표현 |
| `當然`은 근거 없는 말에만 나왔다 | ‘當然이면 잘못된 주장’으로 오해할 수 있다 | 소년이 도입에서 `當然認得！`라고 자연스럽게 긍정하고, T3에서는 평가 주체·자료의 근거를 구별 |
| `固然`에서 옛 지도와 현재 시장을 한 문장에 단순 결합했다 | 오늘 시장의 거래를 근거로 옛 마을 생활을 확정할 수 있다 | **과거 지도의 표기 + 지금 시장의 별도 목격**이라는 시점 차이를 원문·피드백에 명시 |
| T3와 T5가 같은 `全鎮` 과장을 두 번 선택하게 했다 | 플레이어가 같은 정답 구절을 기억해 클릭한다 | T3는 **쪽지 저자의 당연한 판단**, T5는 **옛 지도가 완전히 무가치하다는 별도 평가**를 수정 |
| T1~T5를 연속 선택 문제로만 만들 수 있었다 | 두 사람이 친해지는 변화가 화면 밖으로 사라진다 | T1·T4에는 연구원이 소년에게 배우는 짧은 반응, T2에는 함께 웃는 순간, T3·T5에는 소년의 자기 표현 |
| 한 과제 뒤 ‘정답 확인’과 ‘대사 읽음 확인’을 잇달아 요구할 수 있다 | 짧은 표현 다섯 개가 불필요하게 길어진다 | 성공 피드백과 인물 반응을 한 화면에 두고 **다음으로 한 번만 이동** |

이 검토는 **문서 원문·의미·입력 흐름을 검토한 것**이다. 브라우저에서 실제로 03B를 플레이해 본 테스트, 완성된 상호작용의 사용성 승인, 원어민 감수 결과로 기록하지 않는다. 기존 본선 저장과 코드 상태는 변경하지 않았다.

### 9.2 이번 단계에서 하지 않을 것

- 본선 01~05나 이미 구현된 03A의 문장·진행·저장 방식을 자동 수정하지 않는다.
- 03B를 04A·본선 후속 연구의 필수 선수로 만들지 않는다.
- ‘방문이 잦다’는 이유로 자유 출입증·연구원 직함·호감도 계량화·상시 동행 캐릭터를 추가하지 않는다.
- 옛 지도 내용을 새로운 거대 왕국사·연대기·실제 역사 고증 사실로 확정하지 않는다.
- 똑같은 다섯 빈칸·객관식으로 다섯 목표어를 일렬 채점하지 않는다.
- 보물 발견, 갑작스러운 위험, 표식 발광으로 감사 방문을 억지 사건으로 바꾸지 않는다.
- 새 월드 지역, 별도 지리 지도 조작, 고정 일자 경과, 음성·듣기 동기화까지 이번 한 편의 필수 구현에 넣지 않는다.
- 도시락 포장·조리·구매·소모·보상 시스템을 새로 만들지 않는다. 도시락은 도입과 결말에만 등장하는 이야기 소품이다.
