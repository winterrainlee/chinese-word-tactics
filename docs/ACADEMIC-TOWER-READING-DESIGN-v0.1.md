## 1. 학술탑의 역할

> 표지어를 만났을 때, 지금까지 읽은 내용을 어떻게 처리하고 이어지는 내용을 어떤 방향으로 받아들여야 하는지 알아차린다.

학술탑은 단어의 뜻을 맞히는 장소가 아니라 중국어를 앞에서부터 이해해 나가는 방법을 연구하는 장소다. 문장 내부의 관계에서 문장 사이, 긴 문단의 관계로 넓어진다. 독자는 앞의 내용을 기억하되 매번 문장 처음으로 되돌아가 번역을 다시 조립하지 않아도 되도록 연습한다. 이는 자연스러운 재독 자체를 금지하거나 속도로 학습을 평가한다는 뜻이 아니다.

표지어는 접속사라는 품사명이 아니라 **독해에 유용한 의미 단서**라는 작업상의 개념이다. 접속사·부사·짝구문·문장 끝 표현도 포함한다. 仍然처럼 상태의 지속을 알리는 표현도 대상이다. 독해 중 형성되는 기대와 실제 사실, 화자의 주장, 조건·범위·가능성을 구별한다. 표지어 하나만으로 사실 여부나 전체 문장의 정확한 결론을 확정하지 않는다.

학술탑에서는 검토된 문장과 실제 의미 조작을 통해 이 단서를 경험한다. [읽기 연습의 원래 목표](MY-TEXT-READER-PLAN-v0.1.md)는 외부 원문에서 단서를 알아보고 정방향으로 읽는 것이다. 두 기능은 학습 목적을 공유하되, 학술탑은 지도·설명·연습을 제공하고 읽기 연습은 원문을 읽도록 돕는다. 자동 해석·문장 전체 번역이나 자동 의미 분할 기능을 이번 개편에 추가하지 않는다. 청취에도 같은 읽기 습관을 활용할 수 있지만 실제 듣기 개선은 별도 검증 대상이다.

## 2. 표현 선정 원칙

1. 새 표현을 만났을 때 **독자가 다음에 해야 할 의미 처리**를 구체적으로 설명할 수 있는가?
2. 이미 읽은 정보, 이어지는 내용, 화자의 판단, 조건·범위·초점 중 무엇에 작용하는가?
3. 그 차이를 실제 중국어 문장 속에서 관찰하거나 조작할 수 있는가? 해당 표현을 제거·교체했을 때 어떤 오독이 생기는가?
4. 기존 학술탑 표현과 자연스럽게 재사용·비교할 수 있는가? 같은 한자라는 이유만으로 편입하지 않는다.
5. 일반 의미와 문맥에서의 쓰임을 구분한다. 유의어가 모두 자연스러운 문장에서는 하나만 정답으로 만들지 않는다.

공통 한자(然·而·是·於 등)는 발견과 탐색의 계기다. 글자 풀이가 전체 단어의 의미를 기계적으로 결정한다고 가르치지 않는다. 실제 수업에서 만난 표현 및 기존 공식 어휘 자료를 참고하되, TBCL 등급만으로 채택·배제하지 않는다. 출처·발음·등급과 게임 편집층을 분리한다. 목표어·비교어·서사 노출어를 분리해 목록과 생애주기를 관리한다. 기본적으로 한 스테이지 신규 목표어 1~3개, 한 과제의 신규 중심어 1~2개를 넘기지 않으며 예외는 이유를 기록한다.

### 내부 기능 지도 (사용자에게 분류명 암기 요구 없음)

| 의미 관계 | 독해 중 하는 일 | 대표 표현 |
|---|---|---|
| 전제·조건·대안 | 전제를 받아들이거나 조건을 열고 해당 경우의 귀결을 기다린다. | 既然…就…、如果…就…、不然、要不然、除非…不然… |
| 순서·귀결·진전 | 다음 사건인지, 이유에서 이어지는 결과인지, 다음 단계인지 구분한다. | 然後、因而、從而、進而 |
| 첨가·전환·대체 | 앞의 사실을 유지하며 정보를 더하거나 기대·논점·설명을 바꾼다. | 而且、然而、卻、反而、不是…而是… |
| 양보·지속 | 양보한 내용을 유지하고 결론을 기다리거나 특정 상태가 이어짐을 읽는다. | 雖然、固然、縱然、仍然、依然 |
| 예상·실제·판단 | 결과를 예상과 비교하거나 화자의 판단으로 읽는다. | 果然、竟然、居然、顯然、當然、必然 |
| 범위·초점·재진술 | 어디까지 주장하는지, 무엇을 중심에 놓는지, 앞의 말을 어떻게 풀어 쓰는지 읽는다. | 而已、不盡然、未必、對於…而言、相較於、換句話說 |

분류는 배타적이지 않다. 反而는 기대와 어긋나는 실제 결과와 방향 전환을 함께 다룬다. 因而·從而는 문맥에 따라 겹치며, 進而가 언제나 시간적으로 다음 사건을 뜻하는 것은 아니다. 향후 목적·예시·화제 전환·비교 기준 등은 실제 사용처에서 필요한 범위만 확장한다. 전체 후보 자료의 분류를 이 표로 덮어쓰지 않는다.

## 3. 공통 게임 설계: 독해 과정에 작용하는 세 가지 조작

| 공통 의미 행동 | 플레이어가 경험하는 판단 | 시각·조작 후보 |
|---|---|---|
| 방향 잡기 | 뒤에 붙는 내용의 조건·관계를 예상한다. | 경로, 조건 갈림, 두 구절 연결 |
| 의미 유지·갱신 | 어떤 정보는 그대로 남고, 어느 해석만 바뀌거나 제한되는지 파악한다. | 유지/변화 비교, 선택적 정정, 범위 강조 |
| 정보 성격 파악 | 예상·실제·주장·근거·추론·가능성을 혼동하지 않는다. | 예상과 실제의 짝, 원본과 해석 구분, 근거와 판단 연결 |

세 행동은 기믹의 공통 언어다. 모든 표현을 같은 화살표, 같은 빈칸, 같은 선택 화면으로 표현한다는 뜻이 아니다. 원문, 보고 메모, 옛 지도, 현장 관측 등 연구의 소재가 조작의 모양을 정한다. 정방향 읽기 시각화는 의미 단서이지 정답 자체가 아니다. 앞뒤 순서가 이미 명확하면 재배치하지 않고, 단순히 주어진 내용을 다시 누르는 작업을 없앤다. 드래그를 필수로 요구하지 않는다. 현재 UI의 원본/작업 구분과 간결한 정보 위계, 모바일 탭·뜻 조회·복귀 계약을 유지한다.

### 3.1 표지어의 위치와 작동 시점

| 작동 시점 | 예 | 관찰 설계 |
|---|---|---|
| 관계를 여는 순간 | 既然、雖然、縱然 | 앞의 전제·양보를 기억하고 대응하는 결론을 기다린다. |
| 관계가 전환되는 순간 | 然而、卻、反而、而是 | 앞의 사실/예상/부정한 설명을 구분해 뒤를 받는다. |
| 상태·판단을 표시하는 순간 | 依然、仍然、顯然、果然 | 뒤의 서술을 지속·판단·예상 확인 등으로 읽는다. 구체적인 대상과 내용은 원문에서 확인한다. |
| 이미 읽은 범위를 조절하는 순간 | 而已、不盡然 | 해당 진술이나 앞선 주장에 적용되는 제한을 읽는다. |
| 떨어진 표현이 호응하는 순간 | 既然…就…、不是…而是… | 앞에서 열린 관계를 뒤에서 닫는다. 다른 표지어가 사이에 있어도 관계를 유지한다. |

표지어에서 의도적으로 멈추는 방식은 **초기 관찰용 선택적 기믹**이다. 반드시 문장 전체를 가리거나 모든 표지어에서 답하게 하지 않는다. 이미 읽은 중국어는 자연스러운 순서로 남긴다. 뒤의 내용이 있어야 판단할 수 있는 문제는 필요한 정보를 제공한다. 문장 끝 표현에 미래의 내용 예측을 강요하지 않는다.

### 3.2 의미를 고르는 것과 사건을 맞히는 것을 구분한다

예: `先把窗戶關上，不然……`

- 공개 전에는 창문을 닫지 않은 경우의 결과가 이어진다는 관계만 묻는다.
- 이후 `雨水會淋濕桌上的地圖。`를 공개해 어떤 조건에 붙는 결과인지 확인한다.
- 창문을 닫았을 때의 결과가 문장에 없으면 새 사실로 확정하지 않는다.
- 既然의 전제는 화자가 받아들인 상황이지 무조건 검증된 객관적 사실이라는 뜻이 아니다. 如果도 이미 알려진 사실을 조건으로 제시할 수 있다.
- 依然·仍然은 특정 상태가 계속된다는 뜻이다. 반드시 큰 변화나 장애가 있었을 필요는 없다.
- 顯然·必然·當然은 화자의 판단을 표시할 수 있지만 진실이나 실제 발생을 보증하지 않는다.
- 不盡然은 전면 부정을 뜻하지 않는다. 不是…而是…도 특정 설명·초점의 정정이지 앞에 나온 모든 사실의 삭제가 아니다.

피드백은 정답을 반복하는 대신 어떤 정보를 남겼고 무엇을 잘못 연결했는지 알려 준다. 예측한 의미 관계와 공개된 실제 문장, 상황 자료를 함께 확인한다. 게임에서 필요한 사실은 문장이나 관찰 자료로 근거를 제시한다.

## 4. 한 연구의 학습 순환

| 단계 | 학습 경험 | 도움의 수준 |
|---|---|---|
| 발견 | 연구원 설명 또는 짧은 문장으로 표지어의 역할을 관찰한다. | 필요한 뜻과 관계를 보여 준다. |
| 조작 | 방향을 잡고, 유지/갱신하거나 판단의 성격을 구별한다. | 의미 판단만 남기고 필요한 선택만 받는다. |
| 대비·전이 | 앞 내용이나 표지어를 바꾼 새 문맥에서 같은 역할을 적용한다. | 같은 답 위치나 표현 이름만 외워서 해결하지 않도록 한다. |
| 복합 | 두 개 이상 표지어가 얽힌 문장에서 조건·범위·기대를 함께 처리한다. | 판단에 꼭 필요한 지점만 조작한다. |
| 연속 독해 | 완성된 원문을 자연스럽게 읽고 해석 또는 상황 판단을 한다. | 기호·강제 멈춤을 줄인다. |

연구별 단계 수는 고정하지 않는다. 짧은 연구를 과제 목록처럼 부풀리지 않는다. 사용자가 뜻을 조회하는 데 불이익을 주지 않는다. 시간 제한, 숙련도 점수, 클릭 횟수 보상은 도입하지 않는다. 최종 성공의 의미는 표지어의 명칭 암기가 아니라 새로운 문장에서 의미 관계를 읽고 판단하는 것이다. 실제 장문·듣기 능력 향상을 구현 성공만으로 주장하지 않는다.

## 5. 기존 연구 전체에 대한 적용 지도

| 연구 | 현행 주제 / 핵심 표현 | 개편 시 강화할 경험 | 보존할 것 |
|---|---|---|---|
| 01 | 卻 | 기대와 어긋나는 뒤 사실을 받고 잘못된 추론만 수정 | 두 사실 보존, 서로 다른 두 과제 |
| 02 | 然而 | 앞의 사실과 뒤의 전환을 함께 읽고 보고의 범위를 갱신 | 원본 기록·보고 초안 |
| 03 (본선) | 果然、竟然 | 기대와 실제의 일치/이탈을 읽음. 긍정/부정 결과와 구별 | 네 가지 예상/실제 사례 |
| 03A | 然 발견, 既然、不然 등 | 전제·조건·순서의 갈림 | 색인 발견 이야기, 03A 안정 ID |
| 03B | 仍然、突然、當然、固然、不盡然 | 양보·전환·지속을 중심으로 재편 | 도시락 방문, 옛 지도, 인물 관계와 기존 완료 |
| 03C (제안) | 미구현 | 예상·실제·추론·확신과 판단의 범위 | 03 본선 복습 및 03B 판단 과제의 재사용 검토 |
| 04 | 反而 | 실제 결과가 어떤 기대에 어긋나는지 읽음 | 예상 대신 생긴 결과·역방향 관찰 |
| 04A | 而且、然而、反而、而是、而已、從而、因而、進而 | 추가·전환·정정·범위 제한·결과·진전을 현장 자료와 연결 | T1~T5 현장 탐색, 수로 D 발견 순서와 독립 상태 처리 |
| 05 | 종합 연구 | 여러 표지어를 통합해 안전 조건·가능성·전달 판단을 읽음 | 전체 기록 재독, 공방에 전달할 판단 |

01~05의 본선과 곁가지 연구 구별을 유지한다. 03A~C는 본선 03의 강제 후속 단계나 04의 필수 선수가 아니다. 기존 03B는 03A 결과 이야기 및 장터 M4 후일담, 04A는 본선 04 및 큰비 조건을 유지한다. 03C의 구체적인 해금은 P1 G0에서 결정하며 기존 세계 설정과 선수 그래프를 변경하지 않는다.

## 6. P1 — 03 시리즈 시험 설계 방향 (P0 기준)

2026-11-25 후속: [P1 독립 시험판 G0~G2 사양 및 구현 범위](ACADEMIC-TOWER-READING-P1-TEST-v0.1.md)에 16개 시험 기록과 의미 조작을 구체화했다. 본 문서의 아래 제안은 상위 기준이며 실제 시험판과 검수 상태는 해당 문서를 따른다.

목적: 단어 몇 개를 더 추가하는 데 그치지 않고 §3의 세 의미 행동을 실제 플레이로 검증한다. 아래 묶음과 작업명은 제안이며 최종 문장·대사·신규 ID·세부 문항 수는 G0~G2에서 확정한다. 본선 03 자체의 개편은 P2에 둔다.

### 03A — 문장이 갈라지는 길 (가칭)

- 중심: 既然、不然. 要不然은 비교/확장 후보. 비교: 然後、如果、就、否則 등.
- 기존 색인과 연구원의 짧은 然 설명은 남긴다. 나머지 일곱 표현 관찰을 그대로 반복하는 대신 조건·전제·순서를 가르는 데 집중한다.
- 기존 불필요한 구절 재배치 금지 원칙을 지킨다. 不然에서 앞으로 이어질 조건을 고르고 뒤를 확인하는 방식, 既然에서 전제를 받아들이고 판단을 잇는 방식, 이미 완성된 문장 비교가 후보이다.
- 검수: 不然을 然後로 오독하지 않는가? 既然/如果를 단순히 참/거짓으로 분류하지 않는가? 예측 단계에서 사건의 구체 내용을 맞혀야 통과하는 문제는 없는가?

### 03B — 변하는 것과 남는 것 (가칭)

- 중심: 仍然、依然、固然、縱然. 비교: 雖然、然而、卻、還是(지속 용법), 即使 등.
- 기존 도시락 방문과 옛 지도, 소년의 현재 경험, 두 인물의 관계 발전을 유지한다. 기존 T1의 길 이용 지속과 T4의 인정·보완 과제를 발전시킨다. 기존 突然 종이 사건은 이야기 속 자연스러운 노출로 유지하며 별도 강제 시험을 만들지 않는다.
- 예시: `雖然市集的位置已經改變，那條路依然有人走。` (가상 연습 문장. 실제 물길마을 장터가 이전했다는 설정 확정 아님.) 양보된 변화와 계속되는 길 이용을 함께 남긴다.
- 仍然·依然은 해당 문맥에서 바꾸어 쓸 수 있으면 동등하게 처리한다. 縱然의 가정적 양보와 雖然/固然의 인정 용법을 비교하되 기계적 절대 규칙은 피한다.
- 기존 T3 當然·T5 不盡然의 판단 활동 및 T6의 재구성을 03C와 함께 검토한다. 기존 03B의 서사 완결성을 해치거나 03C를 강제 방문해야 이해되게 만들지 않는다.
- 검수: 지속된 대상만 남기는가? 변화한 사실도 유지하는가? 두 표지어가 협력하는 문장을 읽을 수 있는가?

### 03C — 어디까지 그렇게 말할 수 있을까 (가칭)

- 중심: 顯然、當然、必然、不盡然. 본선 03의 果然、竟然은 복습, 居然·未必는 비교 후보. 偶然·自然은 필요한 대비 문맥이 있을 때만 후보로 둔다.
- 관찰 자료와 화자의 예상·판단·확신을 구분하며, 근거와 주장 사이의 방향을 읽는다. 03B의 판단 수정 기믹을 재사용할 수 있다. 신규 이야기 소재와 구체적인 진입 조건은 미정이다.
- 예시: `二十年前的照片裡已經有這座橋了。顯然，這座橋不是最近才蓋的。` (가상 연습 문장.) 사진 속 관찰과 그에 따른 추론을 구분한다. 顯然의 사용 자체가 판단을 참으로 보증하지 않는다.
- 검수: 果然/竟然을 결과의 좋고 나쁨으로 선택하지 않는가? 必然의 진술을 이미 일어난 사실로 해석하지 않는가? 不盡然을 앞말의 전면 부정으로 해석하지 않는가?

突然·忽然 등 사건 발생 표지는 맥락상 유용하면 자연스럽게 노출하고, 이번 핵심 방향 연구에서는 후순위로 둔다. 全然은 범위 비교 후보, 毅然·坦然·茫然 등 일반 태도·상태 어휘는 별도 어휘 학습 후보로 둔다.

## 7. 구현 경계와 데이터 계약 (P1에서 검증할 후보)

현행 `src/academic-tower-content.js`는 안정 stage/task ID, 원문, 작업 및 판정 자료를 정의한다. `src/academic-tower-runtime.js`의 `config.tasks` 경로는 여러 연구가 쓰는 meaning-links 상태·판정·렌더링을 제공한다. 03B에는 별도 표시 및 이야기 처리가 있고 04A는 `src/academic-tower-er-04a-runtime.js`의 독립 현장형 상태 처리를 갖는다.

공통화의 우선 범위는 의미 단서 표시·선택적 공개·관계 시각화·근거 피드백이다. 기존 과제에 선택적으로 적용하고 실제 두 번째 사용처를 통해 필요한 부분까지만 분리한다. 기존 상태 처리기나 모든 연구 화면을 한 엔진으로 강제 통합하지 않는다. 정적 Pages, Vanilla JS/CSS와 기존 이야기 런타임을 유지한다.

신규 과제 사양은 최소한 다음을 명시한다.

| 항목 | 내용 |
|---|---|
| 안정 ID | 연구, 작업, 원문 구간, 답안의 식별자 |
| 원문·출처 | 번체 중국어의 실제 순서, 상황 자료, 사실/주장/예상의 출처 |
| 표지어·작용 대상 | 관찰할 표현의 위치와 관계가 적용되는 구절·조건·범위 (짝구문도 가능) |
| 의미 행동 | 방향 잡기, 유지/갱신, 정보 성격 파악 중 실제로 필요한 조작 |
| 공개·판정 | 처음 보이는 내용, 뒤 구절 공개 시점, 정답과 허용 대안, 구체적 오독별 피드백 |
| 재독·진행 | 원문 재독, 뜻 조회, 중단/재개, 재플레이, 이야기 연결 및 호환 정책 |

정확한 구간은 과제 데이터에서 저작자가 명시한다. 학술탑의 문맥별 주석을 읽기 연습의 문자열 규칙으로 자동 이전하지 않는다. 읽기 연습의 사전 변경이 필요하면 실제 글의 오탐·누락을 독립 검증한다. 새 공식 어휘 정보는 해당 자료에서 확인한 뒤 게임 편집층에 등록한다.

기존 완료·보상·이야기 이력·월드 및 다른 연구의 진행은 보존한다. 진행 중 저장은 task ID·사양 버전과 의미 행동의 동일성을 확인해 호환 가능한 부분만 옮긴다. 새로운 판단을 과거 답안으로 자동 통과시키지 않는다. 호환 불가 시 해당 연구의 안전한 작업 지점으로 복귀시키되 완료 이력을 되돌리지 않는다. 재플레이는 이전 완료 상태와 분리한다.

## 8. 공통 검수 기준

다음은 P1의 G2/G4/G6 및 후속 연구에 공통 적용한다. 개별 스테이지 문서에는 구체적인 테스트와 기대 결과를 추가한다.

- **의미:** 원문만으로 답할 수 있다. 표지어가 바뀌었을 때 실제 의미도 바뀐다. 앞 사실을 취소하거나 조건·범위·화자의 확신을 과장하는 오독을 판별한다. 자연스러운 유의어 대안은 허용하거나 질문을 고쳐 유일성을 확보한다.
- **정방향:** 조작 전 뒤의 답이 유출되지 않는다. 반대로 해석에 필요한 정보까지 숨기지 않는다. 공개한 원문과 실제 관계가 일치한다. 끝 단계에서는 완성 원문을 별도 해석 UI 없이 읽을 수 있다.
- **최소 행동:** 글자·구절을 정답 위치에 다시 복사하는 일은 요구하지 않는다. 똑같은 구조에 단어만 교체한 연속 퀴즈를 피한다. 조회·실수·재시도는 불이익 없이 제공한다.
- **전이:** 새 문맥, 순서/조건 대비, 기대와 어긋난 좋은 결과·일치한 나쁜 결과, 복합 표지어와 판단 범위를 확인한다. 답을 기억해도 의미를 다시 사용할 수 있도록 한다.
- **시각·모바일:** iPhone 13 mini Safari 세로 기준과 기존 뷰포트 테스트를 확인한다. 중국어 가독성, 44px 탭 영역, safe-area, 원본/작업의 위계, 좁은 화면 줄바꿈 및 갑작스러운 레이아웃 이동을 점검한다. 의미 차이를 색 하나로만 전달하지 않는다.
- **진행:** 최초·늦은 방문, 기존 해금, 중단/재개, 재플레이·기록, 백업 복원, 03B/04A의 이야기 분기, 다른 층 진입의 회귀가 없어야 한다.
- **기술:** 실제 구현 후 단위 검사, `node tools/verify-content.cjs`, `node tools/vocabulary-lifecycle-audit.cjs`(목표어·구성 변경 시), 브라우저 회귀와 시험판/Pages 하위 경로 검사를 수행한다. 자동검사, 배포, 사용자 실기기 승인과 학습효과 검증은 서로 구별한다.

실기기 검수 질문: 표지어를 만나면 해석 방향이 먼저 떠오르는가? 중국어 원문보다 한국어 보기·도식에 의존하는가? 버튼 없이 읽는 마지막 기록에도 배운 관계를 적용할 수 있는가? 기존 기능보다 멈춤/복귀가 과도해졌는가? 검수 결과에 따라 기믹을 줄이거나 바꾼다.
