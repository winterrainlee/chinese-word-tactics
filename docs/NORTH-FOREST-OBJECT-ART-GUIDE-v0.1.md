## 1. 목적

북쪽 숲은 다른 지역보다 **그림 자체가 학습 정보가 되는 비중이 높다.**

특히 F4~F7은:
- 비슷한 식물의 색·모양 차이
- 적합한 재료의 길이·굵기 차이
- 서로 다른 흔적의 종류
- 마지막 흔적 근처의 조사 대상

을 실제로 보고 구별해야 한다.

따라서 북쪽 숲 자산의 목표는 “예쁜 숲 그림”보다:

> **작은 모바일 전술판에서 비슷한 것은 비슷하게, 다른 것은 정확히 구별되게 그린다.**

에 둔다.

## 2. 최우선 원칙

### 2.1 실루엣이 먼저다

한 칸 크기로 줄였을 때도 오브젝트의 종류를 알아볼 수 있어야 한다.

- 표식은 나무·바위와 다른 실루엣
- 꾸러미는 덤불과 다른 덩어리
- 손수레는 일반 장애물과 다른 윤곽
- 흔적은 각각 형태가 겹치지 않게

세부 질감은 실루엣 판별을 방해하지 않는 범위에서만 사용한다.

### 2.2 색만으로 구별하지 않는다

색은 학습 정보로 사용되지만 색 하나만 정답 단서가 되어서는 안 된다.

예:
- 深綠色 / 淺綠色 → 색 차이
- 長 / 短 → 길이 차이
- 尖 / 圓 → 잎 끝 실루엣 차이
- 粗 / 細 → 줄기 굵기 차이

색각 차이, 화면 밝기, 작은 렌더 크기를 고려해 형태·크기·텍스트 정보를 함께 제공한다.

### 2.3 정답만 화려하게 만들지 않는다

정답 오브젝트가 장식적으로 더 예쁘거나 밝으면 단어를 읽지 않고도 답을 고를 수 있다.

특히:
- F4 정답 식물
- F5 적합 재료
- F6 관련 흔적
- F7 꾸러미

는 정답 여부가 시각적 강조가 아니라 **학습 정보의 조합**으로 드러나야 한다.

### 2.4 같은 계열 자산은 하나의 기본형에서 변형한다

F4 식물 후보를 네 종류의 전혀 다른 식물로 만들지 않는다.

한 식물 계열을 바탕으로:
- 색
- 잎 길이
- 잎 끝 모양

만 바꾼다.

그래야 플레이어가 정말 特徵 / 相似 / 不同 / 分辨을 사용한다.

## 4. F2~F3 표식 자산

### 필요한 자산

1. 기본 나무 표식
2. 잎에 일부 가려진 상태
3. 방향 4종
   - 위
   - 아래
   - 왼쪽
   - 오른쪽
4. 회전 가능한 표지판 상태

### 반드시 보여야 하는 특징

- 방향은 작은 화살표 아이콘보다 **표지판 몸체 자체가 어느 쪽을 가리키는지** 읽히게 한다.
- 한 칸 크기에서도 좌/우 방향이 혼동되지 않아야 한다.
- 가려진 상태는 완전히 숨기지 않고 “무언가 가려져 있다”는 사실은 보여야 한다.
- 잎을 젖힌 뒤에는 방향 변화가 분명해야 한다.
- F3에는 정답 방향을 알려 주는 정상 표식 자산을 따로 배치하지 않는다.
- F3의 장터 길은 표지판 옆에서 목적지 방향으로 실제 이어지는 길의 실루엣이 읽혀야 한다.

### 피할 것

- 방향마다 색을 다르게 해 색으로 정답을 암시
- 표지판에 지나치게 긴 글자 표기
- 배경 나무와 비슷한 갈색 실루엣으로 묻히는 것

## 5. F4 식물 변형 세트

F4는 북쪽 숲 아트에서 가장 중요한 세트다.

### 기본 원칙

한 식물의 동일 계열 변형으로 만든다.

기본 구조:
- 잎 3~5장
- 중앙 줄기
- 위에서 보거나 약간 사선으로 본 형태
- 타일 안에서 잎 길이와 끝 모양이 읽히는 크기

### 견본

목표:
- 深綠色
- 長
- 尖

견본 그림은 F4에서만 사용한다. F5에는 정답 외형을 미리 보여 주는 견본 그림을 재사용하지 않는다.

### 후보 A — 정답

- 진한 초록
- 긴 잎
- 뾰족한 끝

### 후보 B

- 진한 초록
- 긴 잎
- 둥근 끝

### 후보 C

- 연한 초록
- 긴 잎
- 뾰족한 끝

### 후보 D

- 진한 초록
- 짧은 잎
- 뾰족한 끝

### 제작 규칙

- 잎 개수와 전체 배치는 최대한 비슷하게 유지한다.
- B는 잎 끝 곡률만 분명하게 다르게 한다.
- C는 형태는 A와 같고 밝기/채도 차이를 둔다.
- D는 잎 비율을 짧게 만들되 다른 특징은 A와 동일하게 유지한다.
- 정답 A만 더 풍성하거나 대칭적으로 만들지 않는다.
- 정답 확인 뒤 실제로 챙긴 상태가 보이도록 해당 군락의 표본 하나가 줄어든 상태 또는 작은 소지 아이콘을 둔다.

### 검수

128px 이상의 원본만 보고 통과시키지 않는다.

실제 판 크기 또는 그보다 작은 썸네일에서:
- A/B의 尖 / 圓 차이
- A/C의 深 / 淺 차이
- A/D의 長 / 短 차이

가 각각 읽혀야 한다.

## 6. F5 재료 변형 세트

F5는 식물 종류 판별보다 “용도에 적합한 상태”를 읽는 판이다.

F5 목표 UI에는 `長 · 細 · 生長在水邊 · 兩根`의 텍스트 작업 지시만 둔다. F4 견본 이미지나 정답 덩굴 실루엣은 표시하지 않는다.

### 핵심 특징

조건:
- 長
- 細
- 生長在水邊

### 자산 후보

#### 적합 재료 A/C
- 길다
- 가늘다
- 물가 군락

#### 부적합 B
- 길다
- 굵다
- 물가

#### 부적합 D
- 짧다
- 가늘다
- 숲 안쪽

### 시각화

- 長/短은 줄기의 실제 길이 비율로 표현
- 粗/細는 줄기 폭으로 표현
- 水邊/林地는 오브젝트 자체 색보다 **주변 지형**으로 표현

즉 生長 위치는 식물 아이콘 내부에 물방울 마크를 붙이지 않는다.
판의 공간 관계를 읽게 한다.

## 7. F6~F7 흔적 자산

### 핵심 세트

#### 파란 실

- 짧은 가는 실
- 나뭇가지나 덤불에 걸린 형태
- 파란색은 분명하지만 네온색처럼 튀지 않음
- 가까이 조사했을 때 더 잘 보이도록 확대/정보 시트 사용 가능

F6의 `마지막으로 본 위치`는 파란 실 자산을 반투명하게 재사용하지 않는다. 눌린 풀과 흙으로 된 중립 위치 마커를 사용해 실제 파란 실 흔적과 역할을 분리한다.

#### 동물 발자국

- 작은 발바닥 또는 발굽 자국의 반복
- 진행 방향이 느껴지는 배열
- 수레 자국과 절대 혼동되지 않게

#### 수레바퀴 자국

- 평행한 두 홈 또는 반복된 바퀴 무늬
- 길 위에 길게 이어지는 형태
- 하나의 아이콘보다 지형에 남은 흔적처럼 보이게

#### 끌린 자국

- 바닥을 스친 불규칙한 선
- 작은 파란 실 조각을 같은 자산 안에 함께 표시해 분실 꾸러미와의 관련성이 읽혀야 함
- 파란 실은 끌린 선보다 밝거나 굵게 강조하지 않음

### 원칙

흔적은 모두 “조사 가능한 오브젝트 버튼”처럼 떠 있지 않는다.

가능하면:
- 바닥
- 가지
- 덤불

같은 세계 요소에 자연스럽게 남겨 둔다.

선택 가능 상태만 얇은 조사 강조로 표시한다.

## 8. F7 주변 조사 자산

필요한 대상:
- 큰 나무
- 둥근 바위
- 낮은 덤불
- 작은 물길

각 대상은 쉬운 묘사어 복습에도 사용된다.

### 큰 나무

- 타일을 꽉 채우는 수직 실루엣
- 다른 나무보다 명확히 큰 크기

### 둥근 바위

- 원형에 가까운 외곽
- 각진 일반 돌과 구별

### 낮은 덤불

- 넓고 낮은 실루엣
- 꾸러미가 아래에 걸릴 수 있는 빈 공간이 보여야 함

### 작은 물길

- 한두 칸을 지나가는 가는 물 흐름
- 물웅덩이와 혼동되지 않게 방향성이 있어야 함

꾸러미는 처음부터 덤불 밖에 완전히 노출시키지 않는다.

조사 전:
- 일부만 보이거나 완전히 가려짐

추가 흔적 발견 후:
- 덤불 가지 위에 새 파란 실 조각이 나타남
- 아직 꾸러미 전체 형태는 보이지 않음

발견 후:
- 꾸러미 전체 형태 표시

## 9. 파란 끈 꾸러미

### 역할

F6에서 찾는 대상이지만 F7 전까지 직접 보여주지 않는다.

### 외형

- 작고 소박한 천 꾸러미
- 중성적인 천 색
- 파란 끈으로 묶음
- 귀중품 상자처럼 보이지 않음

### 시각 정보

파란 끈은:
- F6의 파란 실 흔적과 연결되지만
- 판 전체에서 멀리서도 번쩍이는 정답 표시가 되어서는 안 된다.

### 상태

1. 정상 꾸러미 reference
2. 덤불 아래 일부 가려진 상태
3. 발견 후 완전히 드러난 상태
4. 플레이어가 소지한 작은 인벤토리 아이콘

## 10. F8 숲길·장애물·손수레

### 작은 손수레

1장 행상 아주머니의 손수레와 계열감을 유지하되 동일한 수레일 필요는 없다.

필수:
- 두 바퀴 또는 명확한 바퀴 구조
- 짐을 실을 공간
- 플레이어 캐릭터와 겹쳐도 식별 가능

### 장애물 가지

- “나무 한 그루가 쓰러졌다” 수준의 대형 장애물보다
- 소년이 실제로 치울 수 있을 법한 굵은 가지 묶음

치우기 전/후 상태가 필요하다.

### 길 상태

숲길은 인접 타일에 따라 실제로 연결되어 보여야 한다.

- 모든 길 타일에 같은 수평 점선을 반복하지 않는다.
- 세로·가로 직선은 진행 방향과 일치시킨다.
- 모서리와 갈림은 연결된 통로 형태로 그린다.
- 마른 길의 자갈·흙 알갱이는 방향 없는 질감으로 사용한다.
- 바퀴 자국을 넣는다면 직선과 굽이에 맞춰 방향을 바꾼다.

#### 乾

- 기본 흙길
- 비교적 균일한 표면

#### 濕

- 더 어두운 지면
- 작은 물기/진흙 표현
- 색뿐 아니라 반사·웅덩이·질감 차이 추가

#### 寬 / 窄

- 타일 아이콘이 아니라 실제 통로 폭으로 보여준다.

가운데 위험길은:
- 젖음 + 좁음

두 특징이 함께 보여야 한다.

## 11. 정답을 암시하지 않는 시각 규칙

다음을 금지한다.

- 정답만 금색 테두리
- 정답만 더 밝은 명암
- 정답 오브젝트만 큰 크기
- 정답만 더 정교한 그림
- 관련 흔적만 애니메이션
- 오답 후보를 일부러 못생기거나 흐리게 그림

선택 전에는 모두 동일한 시각적 중요도를 갖는다.

조사 후 정보 차이는 텍스트와 실제 형태 차이로 드러낸다.

## 14. 파일·변형 관리 원칙

정확한 파일 형식은 구현 시 확정하되, 의미 있는 변형을 파일명 또는 데이터에서 분명히 식별한다.

예시 개념:
- plant-long-pointed-dark
- plant-long-round-dark
- plant-long-pointed-light
- plant-short-pointed-dark

방향 표식:
- marker-up
- marker-right
- marker-down
- marker-left

흔적:
- last-seen-marker
- trace-blue-thread
- trace-animal
- trace-wheel
- trace-drag
- bush-blue-thread

자산 이름 자체가 플레이어에게 노출될 필요는 없다.
개발 과정에서 변형 혼동을 막기 위한 내부 규칙이다.

## 15. 완료 기준

북쪽 숲 A급 아트 자산은 다음을 모두 만족해야 구현용 완료로 본다.

1. 실제 모바일 판 크기에서 식별된다.
2. F4의 세 특징 차이가 각각 독립적으로 읽힌다.
3. F5의 길이·굵기·생장 위치를 구별할 수 있다.
4. F6의 파란 실 / 동물 발자국 / 바퀴 자국이 즉시 서로 다른 종류로 보인다.
5. F6의 마지막 위치 표식은 파란 실 흔적으로 오인되지 않고, 끌린 자국의 작은 파란 실은 라벨과 일치한다.
6. F7의 새 파란 실은 확인 뒤에만 덤불 위에 나타나며, 꾸러미는 조사 전에는 정답을 노골적으로 드러내지 않는다.
7. F8의 젖은 길과 좁은 길은 색 외의 시각 정보도 가진다.
8. F8의 직선·모서리·바퀴 자국은 실제 경로 방향과 일치하고, 의미 없는 일괄 수평 점선이 없다.
9. 정답 자산이 오답보다 장식적으로 더 강조되지 않는다.
10. 기존 게임의 따뜻하고 조용한 시각 분위기와 충돌하지 않는다.
11. 오브젝트가 일반 UI 버튼처럼 보이지 않는다.
12. iPhone 13 mini 실기기에서 최종 판별 검수를 통과한다.
