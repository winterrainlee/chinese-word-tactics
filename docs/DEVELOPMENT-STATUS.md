# 개발 상황판

마지막 업데이트: 2026-09-11

## 지금 위치

**main은 v0.6 스토리·여정 기반과 길목 G3 `두 갈래 길`까지 구현·배포된 상태다.** G1~G3의 핵심 플레이는 iPhone 13 mini Safari 세로 화면에서 실제 검수를 통과했다. G3에는 최초 본편에서 방문한 초소의 `通行牌`를 저장하고 후속 이야기에서 다시 보여주는 선택 흔적 시스템을 추가했으며, 이 새 이야기 연결만 실기기 재확인이 남아 있다. 1.0 이전에는 main에 빠르게 반영 → GitHub Pages 배포 → iPhone 실기기 확인 → 즉시 수정하는 흐름을 유지한다.

이번 실행 내역은 [v0.6 실행 계획](V0.6-EXECUTION-PLAN.md)에 기록한다. 이전의 상세 기능·지역별 기획 상태는 [v0.5 상황판 보존본](archive/DEVELOPMENT-STATUS-v0.5.md)을 참고한다. 기존 기획서와 `legacy/tutorial-v03.html`은 보존했다.

## 상태 표기

`✅`는 완료, `🧪`는 구현/자동 검사 후 실기기 검수 전, `🟨`는 기획 후 구현 전, `⬜`는 구체화 전, `⏸`는 보류를 뜻한다. 코드 구현과 실기기 통과를 같은 상태로 기록하지 않는다.

## 다음 순서

1. 배포된 버전을 새로 불러온 뒤 여정에서 G3 후속 이야기 `길은 다시 만난다`를 다시 읽는다.
2. 기존 G3 플레이에서 방문했던 초소의 `西哨通行牌` 또는 `東哨通行牌`가 장면에 복구되어 나오는지 확인한다. 두 초소를 모두 방문했다면 두 패가 모두 나와야 한다.
3. 필요하면 G3를 재플레이해 반대 초소를 방문한 뒤 다시 후속 이야기를 읽어, 본편의 최초 통행패가 바뀌지 않는지 확인한다.
4. 통과하면 G4 `바퀴가 걸린 자리`의 `位置 / 周圍 / 障礙` 상세 설계로 넘어간다.

G3 상세 설계는 [GATE-TOWN-G3-DESIGN-v0.1.md](GATE-TOWN-G3-DESIGN-v0.1.md)에 기록했다. 이번 선택 흔적은 범용 인벤토리를 추가한 것이 아니라 **플레이어가 실제로 택한 해결 방식이 바로 다음 이야기 한두 줄에 남도록 하는 작은 stage outcome**이다. 스토리 장면 배경은 기존 지역 아이콘을 재사용한다.
