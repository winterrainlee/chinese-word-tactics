# 개발 상황판

마지막 업데이트: 2026-09-11

## 지금 위치

**main은 v0.6 스토리·여정 기반과 길목 G5 `좁은 성문`까지 구현·배포된 상태다.** G1~G4의 핵심 플레이와 G3 `通行牌` 선택 흔적 후속 이야기까지 iPhone 13 mini Safari 세로 화면에서 실제 검수를 통과했다. G5는 `移動 / 前進 / 後退`를 수레의 실제 위치 변화로 경험하는 첫 movable entity 판으로 구현했고 실기기 검수를 기다린다. 1.0 이전에는 main에 빠르게 반영 → GitHub Pages 배포 → iPhone 실기기 확인 → 즉시 수정하는 흐름을 유지한다.

2026-09-11 세계 구조를 다시 정리했다. 튜토리얼 뒤의 `길목 / 장인골 / 장터`는 더 이상 세 개의 독립 마을이 아니라, 숲과 물길을 지나 도착하는 큰 정착지 **물길마을（三溪鎮）** 안의 세 생활 구역이다. `회의소 / 학술탑`도 별도 도시가 아니라 같은 마을 안의 후속 장소로 본다. `길목` 너머만 변경 방면과 `끝마을` 같은 외부 정착지로 이어진다. 세계관 기준은 [WORLD-v0.6.md](WORLD-v0.6.md)를 우선한다.

현재 런타임 월드맵과 일부 콘텐츠 표기는 아직 v0.5의 독립 지역 구조다. 이번 단계에서는 세계관 문서만 기준을 갱신했고, 지도·표기·진행 구조의 실제 마이그레이션은 별도 구현 작업으로 남긴다. 기존 `gate-*` 같은 내부 식별자는 세계관 명칭과 분리해 당장 바꾸지 않아도 된다.

이번 실행 내역은 [v0.6 실행 계획](V0.6-EXECUTION-PLAN.md)에 기록한다. 이전의 상세 기능·지역별 기획 상태는 [v0.5 상황판 보존본](archive/DEVELOPMENT-STATUS-v0.5.md)을 참고한다. 기존 기획서와 `legacy/tutorial-v03.html`은 보존했다.

## 상태 표기

`✅`는 완료, `🧪`는 구현/자동 검사 후 실기기 검수 전, `🟨`는 기획 후 구현 전, `⬜`는 구체화 전, `⏸`는 보류를 뜻한다. 코드 구현과 실기기 통과를 같은 상태로 기록하지 않는다.

## 다음 순서

1. iPhone 13 mini Safari에서 G5 `좁은 성문`을 실제 플레이한다.
2. 수레를 누르면 조작 대상이 자연스럽게 수레로 바뀌고, 이동 가능 칸의 `前進 / 後退` 표시가 작은 화면에서도 읽히는지 확인한다.
3. 닫힌 문 쪽으로 수레를 움직이려 했을 때 정보만 주고 행동을 확정하지 않는지 확인한다.
4. 수레를 뒤로 빼 문짝이 열릴 공간을 만든 뒤, 소년이 문을 조사·개방하고 수레를 다시 앞으로 보내는 흐름이 자연스러운지 확인한다.
5. 통과하면 G6 `跟隨 / 帶領` follower를 구현하고, G7에서 두 번째 사용처가 생길 때 follower chain으로 확장한다.
6. 길목 G6~G7과 병행하거나 직후에 월드맵·도입 대사·장소 표기를 `물길마을（三溪鎮）` 계층으로 마이그레이션할 세부 구현 계획을 작성한다.

G4~G7 통합 설계는 [GATE-TOWN-G4-G7-DESIGN-v0.1.md](GATE-TOWN-G4-G7-DESIGN-v0.1.md)에 기록했다. G5의 movable entity는 수레 위치, 앞·뒤 이동, 충돌, 목적지 판정만 담당하며 회전·관성·무게 같은 범용 물리 시스템은 도입하지 않는다.

세계관 변경의 상세 기준은 [WORLD-v0.6.md](WORLD-v0.6.md)를 따른다. 기존 `WORLD-v0.5.md`는 구현 당시의 기준선을 설명하는 보존 문서로 취급한다.
