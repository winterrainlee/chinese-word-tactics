# 개발 상황판

마지막 업데이트: 2026-09-12

## v1.0 — 물길마을의 첫 여행

> **단어의 뜻으로 길을 찾는 소년의 첫 장이 완결되고, 물길마을에 돌아올 곳과 다음 의뢰가 생겨 이후의 여행을 계속 확장할 수 있는 버전.**

v1.0은 세계 전체의 완성이 아니다. 다음 두 가지가 함께 성립한 첫 완결판이다.

1. 고향을 떠난 소년이 물길마을의 `길목 / 장인골 / 장터`를 원하는 순서로 경험하고, 주민에게 믿고 일을 맡길 수 있는 여행자로 인정받는다.
2. 여관과 첫 자유 의뢰가 실제로 작동하여, 완결된 첫 장 뒤에도 새 콘텐츠를 자연스럽게 이어 붙일 수 있다.

구역별 판 수는 현재 제작 기준이지 출시 조건 자체가 아니다. 길목·장인골은 7판, 장터는 8판이며, 각 구역에서 **새 단어 소개 → 재사용 → 의미 조합 → 구역의 사건 해결**이 충분히 완결되는지를 우선한다.

아래의 `1.0 필수`와 `출시 품질` 항목이 모두 `✅`가 되어야 v1.0으로 부른다.

## 지금 위치

**main은 v0.6 이야기·여정 기반, 물길마을（三溪鎮） 그림지도, 길목 G1~G7·장인골 W1~W7·장터 M1~M8 전체가 구현된 상태다. 다음 큰 구현 범위는 여관 방 안 상호작용과 세 구역 합류·1장 결말이다.**

- 튜토리얼 6판과 길목 G1~G6은 iPhone 13 mini Safari 세로 화면에서 실제 검수를 통과했다.
- 길목 G7 `북쪽으로 가는 행렬`은 자동·브라우저 검사를 통과했고 실기기 최종 검수를 기다린다.
- 물길마을 그림지도도 자동·브라우저 검사를 통과했고 작은 화면의 시각·터치 실기기 검수를 기다린다.
- 장인골은 W1~W7 전체를 구현·배포했다. 상태 조절, 연결 관계, 조건 판정, 파생 결과, 손상·수리와 종합판을 자동 검증했고 W7 첫 완료에서 `workshop-core`가 기록된다. iPhone 13 mini Safari 공동 실기기 검수는 남아 있다.
- 장터는 M1~M8 전체를 구현했다. 공통 자원 런타임 하나에서 `需求 / 足夠 / 不足` → `數量 / 剩下` → `交換 / 獲得` → `買 / 賣 / 價格` → `價值 / 選擇` → `放棄` → `分配 / 補充` → 종합으로 이어진다.
- 프롤로그 행상인은 중년 여성 `行商阿姨`로 확정했다. 길에서는 작은 목제 손수레 바퀴가 진흙 홈에 빠져 소년에게 자연스럽게 손을 빌려 달라고 부탁하고, 장터 전술판에서는 사람형 NPC로 직접 등장한다. M1 실기기 검토 뒤 소년 현재 칸 강조·중앙 정렬도 수정했고 사용자가 자연스럽다고 확인했다.
- 스토리 화자 아이콘은 행상 아주머니·젊은 병사 길지기·노년 여성 장인·장터지기·여관 주인·수레꾼의 고정 인물 6종과 성별 없는 공용 주민 실루엣을 SVG로 제작해 연결했다. 여성 3명·남성 3명으로 배분했고 내레이터와 정체불명의 목소리는 초상을 표시하지 않는다. 40px 렌더·375×812 브라우저 검사는 통과했으며 iPhone 실기기 검수는 남아 있다.
- M4 `오늘 저녁거리`는 판 내부 `錢幣`만 사용한다. 원자적 구매 뒤 첫 본편 완료에서 `inn-unlocked`가 기록되고, 월드맵 장터 옆에 작은 `客棧 · 여관` 하위 표식이 열린다. 사용자가 M4와 여관 표식을 실기기에서 확인했다.
- M5 `어느 것이 나을까`는 가격 3·용량 2의 작은 바구니와 가격 6·용량 3의 큰 나무상자를 모두 유효한 해법으로 둔다. 최초 선택만 `stageOutcomes`에 저장하며 우열 점수는 없다.
- M6 `짐칸은 하나뿐`은 `放棄`를 폐기가 아니라 이번 차례의 보류로 사용한다. 먼저 보낸 물건과 다음 차례로 미룬 물건을 최초 본편 선택으로 저장하고 재플레이가 덮어쓰지 않는다.
- M7 `제자리로 돌아갈 물건`은 6열 판에서 네 물건을 각 필요 장소에 `分配`하고 부족분을 `補充`한다. 잘못된 목적지에 놓으려 해도 상태를 바꾸지 않는다.
- M8 `장날이 열리기 전에`는 새 규칙 없이 분배·교환·구매를 조합하는 종합판이다. 해결 순서는 저장하지 않고 최종 세계 상태만 본다. 자동검사에서 서로 다른 세 해결 순서를 모두 통과했으며 첫 본편 완료에서 `market-core`가 기록된다. 이때 여관 표식에 작은 나무패가 달린 황동 방 열쇠와 미세하게 따뜻해진 문빛이 생긴다.
- 여관은 M4 뒤의 기본 SVG 표식과 M8 뒤의 방 열쇠 상태까지 구현했다. 방 안 사물 상호작용·첫날 밤/아침 루틴은 별도 여관 MVP 설계를 따라 다음에 연결한다.
- 세 갈래 완료를 계산하는 `gate-core / workshop-core / market-core` 기반은 모두 실제 구현에 연결됐다. 세 구역 합류·사회적 인정 장면은 아직 구현하지 않았다.
- **1.0 전술 UX 공통층을 구현했다.** 상시 목표는 52px 중심의 짧은 안내로 줄이고 전체 목표·규칙은 `뜻`에서 확인한다. 상태 메시지는 판 바로 아래의 행동 피드백으로 강화했고, 장터 대상 패널은 그 아래로 이동했다. 완료 시 모달로 판을 덮지 않고 최종 판 위에 인라인 진행 버튼을 표시하며, 완료 직후 새로고침도 같은 완료 상태로 복원한다. 길목·장인골·장터는 구역 최종 후일담 전까지 월드맵을 강제로 왕복하지 않는다. 375×812 Chromium 자동검수는 통과했고 iPhone 13 mini Safari 최종 확인이 남아 있다.

1.0 이전에는 `main 반영 → GitHub Pages 배포 → iPhone 실기기 확인 → 즉시 수정`의 짧은 주기를 유지한다. 기존 `legacy/tutorial-v03.html`과 이전 기획 보존본은 덮어쓰지 않는다.

2. 성공하거나 실패했을 때 판에서 무슨 일이 일어났는지 납득되는가?

장터 자동검사는 M1~M4의 기존 자원 이동·교환·구매 회귀에 더해 M5 두 선택 모두의 완료, M6 보류 물건 보존, M7 오배송 무변경과 최종 분배, M8 서로 다른 세 해결 순서를 확인한다. 여관 전용 검사는 표식 미노출·M4 기본 표식·M8 방 열쇠 클래스와 접근성 이름·상세 시트·저장 비확장·기존 좌표 유지를 확인한다. M5/M6 최초 선택은 `stageOutcomes`에 한 번만 남고 재플레이가 덮어쓰지 않으며, M8 해결 순서는 저장하지 않는다. M8 첫 본편 완료만 `market-core`를 기록한다. M7·M8의 6열 판은 44px 최소 터치 영역을 유지하도록 별도 폭 규칙을 사용한다.

UX 자동검사는 공통 계약·정적 휴리스틱·375×812 실제 Chromium 렌더를 함께 사용한다. 현재 Node 회귀 172개와 UX 휴리스틱 8개가 모두 통과하며, 이야기 연결부 71개에서 반복 가능성이 높은 9개를 REVIEW 후보로만 보고한다. 자세한 전후 수치와 남은 실기기 항목은 `UX-FLOW-IMPLEMENTATION-2026-09-12.md`를 기준으로 한다.

## 1.0까지의 실행 순서

1. 장터 M5~M8을 iPhone 13 mini Safari에서 한 묶음으로 검수하고, M5 선택의 중립성·M6 보류 의미·M7 6열 터치·M8 순서 자유와 새 목표·상태·대상 패널 배치를 확인한 뒤 장터 1차 묶음을 닫는다.
2. G7 `북쪽으로 가는 행렬`과 물길마을 그림지도의 iPhone 13 mini Safari 검수를 마치고 길목을 닫는다. 같은 구역이 중간 월드맵 왕복 없이 이어지는 리듬도 함께 본다.
3. 장인골 W1~W7을 iPhone 13 mini Safari에서 함께 검수하고 시각·터치·난도·서사 연결과 새 인라인 완료 흐름을 닫는다.
4. 여관 방 안의 최소 생활 상호작용을 붙여 `돌아올 곳`을 실제 플레이 공간으로 만든다.
5. 세 구역을 어떤 순서로 끝내도 같은 1장 결말에 도달하고 작은 선택 흔적만 달라지는지 통합한다.
6. 세 갈래 합류와 사회적 인정 장면을 완성한다.
7. 의뢰 게시판과 첫 자유 의뢰 한 개로 이후 콘텐츠 추가 루프를 실제 검증한다.
8. 저장 내보내기·복원을 추가하고, 전 콘텐츠 제목·대사·단어·힌트를 최종 윤문한다. 이야기 연결 감사의 REVIEW 후보도 이 단계에서 직접 읽고 불필요한 반복만 줄인다.
9. 빈 저장부터 1장 결말과 첫 의뢰까지 목표 기기에서 완주하고, 대표적인 다른 구역 순서·재플레이·복원을 회귀 검사한다.

각 구역은 `기획 → 구현 → Pages 배포 → 실기기 확인 → 즉시 수정` 순서로 닫는다. 여러 판을 장기 브랜치에 묵히지 않는다.

## 1.0 이후

다음 항목은 지도나 이야기에서 방향을 암시할 수 있지만 v1.0 출시를 막지 않는다.

| 범위 | 1.0 이후 역할 |
|---|---|
| 끝마을·변경 방면 | 길목에서 열린 북쪽 길을 따라 물길마을 바깥세계로 확장한다. |
| 학술탑 | 장인골에서 얻은 수리 경험과 글자·말의 힘에 관한 단서를 잇는다. |
| 회의소 | 장터의 `需求 / 分配 / 選擇`을 더 사회적인 문맥으로 확장해, 실제 이해관계 충돌·공동 규칙·`公平`을 다룬다. |
| 여관 확장 | 아침·밤·청소 같은 생활 루틴과 방의 작은 변화를 늘린다. |
| 게시판 확장 | 숲 던전, 채집, 전달, 조사 등 새로 제작한 자유 의뢰를 추가한다. |
| 경제 확장 | 품삯·식사·숙박·여행 준비를 생활감으로 사용하되 반복 파밍과 진행 차단을 만들지 않는다. |
| 단어장·학습 로그·어휘 파이프라인 | 콘텐츠가 충분히 쌓였을 때 복습과 제작 효율을 높이는 방향으로 확장한다. |

일일 갱신, 출석, 에너지, 별점, 랭킹, 랜덤 반복 의뢰, 계정·서버·클라우드 저장, 전체 B1~B2 어휘 수록은 1.0 조건이 아니다. 특히 접속 유도와 반복 파밍을 위한 시스템은 이후에도 기본 방향으로 삼지 않는다.
