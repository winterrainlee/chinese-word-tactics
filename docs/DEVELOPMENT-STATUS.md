# 개발 상황판

마지막 업데이트: 2026-09-11

## 지금 위치

**main은 v0.6 스토리·여정 기반과 길목 G4 `바퀴가 걸린 자리`까지 구현·배포된 상태다.** G1~G3의 핵심 플레이와 G3 `通行牌` 선택 흔적 후속 이야기까지 iPhone 13 mini Safari 세로 화면에서 실제 검수를 통과했다. G4는 `位置 / 周圍 / 障礙` 조사 흐름과 데이터 기반 `contextActions` 일반화를 구현했고 실기기 검수를 기다린다. 1.0 이전에는 main에 빠르게 반영 → GitHub Pages 배포 → iPhone 실기기 확인 → 즉시 수정하는 흐름을 유지한다.

이번 실행 내역은 [v0.6 실행 계획](V0.6-EXECUTION-PLAN.md)에 기록한다. 이전의 상세 기능·지역별 기획 상태는 [v0.5 상황판 보존본](archive/DEVELOPMENT-STATUS-v0.5.md)을 참고한다. 기존 기획서와 `legacy/tutorial-v03.html`은 보존했다.

## 상태 표기

`✅`는 완료, `🧪`는 구현/자동 검사 후 실기기 검수 전, `🟨`는 기획 후 구현 전, `⬜`는 구체화 전, `⏸`는 보류를 뜻한다. 코드 구현과 실기기 통과를 같은 상태로 기록하지 않는다.

## 다음 순서

1. iPhone 13 mini Safari에서 G4 `바퀴가 걸린 자리`를 실제 플레이한다.
2. 수레를 먼저 봐도, 돌/상자를 먼저 봐도 진행이 막히지 않는지 확인한다.
3. 수레 확인 뒤 주변 물체 강조가 과하게 정답을 알려주지 않는지, `수레 살펴보기 / 돌 살펴보기 / 돌 치우기` 버튼 전환이 자연스러운지 확인한다.
4. 돌을 치운 뒤 G4 후속 이야기에서 같은 수레가 좁은 문 앞에 멈추며 G5로 자연스럽게 이어지는지 확인한다.
5. 통과하면 G5 movable entity를 구현한다.

G4~G7 통합 설계는 [GATE-TOWN-G4-G7-DESIGN-v0.1.md](GATE-TOWN-G4-G7-DESIGN-v0.1.md)에 기록했다. G4부터는 G1에서 검증한 단일 상황 행동을 데이터 기반 `contextActions`로 일반화하되, 범용 퀘스트 엔진까지 확장하지 않는다.
