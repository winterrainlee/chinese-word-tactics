# 개발 상황판

마지막 업데이트: 2026-09-10

## 지금 위치

**main은 v0.6 스토리·여정 기반과 길목 G1 `문 안쪽`까지 구현된 상태다.** 1.0 이전에는 main에서 바로 배포하며 빠르게 실기기 확인과 조정을 반복한다. iPhone 13 mini Safari의 G1 실기기 검수는 남아 있다.

이번 실행 내역은 [v0.6 실행 계획](V0.6-EXECUTION-PLAN.md)에 기록한다. 이전의 상세 기능·지역별 기획 상태는 [v0.5 상황판 보존본](archive/DEVELOPMENT-STATUS-v0.5.md)을 참고한다. 기존 기획서와 `legacy/tutorial-v03.html`은 보존했다.

## 상태 표기

`✅`는 완료, `🧪`는 구현/자동 검사 후 실기기 검수 전, `🟨`는 기획 후 구현 전, `⬜`는 구체화 전, `⏸`는 보류를 뜻한다. 코드 구현과 실기기 통과를 같은 상태로 기록하지 않는다.

## 다음 순서

1. iPhone에서 길목을 선택해 G1 `문 안쪽`의 맵 크기, 살펴보기, 같은 문으로 되돌아오는 감각을 검수한다.
2. G1 전후 번체 대사와 한국어 보조 문구를 실제 화면에서 다듬는다.
3. G2 `종소리가 닿는 곳`의 `距離 / 範圍` 판정과 맵을 상세 설계한다.

스토리 장면 배경은 기존 지역 아이콘을 재사용했다. 별도 배경화·행상인 초상화, 지역 상세의 실제 의뢰, 대용사 조건은 이번 범위에 넣지 않았다.
