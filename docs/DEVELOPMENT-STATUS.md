# 개발 상황판

마지막 업데이트: 2026-09-11

## 지금 위치

**main은 v0.6 스토리·여정 기반, 물길마을（三溪鎮） 지도 전환, 길목 G7 `북쪽으로 가는 행렬`까지 7/7 구현·배포된 상태다.** G1~G6의 핵심 플레이는 iPhone 13 mini Safari 세로 화면에서 실제 검수를 통과했다. G7은 새 단어 없이 `路線 / 經由 / 跟隨 / 帶領`과 장애물 판단을 조합하고, G6에서 검증한 follower를 두 대의 작은 행렬로 확장한 종합판으로 구현했으며 실기기 검수를 기다린다. G7 최초 본편에서 고른 초소·경로는 애프터스토리에 흔적으로 남고, 완료 시 `gate-core` milestone을 기록한다. 물길마을 지도는 자동 검사와 Pages 배포를 통과했고 작은 화면에서의 시각·터치 검수를 기다린다. 1.0 이전에는 main에 빠르게 반영 → GitHub Pages 배포 → iPhone 실기기 확인 → 즉시 수정하는 흐름을 유지한다.

2026-09-11 세계 구조를 다시 정리했다. 튜토리얼 뒤의 `길목 / 장인골 / 장터`는 더 이상 세 개의 독립 마을이 아니라, 숲과 물길을 지나 도착하는 큰 정착지 **물길마을（三溪鎮）** 안의 세 생활 구역이다. `회의소 / 학술탑`도 별도 도시가 아니라 같은 마을 안의 후속 장소로 본다. `길목` 너머만 변경 방면과 `끝마을` 같은 외부 정착지로 이어진다. 세계관 기준은 [WORLD-v0.6.md](WORLD-v0.6.md)를 우선한다.

런타임 월드 화면도 새 구조로 1차 전환했다. 기존 세로 카드 목록 대신 세 물줄기와 세 길이 보이는 세로형 마을 지도를 사용하고, `길목 / 장인골 / 장터 / 회의소 / 학술탑 / 끝마을 방면`을 실제 공간 관계에 맞춰 배치한다. 고향은 `小村`, 첫 정착지는 `三溪鎮`으로 표시한다. 기존 `gate-town / workshop-town / market-town` 같은 내부 식별자는 저장·여정 호환을 위해 유지하고 표시층에서 새 세계관 이름으로 바꾼다.

첫 행상인 장면도 새 구조에 맞췄다. 행상인이 소년에게 어디에서 왔는지 묻고, 소년은 `森林那邊的一個小村。`이라고 답한다. 이어서 행상인이 `三溪鎮`의 이름과 세 물줄기, 세 길이 모두 같은 마을로 이어진다는 사실을 설명한다.

이번 실행 내역은 [v0.6 실행 계획](V0.6-EXECUTION-PLAN.md)에 기록한다. 이전의 상세 기능·지역별 기획 상태는 [v0.5 상황판 보존본](archive/DEVELOPMENT-STATUS-v0.5.md)을 참고한다. 기존 기획서와 `legacy/tutorial-v03.html`은 보존했다.

## 상태 표기

`✅`는 완료, `🧪`는 구현/자동 검사 후 실기기 검수 전, `🟨`는 기획 후 구현 전, `⬜`는 구체화 전, `⏸`는 보류를 뜻한다. 코드 구현과 실기기 통과를 같은 상태로 기록하지 않는다.

## 다음 순서

1. iPhone 13 mini Safari에서 G7 `북쪽으로 가는 행렬`을 실제 플레이한다.
2. 소년 → 첫 수레 → 둘째 수레의 2대 행렬이 한눈에 읽히는지 확인한다.
3. 동쪽 길은 장애물 없이 우회하고, 서쪽 길은 돌을 확인·제거하면 통과할 수 있다는 두 해결 방향이 과한 힌트 없이 이해되는지 본다.
4. 초소 경유 뒤 북쪽 `N`에 소년, 바로 뒤에 첫 수레, 그 옆 접근 칸에 둘째 수레까지 들어왔을 때 완료되는 감각이 자연스러운지 확인한다.
5. G7 애프터스토리에서 최초 본편의 서/동 경로 선택이 자연스럽게 한두 줄 남고, 오래된 길표지의 빛과 끝마을 방면 안내가 과하지 않은지 본다.
6. G7가 통과하면 길목 7/7을 실기기 완료로 닫고, 다음 구현 순서를 장인골/장터 중에서 정한다.
7. 별도로 새 **물길마을（三溪鎮） 지도**의 작은 화면 시각·터치 검수도 남아 있다.

G4~G7 통합 설계는 [GATE-TOWN-G4-G7-DESIGN-v0.1.md](GATE-TOWN-G4-G7-DESIGN-v0.1.md)에 기록했다. G7은 G6의 follower 한 칸 규칙을 새 길찾기 없이 두 대의 chain으로 확장한다. 서쪽 장애물은 반드시 쓰는 시험 문제가 아니라, G4에서 배운 해결 수단을 필요할 때 선택할 수 있는 경로 요소로 둔다.

세계관 변경의 상세 기준은 [WORLD-v0.6.md](WORLD-v0.6.md)를 따른다. 기존 `WORLD-v0.5.md`는 구현 당시의 기준선을 설명하는 보존 문서로 취급한다.
