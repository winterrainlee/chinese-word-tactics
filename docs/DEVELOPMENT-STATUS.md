# 개발 상황판

마지막 업데이트: 2026-09-11

## 지금 위치

**main은 v0.6 스토리·여정 기반과 길목 G3 `두 갈래 길`까지 구현·배포·실기기 확인된 상태다.** G1~G3의 핵심 플레이와 G3 `通行牌` 선택 흔적 후속 이야기까지 iPhone 13 mini Safari 세로 화면에서 실제 검수를 통과했다. 길목 후반부 G4~G7은 하나의 생활형 사건으로 통합 상세 설계를 완료했고 구현 전이다. 1.0 이전에는 main에 빠르게 반영 → GitHub Pages 배포 → iPhone 실기기 확인 → 즉시 수정하는 흐름을 유지한다.

이번 실행 내역은 [v0.6 실행 계획](V0.6-EXECUTION-PLAN.md)에 기록한다. 이전의 상세 기능·지역별 기획 상태는 [v0.5 상황판 보존본](archive/DEVELOPMENT-STATUS-v0.5.md)을 참고한다. 기존 기획서와 `legacy/tutorial-v03.html`은 보존했다.

## 상태 표기

`✅`는 완료, `🧪`는 구현/자동 검사 후 실기기 검수 전, `🟨`는 기획 후 구현 전, `⬜`는 구체화 전, `⏸`는 보류를 뜻한다. 코드 구현과 실기기 통과를 같은 상태로 기록하지 않는다.

## 다음 순서

1. [G4~G7 통합 설계](GATE-TOWN-G4-G7-DESIGN-v0.1.md)를 기준으로 G4부터 구현한다.
2. G4에서 길표지 이후 두 번째 실제 상호작용 대상을 얻으므로 `interaction-runtime.js`를 최소한의 `contextActions` 구조로 일반화한다.
3. G4 구현 → Pages → iPhone 검수 후 G5의 movable entity를 추가한다.
4. G5 검수 후 G6 follower를 추가하고, G7에서 두 번째 사용처가 생길 때 2대 follower chain으로 확장한다.
5. G7 완료 시 `gate-core`를 기록하고 `邊境村`을 이야기상 강한 추천 목적지로 연결한다.

G4~G7은 한 대의 짐수레와 같은 마부를 중심으로 **조사 → 수레 조작 → 인도 → 작은 행렬**로 이어진다. 제목 `해 지기 전`은 이야기 분위기만 만들며 실제 시간 제한이나 턴 제한은 도입하지 않는다.
