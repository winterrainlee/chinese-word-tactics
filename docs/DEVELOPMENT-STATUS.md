# 개발 상황판

마지막 업데이트: 2026-09-11

## 지금 위치

**main은 v0.6 스토리·여정 기반과 길목 G3 `두 갈래 길`까지 구현·배포된 상태다.** G1 `문 안쪽`과 G2 `종소리가 닿는 곳`은 iPhone 13 mini Safari 세로 화면에서 실제 플레이 검수를 통과했다. G3는 Pages 자동 검사와 배포를 통과했고 실기기 검수를 기다린다. 1.0 이전에는 main에 빠르게 반영 → GitHub Pages 배포 → iPhone 실기기 확인 → 즉시 수정하는 흐름을 유지한다.

이번 실행 내역은 [v0.6 실행 계획](V0.6-EXECUTION-PLAN.md)에 기록한다. 이전의 상세 기능·지역별 기획 상태는 [v0.5 상황판 보존본](archive/DEVELOPMENT-STATUS-v0.5.md)을 참고한다. 기존 기획서와 `legacy/tutorial-v03.html`은 보존했다.

## 상태 표기

`✅`는 완료, `🧪`는 구현/자동 검사 후 실기기 검수 전, `🟨`는 기획 후 구현 전, `⬜`는 구체화 전, `⏸`는 보류를 뜻한다. 코드 구현과 실기기 통과를 같은 상태로 기록하지 않는다.

## 다음 순서

1. iPhone 13 mini Safari에서 G3 `두 갈래 길`을 실제 플레이한다.
2. 서쪽/동쪽 어느 경로도 자연스럽게 선택되는지 확인한다.
3. 초소가 본선 옆 한 칸 샛길로 읽히며 `經由`가 `通過`와 다른 행동으로 느껴지는지 확인한다.
4. 초소 없이 북쪽 출구에 먼저 도착했을 때 리셋 없이 되돌아갈 수 있는지 확인한다.
5. 통과하면 G4 `바퀴가 걸린 자리`의 `位置 / 周圍 / 障礙` 상세 설계로 넘어간다.

G3 상세 설계는 [GATE-TOWN-G3-DESIGN-v0.1.md](GATE-TOWN-G3-DESIGN-v0.1.md)에 기록했다. 스토리 장면 배경은 기존 지역 아이콘을 재사용한다. 별도 배경화·고유 NPC 초상화·대형 분기 시스템은 아직 넣지 않는다.
