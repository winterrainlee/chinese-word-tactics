# 개발 상황판

마지막 업데이트: 2026-09-12

## v1.0 — 물길마을의 첫 여행

> **단어의 뜻으로 길을 찾는 소년의 첫 장이 완결되고, 물길마을에 돌아올 곳과 다음 의뢰가 생겨 이후의 여행을 계속 확장할 수 있는 버전.**

v1.0은 세계 전체의 완성이 아니다. 다음 두 가지가 함께 성립한 첫 완결판이다.

1. 고향을 떠난 소년이 물길마을의 `길목 / 장인골 / 장터`를 원하는 순서로 경험하고, 주민에게 믿고 일을 맡길 수 있는 여행자로 인정받는다.
2. 여관과 첫 자유 의뢰가 실제로 작동하여, 완결된 첫 장 뒤에도 새 콘텐츠를 자연스럽게 이어 붙일 수 있다.

구역별 판 수는 현재 제작 기준이지 출시 조건 자체가 아니다. 길목·장인골은 7판, 장터는 8판으로 설계되어 있으며, 각 구역에서 **새 단어 소개 → 재사용 → 의미 조합 → 구역의 사건 해결**이 충분히 완결되는지를 우선한다.

아래의 `1.0 필수`와 `출시 품질` 항목이 모두 `✅`가 되어야 v1.0으로 부른다.

## 지금 위치

**main은 v0.6 이야기·여정 기반, 물길마을（三溪鎮） 그림지도, 길목 G1~G7과 장인골 W1~W7, 장터 M1~M3까지 구현된 상태다. 장터 M4~M8과 여관 런타임은 다음 구현 범위다.**

- 튜토리얼 6판과 길목 G1~G6은 iPhone 13 mini Safari 세로 화면에서 실제 검수를 통과했다.
- 길목 G7 `북쪽으로 가는 행렬`은 자동·브라우저 검사를 통과했고 실기기 최종 검수를 기다린다.
- 물길마을 그림지도도 자동·브라우저 검사를 통과했고 작은 화면의 시각·터치 실기기 검수를 기다린다.
- 장인골은 W1~W7 전체를 구현·배포했다. 상태 조절, 연결 관계, 조건 판정, 파생 결과, 손상·수리와 종합판을 자동 검증했고 W7 첫 완료에서 `workshop-core`가 기록된다. iPhone 13 mini Safari에서 W1~W7 공동 실기기 검수는 남아 있다.
- 장터는 M1~M3을 구현했다. 작은 격자+상황 패널의 공통 자원 런타임에서 `需求 / 足夠 / 不足` → `數量 / 剩下` → `交換 / 獲得`을 실제 수량 이동으로 다룬다. M1에서 프롤로그의 행상 아주머니와 바로 다시 만나 두 좌판의 필요량을 확인하고, M2에서 아주머니의 남은 짐을 정리하며, M3에서는 남은 천을 밧줄과 교환해 다시 가져다준다.
- 프롤로그 행상인은 중년 여성 `行商阿姨`로 확정했다. 길에서는 늑대를 피하다 작은 목제 손수레 바퀴가 진흙 홈에 빠져 소년에게 자연스럽게 손을 빌려 달라고 부탁하고, 장터 전술판에서는 현대식 수레 아이콘 대신 사람형 NPC로 직접 등장한다. M1 첫 실기기 검토 뒤 소년 현재 칸 강조·중앙 정렬과 이동 화살표 시각 우선순위도 수정했다.
- 장터 M4~M8은 상세 설계를 완료했고 아직 런타임 구현 전이다. M4에서 `inn-unlocked`, M8에서 `market-core`를 기록하는 계획은 유지한다.
- 세 갈래 완료를 계산하는 `gate-core / workshop-core / market-core` 기반은 있으나, 세 구역 합류·사회적 인정 장면은 아직 구현하지 않았다.
- 여관과 의뢰 게시판은 별도 설계 문서가 있고 런타임 구현은 시작 전이다. 여관은 장터 M4 완료 뒤 장터 옆 하위 장소로 열기로 확정했다.
- 장터 신규 구현에는 자원 이동·복구·운반 한도·원자적 교환을 검증하는 순수 로직 테스트와, M1~M3 여정 순서·행상 아주머니의 직접 재회·스크립트 로딩·현재 위치 표현을 확인하는 테스트를 추가했다. 장터판 구조 변경 시 옛 판 내부 저장만 안전하게 초기화하는 호환 처리도 넣었다.

1.0 이전에는 `main 반영 → GitHub Pages 배포 → iPhone 실기기 확인 → 즉시 수정`의 짧은 주기를 유지한다. 기존 `legacy/tutorial-v03.html`과 이전 기획 보존본은 덮어쓰지 않는다.

## 1.0까지의 실행 순서

1. G7 `북쪽으로 가는 행렬`과 물길마을 그림지도의 iPhone 13 mini Safari 검수를 마치고 길목을 닫는다.
2. 장인골 W1~W7을 iPhone 13 mini Safari에서 함께 검수하고, 시각·터치·난도·서사 연결을 즉시 수정한 뒤 장인골 1차 묶음을 닫는다.
3. 장터 M1~M3의 Pages·iPhone 검수를 하고 즉시 수정한 뒤, 같은 자원 런타임을 확장해 M4 구매·`inn-unlocked` 구현으로 이어간다.
4. M5~M7의 복수 선택·보류·분배를 붙이고 M8 종합판에서 `market-core`를 연결한다.
5. 세 구역을 어떤 순서로 끝내도 같은 1장 결말에 도달하고 작은 선택 흔적만 달라지는지 통합한다.
6. 세 갈래 합류와 사회적 인정 장면, 여관의 돌아올 곳 감각을 완성한다.
7. 의뢰 게시판과 첫 자유 의뢰 한 개로 이후 콘텐츠 추가 루프를 실제 검증한다.
8. 저장 내보내기·복원을 추가하고, 전 콘텐츠 제목·대사·단어·힌트를 최종 윤문한다.
9. 빈 저장부터 1장 결말과 첫 의뢰까지 목표 기기에서 완주하고, 대표적인 다른 구역 순서·재플레이·복원을 회귀 검사한다.

각 구역은 `기획 → 한 판 구현 → Pages 배포 → 실기기 확인 → 다음 판` 순서로 닫는다. 여러 판을 장기 브랜치에 묵히지 않는다.

## 1.0 이후

다음 항목은 지도나 이야기에서 방향을 암시할 수 있지만 v1.0 출시를 막지 않는다.

| 범위 | 1.0 이후 역할 |
|---|---|
| 끝마을·변경 방면 | 길목에서 열린 북쪽 길을 따라 물길마을 바깥세계로 확장한다. |
| 학술탑 | 장인골에서 얻은 수리 경험과 글자·말의 힘에 관한 단서를 잇는다. |
| 회의소 | 장터의 `需求 / 分配 / 選擇`을 더 사회적인 문맥으로 확장해, 실제 이해관계 충돌·공동 규칙·`公平`을 다룬다. |
| 여관 확장 | 아침·밤·청소 같은 생활 루틴과 방의 작은 변화를 늘린다. |
| 게시판 확장 | 숲 던전, 채집, 전달, 조사 등 새로 제작한 자유 의뢰를 추가한다. |
| 경제 확장 | 품삯·식사·숙박·여행 준비를 생활감으로 사용하되 반복 파밍과 진행 차단을 만들지 않는다. |
| 단어장·학습 로그·어휘 파이프라인 | 콘텐츠가 충분히 쌓였을 때 복습과 제작 효율을 높이는 방향으로 확장한다. |

일일 갱신, 출석, 에너지, 별점, 랭킹, 랜덤 반복 의뢰, 계정·서버·클라우드 저장, 전체 B1~B2 어휘 수록은 1.0 조건이 아니다. 특히 접속 유도와 반복 파밍을 위한 시스템은 이후에도 기본 방향으로 삼지 않는다.
