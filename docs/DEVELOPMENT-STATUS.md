# 개발 상황판

마지막 업데이트: 2026-09-11

## 지금 위치

**main은 v0.6 스토리·여정 기반과 길목 G2 `종소리가 닿는 곳`까지 구현·배포된 상태다.** G1 `문 안쪽`과 G2는 iPhone 13 mini Safari 세로 화면에서 실제 플레이 검수를 통과했다. 1.0 이전에는 main에 빠르게 반영 → GitHub Pages 배포 → iPhone 실기기 확인 → 즉시 수정하는 흐름을 유지한다.

이번 실행 내역은 [v0.6 실행 계획](V0.6-EXECUTION-PLAN.md)에 기록한다. 이전의 상세 기능·지역별 기획 상태는 [v0.5 상황판 보존본](archive/DEVELOPMENT-STATUS-v0.5.md)을 참고한다. 기존 기획서와 `legacy/tutorial-v03.html`은 보존했다.

## 상태 표기

`✅`는 완료, `🧪`는 구현/자동 검사 후 실기기 검수 전, `🟨`는 기획 후 구현 전, `⬜`는 구체화 전, `⏸`는 보류를 뜻한다. 코드 구현과 실기기 통과를 같은 상태로 기록하지 않는다.

## 다음 순서

1. G3 `두 갈래 길`의 한 줄 플레이 경험과 5×7 전후 맵을 확정한다.
2. `路線`이 전체 이동 경로, `經由`가 그 경로에 포함된 중간 지점이라는 차이를 실제 이동으로 느끼게 한다.
3. 기존 `通過 / 到達`, 조사, 다조건 완료 중 무엇을 재사용할지 먼저 정하고, 정말 필요한 route/waypoint 판정만 추가한다.
4. 설계 합의 뒤 G3 전후 이야기 → 전술 → 여정 연결 → 자동 검사 → main/Pages → iPhone 검수 순으로 진행한다.

스토리 장면 배경은 기존 지역 아이콘을 재사용한다. 별도 배경화·고유 NPC 초상화·대형 분기 시스템은 아직 넣지 않는다.
