# 개발 상황판

마지막 업데이트: 2026-09-11

## v1.0 — 물길마을의 첫 여행

> **단어의 뜻으로 길을 찾는 소년의 첫 장이 완결되고, 물길마을에 돌아올 곳과 다음 의뢰가 생겨 이후의 여행을 계속 확장할 수 있는 버전.**

v1.0은 세계 전체의 완성이 아니다. 다음 두 가지가 함께 성립한 첫 완결판이다.

1. 고향을 떠난 소년이 물길마을의 `길목 / 장인골 / 장터`를 원하는 순서로 경험하고, 주민에게 믿고 일을 맡길 수 있는 여행자로 인정받는다.
2. 여관과 첫 자유 의뢰가 실제로 작동하여, 완결된 첫 장 뒤에도 새 콘텐츠를 자연스럽게 이어 붙일 수 있다.

구역당 7판은 현재 제작 기준이지 출시 조건 자체가 아니다. 각 구역에서 **새 단어 소개 → 재사용 → 의미 조합 → 구역의 사건 해결**이 충분히 완결되는지를 우선한다.

아래의 `1.0 필수`와 `출시 품질` 항목이 모두 `✅`가 되어야 v1.0으로 부른다.

## 지금 위치

**main은 v0.6 이야기·여정 기반, 물길마을（三溪鎮） 그림지도, 길목 G1~G7까지 구현·배포된 상태다.**

- 튜토리얼 6판과 길목 G1~G6은 iPhone 13 mini Safari 세로 화면에서 실제 검수를 통과했다.
- 길목 G7 `북쪽으로 가는 행렬`은 자동·브라우저 검사를 통과했고 실기기 최종 검수를 기다린다.
- 물길마을 그림지도도 자동·브라우저 검사를 통과했고 작은 화면의 시각·터치 실기기 검수를 기다린다.
- 장인골·장터는 이야기 역할과 1차 학습 방향만 정해졌으며, 개별 스테이지 설계와 구현은 남아 있다.
- 세 갈래 완료를 계산하는 `gate-core` 계열 기반은 있으나, 세 구역 합류·사회적 인정 장면은 아직 구현하지 않았다.
- 여관과 의뢰 게시판은 별도 설계 문서가 있고 런타임 구현은 시작 전이다.
- 현재 공개 배포는 Node 단위 검사 86개, 여정 브라우저 흐름 17개, G1~G7 전술 브라우저 회귀 검사를 통과한다.

1.0 이전에는 `main 반영 → GitHub Pages 배포 → iPhone 실기기 확인 → 즉시 수정`의 짧은 주기를 유지한다. 기존 `legacy/tutorial-v03.html`과 이전 기획 보존본은 덮어쓰지 않는다.

### 게임의 핵심 약속

새로 만드는 모든 1.0 콘텐츠는 다음을 지켜야 한다.

- 단어의 뜻이 거리, 영역, 상태 변화, 자원 이동, 선택 같은 판의 실제 규칙과 연결된다.
- 한 스테이지의 새 목표어는 기본적으로 1~3개이며, 앞에서 배운 단어를 다시 사용한다.
- 단어 카드는 언제든 불이익 없이 확인할 수 있다.
- 성공 뒤에는 사용자가 왜 해결되었는지 자신의 말로 설명할 수 있다.
- 시간 제한, 별점, 에너지, 반복 파밍을 핵심 진행 조건으로 넣지 않는다.
- 가능한 판에서는 하나의 정답 동선보다 여러 접근이나 행동 순서를 허용한다.
- 추천 경로와 실제 잠금 조건을 시각·문구 모두에서 구분한다.

## 1.0까지의 실행 순서

1. G7 `북쪽으로 가는 행렬`과 물길마을 그림지도의 iPhone 13 mini Safari 검수를 마치고 길목을 닫는다.
2. 장인골 전체의 학습어·상태 변화·이야기 흐름을 먼저 확정한 뒤 작은 단위로 설계·구현·실기기 검수한다.
3. 장터 전체의 자원 선택·교환 흐름을 확정하고, 진행 중 최소 여관이 자연스럽게 열리도록 구현한다.
4. 세 구역을 어떤 순서로 끝내도 같은 1장 결말에 도달하고 작은 선택 흔적만 달라지는지 통합한다.
5. 세 갈래 합류와 사회적 인정 장면, 여관의 돌아올 곳 감각을 완성한다.
6. 의뢰 게시판과 첫 자유 의뢰 한 개로 이후 콘텐츠 추가 루프를 실제 검증한다.
7. 저장 내보내기·복원을 추가하고, 전 콘텐츠 제목·대사·단어·힌트를 최종 윤문한다.
8. 빈 저장부터 1장 결말과 첫 의뢰까지 목표 기기에서 완주하고, 대표적인 다른 구역 순서·재플레이·복원을 회귀 검사한다.

각 구역은 `기획 → 한 판 구현 → Pages 배포 → 실기기 확인 → 다음 판` 순서로 닫는다. 여러 판을 장기 브랜치에 묵히지 않는다.

| 경제 확장 | 품삯·식사·숙박·여행 준비를 생활감으로 사용하되 반복 파밍과 진행 차단을 만들지 않는다. |
| 단어장·학습 로그·어휘 파이프라인 | 콘텐츠가 충분히 쌓였을 때 복습과 제작 효율을 높이는 방향으로 확장한다. |

일일 갱신, 출석, 에너지, 별점, 랭킹, 랜덤 반복 의뢰, 계정·서버·클라우드 저장, 전체 B1~B2 어휘 수록은 1.0 조건이 아니다. 특히 접속 유도와 반복 파밍을 위한 시스템은 이후에도 기본 방향으로 삼지 않는다.
