# 개발 상황판

마지막 업데이트: 2026-09-22

## v1.0 — 물길마을의 첫 여행

> **단어의 뜻으로 길을 찾는 소년의 첫 장이 완결되고, 물길마을에 돌아올 곳과 다음 의뢰가 생겨 이후의 여행을 계속 확장할 수 있는 버전.**

v1.0은 세계 전체의 완성이 아니다. 다음 두 가지가 함께 성립한 첫 완결판이다.

1. 고향을 떠난 소년이 물길마을의 `길목 / 장인골 / 장터`를 원하는 순서로 경험하고, 세 구역에서 각각 일을 도운 뒤 물길마을에 돌아올 자리를 얻는다.
2. 여관과 첫 자유 의뢰가 실제로 작동하여, 완결된 첫 장 뒤에도 새 콘텐츠를 자연스럽게 이어 붙일 수 있다.

구역별 판 수는 현재 제작 기준이지 출시 조건 자체가 아니다. 길목·장인골은 7판, 장터는 8판이며, 각 구역에서 **새 단어 소개 → 재사용 → 의미 조합 → 구역의 사건 해결**이 충분히 완결되는지를 우선한다.

아래의 `1.0 필수`와 `출시 품질` 항목을 모두 `✅`로 닫았으며, 2026-09-19 사용자 최종 완주 검수까지 통과해 v1.0을 완료했다.

## 지금 위치

**main은 v1.0 `물길마을의 첫 여행`의 구현과 최종 검수를 모두 마쳤다. 제목 화면 `따라온 단어들`에서 출발해 튜토리얼 6판, 물길마을（三溪鎮） 그림지도, 길목 G1~G7·장인골 W1~W7·장터 M1~M8, 여관 MVP와 C06 1장 결말, C08 첫 자유 의뢰까지 한 흐름으로 이어진다. 여정에는 `자유 의뢰 · 물길마을 주변 → 북쪽 숲 → 개별 의뢰` 계층이 있으며, 설정의 버전 JSON 저장 내보내기·검증·복원도 iPhone 13 mini Safari 실기기에서 확인했다. 2026-09-19 빈 저장부터 1장 결말과 첫 자유 의뢰까지 완주하고, 다른 구역 순서·재플레이·백업 복원까지 최종 사용자 회귀 검수를 통과해 Q07을 닫았다. 1.0 이후 확장인 북쪽 숲 F2~F8도 구현·자동검사와 iPhone 13 mini Safari 최종 검수를 마쳤다.**

- 제목 화면 `따라온 단어들`과 첫 출발/이어하기 흐름, 튜토리얼 6판, 물길마을 도착과 그림지도, 이야기·여정 UX를 iPhone 13 mini Safari에서 확인했다. 늑대 정보는 정확한 다음 칸을 예고하지 않고 위험 거리와 이동 원칙만 알려 준다.
- 길목 G1~G7의 기존 흐름과 범용 살펴보기 모드를 제거한 현재 입력 방식이 실기기 검수를 통과했다.
- 장인골 W1~W7 전체가 실기기 검수를 통과했다. 상태 조절, 연결 관계, 조건 판정, 파생 결과, 손상·수리와 종합판이 작동하며 W7 첫 완료에서 `workshop-core`가 기록된다.
- 장터 M1~M8의 기존 흐름과 장소 직접 조회 방식이 실기기 검수를 통과했다. 장소 정보는 거리와 관계없이 볼 수 있고 실제 행동만 인접 상태에서 실행한다.
- M2 `남은 상자`는 첫 등장 때 현재 수량을 바로 보여주지 않는다. `原來數量 / 已送出`을 읽고 `剩下`을 확인한 뒤에만 실제 남은 수량과 운반 행동이 열린다. M3 이후에는 현재 수량을 기본 정보로 제공한다.
- M4 `오늘 저녁거리`는 판 내부 `錢幣` 8개와 가격이 다른 세 좌판을 사용한다. 세 가격을 모두 확인해야 구매가 열리고, 가격 6짜리 빵을 먼저 사는 것도 허용되지만 채소를 살 돈이 부족해지는 실패 상태가 실제로 남는다. 정상 완료 뒤 `inn-unlocked`가 기록되고 장터 옆에 `客棧 · 여관` 표식이 열린다.
- M5 `어느 것이 나을까`는 가격 3·용량 2의 작은 바구니와 가격 6·용량 3의 큰 나무상자를 모두 유효한 해법으로 둔다. 최초 선택만 `stageOutcomes`에 저장하며 우열 점수는 없다.
- M6 `짐칸은 하나뿐`은 `放棄`를 폐기가 아니라 이번 차례의 보류로 사용한다. 먼저 보낸 물건과 다음 차례로 미룬 물건을 최초 본편 선택으로 저장하고 재플레이가 덮어쓰지 않는다.
- M7 `제자리로 돌아갈 물건`은 같은 밀가루를 빵집과 국수 좌판에 나누어 `分配`하고 정확한 부족분을 `補充`한다. 자동 초과 방지는 없으며, 너무 많이 넣으면 과잉 상태가 실제로 남고 초과분을 회수해 수정할 수 있다. 최종 완료는 빵집 3, 국수 좌판 2, 등잔기름 좌판 4, 창고 천 1, 늦게 온 짐 밀가루 1의 정확한 상태를 요구한다.
- 장터 판단 트레이는 실기기 검수 결과에 따라 소지 품목과 현재 돈을 같은 1차 크기로 표시하고, 운반 한도만 보조 정보로 낮춘다. 선택 대상과 행동은 고정하고 비교 정보는 한 화면에 두 카드가 완전히 보이는 가로 레일로 둔다. M7 창고는 `布 0/1` 필요량을 명시해 판 배지·선택 요약·비교 카드·완료 판정이 같은 데이터를 읽는다.
- M8 `장날이 열리기 전에`는 새 규칙 없이 분배·교환·구매를 조합하는 종합판이다. 해결 순서는 저장하지 않고 최종 세계 상태만 본다. 서로 다른 해결 순서를 허용하며 첫 본편 완료에서 `market-core`가 기록된다. 이때 여관 표식에 작은 나무패가 달린 황동 방 열쇠와 미세하게 따뜻해진 문빛이 생긴다.
- 프롤로그 행상인은 중년 여성 `行商阿姨`로 확정했다. 길에서는 작은 목제 손수레 바퀴가 진흙 홈에 빠져 소년에게 자연스럽게 손을 빌려 달라고 부탁하고, 장터 전술판에서는 사람형 NPC로 직접 등장한다.
- 스토리 화자 아이콘은 행상 아주머니·젊은 병사 길지기·노년 여성 장인·장터지기·여관 주인·수레꾼의 고정 인물 6종과 성별 없는 공용 주민 실루엣을 SVG로 제작해 연결했다. 내레이터와 정체불명의 목소리는 초상을 표시하지 않으며 실기기 표시를 확인했다.
- 여관 MVP는 방과 기본 상호작용까지 구현했다. `通行牌`는 옷상자 위, `貨車引路牌`는 침대 위 벽, `修繕牌`는 책상 위에 실제 진행 기록에 따라 나타난다. 방 배경은 첫 화면에서 선로딩하지 않고 여관을 실제로 눌렀을 때부터 불러온다.
- C05의 세 갈래는 서로 자동으로 다음 구역을 강제하지 않고, 길목·장인골·장터를 원하는 순서로 진행해도 핵심 진행이 막히지 않는 현재 구조를 사용자 검수로 닫았다.
- C06은 `gate-core / workshop-core / market-core`와 세 구역 최종 후일담을 모두 확인한 뒤 열린다. 시간 경과나 주민들의 선행 평판을 가정하지 않고, 여관 문구가 바뀐 뒤 소년이 직접 여관으로 돌아가 세 곳을 다녀온 이야기를 한다. 방에서 여행의 흔적을 정리하며 `chapter1-complete`를 기록하고 실제 방 화면으로 돌아온다.
- C06은 일반 `여정` 추천 목록에서 자동으로 튀어나오지 않는다. 여관이라는 장소에서 직접 진입하는 내부 결말로 취급한다.
- C08은 1장 결말 뒤 여관 주인의 직접 부탁을 수락하고 북쪽 숲 바깥쪽에서 월백버섯 세 개를 모아 귀환·보고하면 의뢰 게시판이 생기는 첫 자유 의뢰다. 일반 버섯과 월백버섯의 상황형 조사·채집, 북쪽 숲 표식, 귀환·보고 흐름까지 실기기 검수를 통과했다.
- 여정에서 북쪽 숲은 1장의 네 번째 지역이 아니라 `자유 의뢰 · 물길마을 주변` 아래의 영구 장소로 표시한다. 수락한 의뢰만 그 아래에 나타나고, 각 의뢰는 독립된 타임라인과 계속 위치를 가진다. 본편 `이어서 여행하기`는 자유 의뢰 진행과 분리했다.
- **북쪽 숲 F2~F8과 네 후속 의뢰는 `✅`로 마감했다.** 게시판 설치 뒤 `숲길의 표식(F2~F3)`과 `장인이 찾는 재료(F4~F5)`가 함께 열리고, 둘의 보고 뒤 `사라진 꾸러미(F6~F7)`, 이어서 `오늘의 숲길(F8)`이 열린다. 최종 후일담은 `north-forest-familiar`를 기록한다. 전용 Node 검사, F2~F8 브라우저 완주, F1~F8 네 viewport 64상태 회귀와 CI 연결에 더해 2026-09-22 iPhone 13 mini Safari 최종 검수를 완료했다.
- **설정과 Q05 저장 관리가 구현·자동·실기기 검수를 모두 통과했다.** 새 게임에서도 제목의 ⚙로 설정에 들어갈 수 있고 게임 중 메뉴에서도 같은 화면을 연다. 백업은 게임이 소유한 여정·전술·월드·완료대기·단어장 5개 저장 영역만 버전이 있는 JSON으로 내보낸다. 복원은 쓰기 전에 형식과 항목을 검사하고 진행 요약을 보여 준 뒤 명시적 확인을 받아 적용하며, 다른 같은 출처의 저장값은 건드리지 않는다. iPhone 13 mini Safari에서 현재 진행을 내보낸 파일을 다시 선택해 복원했고 진행 상태가 그대로 유지되는 것까지 확인했다.
- **1.0 전술 UX 공통층과 범용 살펴보기 모드를 제거한 최신 조작이 실기기 검수를 통과했다.** 상시 목표는 짧은 안내로 줄이고 전체 목표·규칙은 `뜻`에서 확인한다. 상태 메시지는 판 바로 아래의 행동 피드백으로 강화했고, 장터 대상 패널은 그 아래로 이동했다. 완료 시 모달로 판을 덮지 않고 최종 판 위에 인라인 진행 버튼을 표시하며, 완료 직후 새로고침도 같은 완료 상태로 복원한다. 길목·장인골·장터는 구역 최종 후일담 전까지 월드맵을 강제로 왕복하지 않는다.
- **2026-09-22 장터 판단 위계 원칙을 길목·장인골·북쪽 숲의 판단 구조에 맞게 확장했다.** G7은 `經由 / 跟隨`, W7은 남은 이상 장치 수와 중국어 결과 행동, F5는 `適合 n/2`, F8은 확인한 `乾·寬 / 濕·窄`를 각 완료 상태와 같은 데이터에서 파생한다. F3·F7의 사용하지 않는 진척 플래그를 제거했고 튜토리얼 6판은 구조 변경 없이 회귀만 확인했다. 네 viewport Chromium 자동 검증을 통과했으며 북쪽 숲 F5·F8은 2026-09-22 iPhone 13 mini Safari 최종 검수에도 포함했다.
- **2026-09-22 신규 지역·스테이지 개발 절차를 표준화했다.** 범위·안정 ID, 상황·어휘·기믹 설계, 구현 수준 사양, 작은 수직 slice, 자동검증, Pages, iPhone 승인까지 일곱 게이트와 Definition of Ready/Done으로 고정했다. `node tools/verify-content.cjs`는 전체 빠른 콘텐츠 게이트를, `--browser`는 기존 Pages 브라우저 회귀까지 실행한다. 새 콘텐츠 계약 감사는 `index.html`의 classic-script 순서를 기준으로 stage/story/journey/world/lexicon/lifecycle 교차 참조와 grid 기본 계약을 검사하며 CI 배포 전에 실행된다.
- **2026-09-22 실기기 검수에서 목표 카드의 중복 안내를 다시 축소했다.** G7의 `經由 / 跟隨` 상시 요약과 F1의 `月白菇 X/3 · 한국어 다음 행동`을 목표 옆에서 제거했다. G7의 경로·행렬은 판, F1의 묶음 수량은 조사한 판, 행동 결과와 실패 이유는 상태줄, 전체 규칙은 책 버튼 상세가 맡는다. 공통 목표 렌더가 `ruleline` 클래스를 초기화해 G7의 예외 스타일이 다음 F1에 남던 전환 누수도 막았다.
- **2026-09-22 판 아래 상태줄도 36판 기준으로 정리했다.** 일반 진입 안내 17개와 W1~W7·M1~M8의 시작 설명을 제거해 33판은 빈 상태줄로 시작하고, 첫 이동·늑대 주기처럼 판만으로 알 수 없는 튜토리얼 3판만 안내를 유지한다. 공통 `目標完成`과 M8의 완료 재진술도 제거했으며, 중국어 행동 결과·수량 변화·실패 이유·장터 판단 트레이·44px 되돌리기는 유지한다. 결과가 없는 완료 상태는 높이만 예약하고 빈 카드 테두리를 표시하지 않는다.
- **2026-09-22 장터의 빈 행동 칸도 설명 없이 비우도록 정리했다.** 선택 대상에 실행 가능한 거래·보충 버튼이 없을 때 `지금 여기서 할 수 있는 행동은 없어`를 표시하지 않는다. 실제 행동이 가능해지면 나타나는 버튼만으로 상태 변화를 알리고, 구체적인 행동 실패 이유는 기존 상태 피드백에 유지한다.

v1.0 마감까지 `main 반영 → GitHub Pages 배포 → iPhone 실기기 확인 → 즉시 수정`의 짧은 주기를 유지했다. 기존 `legacy/tutorial-v03.html`과 이전 기획 보존본은 계속 보존한다.

2. 2026-09-19 iPhone 13 mini Safari에서 빈 저장부터 1장 결말과 첫 자유 의뢰까지 완주하고, 대표적인 다른 구역 순서·재플레이·백업 복원을 다시 확인해 Q07을 닫았다.

v1.0까지는 `기획 → 구현 → Pages 배포 → iPhone 실기기 확인 → 즉시 수정`의 짧은 주기로 닫았다. 이후 확장은 아래 `1.0 이후` 항목에서 이어간다.

## 1.0 이후

다음 항목은 지도나 이야기에서 방향을 암시할 수 있지만 v1.0 출시를 막지 않는다.

| 범위 | 1.0 이후 역할 |
|---|---|
| 북쪽 숲 F2~F8 | `✅` 다섯 자유 의뢰와 최종 `north-forest-familiar`까지 구현·자동검사·iPhone 13 mini Safari 최종 검수 완료. |
| 끝마을·변경 방면 | 길목에서 열린 북쪽 길을 따라 물길마을 바깥세계로 확장한다. |
| 학술탑 | 장인골에서 얻은 수리 경험과 글자·말의 힘에 관한 단서를 잇는다. |
| 회의소 | 장터의 `需求 / 分配 / 選擇`을 더 사회적인 문맥으로 확장해, 실제 이해관계 충돌·공동 규칙·`公平`을 다룬다. |
| 여관 확장 | 청소·부엌·세탁 같은 생활 기능은 실제 이야기·플레이 수요가 생길 때만 늘린다. 날짜·밤·아침 루틴을 진행 조건으로 만들지 않는다. |
| 여관 방 자산 로딩 정리 | 현재 640×960 WebP를 Base64 3청크로 보관하고 여관을 실제로 눌렀을 때 preload·decode한다. 추후 바이너리 자산 업로드 경로를 정리해 실제 단일 `.webp` 파일 직접 로딩으로 교체하고, 청크 결합·Base64 디코딩·Blob 생성 경로를 제거한다. |
| 게시판 확장 | 북쪽 숲의 다섯 의뢰를 `자유 의뢰 · 물길마을 주변 → 북쪽 숲 → 개별 의뢰` 아래 형제 항목으로 누적하는 구조는 구현했다. 이후 숲 던전·채집·전달·조사 의뢰도 같은 장소 계층에 추가한다. |
| 경제 확장 | 품삯·식사·숙박·여행 준비를 생활감으로 사용하되 반복 파밍과 진행 차단을 만들지 않는다. |
| 단어장·학습 로그·어휘 파이프라인 | 콘텐츠가 충분히 쌓였을 때 복습과 제작 효율을 높이는 방향으로 확장한다. |

일일 갱신, 출석, 에너지, 별점, 랭킹, 랜덤 반복 의뢰, 계정·서버·클라우드 저장, 전체 B1~B2 어휘 수록은 1.0 조건이 아니다. 특히 접속 유도와 반복 파밍을 위한 시스템은 이후에도 기본 방향으로 삼지 않는다.
