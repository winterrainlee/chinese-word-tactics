# 개발 상황판

마지막 업데이트: 2026-09-11

## 지금 위치

**main은 v0.6 스토리·여정 기반, 물길마을（三溪鎮） 지도 전환, 길목 G5 `좁은 성문`까지 구현·배포된 상태다.** G1~G4의 핵심 플레이와 G3 `通行牌` 선택 흔적 후속 이야기까지 iPhone 13 mini Safari 세로 화면에서 실제 검수를 통과했다. G5는 `移動 / 前進 / 後退`를 수레의 실제 위치 변화로 경험하는 첫 movable entity 판으로 구현했고 실기기 검수를 기다린다. 물길마을 지도는 자동 검사와 Pages 배포를 통과했고 작은 화면에서의 시각·터치 검수를 기다린다. 1.0 이전에는 main에 빠르게 반영 → GitHub Pages 배포 → iPhone 실기기 확인 → 즉시 수정하는 흐름을 유지한다.

2026-09-11 세계 구조를 다시 정리했다. 튜토리얼 뒤의 `길목 / 장인골 / 장터`는 더 이상 세 개의 독립 마을이 아니라, 숲과 물길을 지나 도착하는 큰 정착지 **물길마을（三溪鎮）** 안의 세 생활 구역이다. `회의소 / 학술탑`도 별도 도시가 아니라 같은 마을 안의 후속 장소로 본다. `길목` 너머만 변경 방면과 `끝마을` 같은 외부 정착지로 이어진다. 세계관 기준은 [WORLD-v0.6.md](WORLD-v0.6.md)를 우선한다.

런타임 월드 화면도 새 구조로 1차 전환했다. 기존 세로 카드 목록 대신 세 물줄기와 세 길이 보이는 세로형 마을 지도를 사용하고, `길목 / 장인골 / 장터 / 회의소 / 학술탑 / 끝마을 방면`을 실제 공간 관계에 맞춰 배치한다. 고향은 `小村`, 첫 정착지는 `三溪鎮`으로 표시한다. 기존 `gate-town / workshop-town / market-town` 같은 내부 식별자는 저장·여정 호환을 위해 유지하고 표시층에서 새 세계관 이름으로 바꾼다.

첫 행상인 장면도 새 구조에 맞췄다. 행상인이 소년에게 어디에서 왔는지 묻고, 소년은 `森林那邊的一個小村。`이라고 답한다. 이어서 행상인이 `三溪鎮`의 이름과 세 물줄기, 세 길이 모두 같은 마을로 이어진다는 사실을 설명한다.

이번 실행 내역은 [v0.6 실행 계획](V0.6-EXECUTION-PLAN.md)에 기록한다. 이전의 상세 기능·지역별 기획 상태는 [v0.5 상황판 보존본](archive/DEVELOPMENT-STATUS-v0.5.md)을 참고한다. 기존 기획서와 `legacy/tutorial-v03.html`은 보존했다.

## 상태 표기

`✅`는 완료, `🧪`는 구현/자동 검사 후 실기기 검수 전, `🟨`는 기획 후 구현 전, `⬜`는 구체화 전, `⏸`는 보류를 뜻한다. 코드 구현과 실기기 통과를 같은 상태로 기록하지 않는다.

## 다음 순서

1. iPhone 13 mini Safari에서 새 **물길마을（三溪鎮） 지도**를 먼저 확인한다.
2. `小村 → 숲 → 三溪 합류점 → 세 길`의 방향이 설명 없이도 읽히는지 본다.
3. 길목·장인골·장터가 같은 마을의 세 구역처럼 보이고, 학술탑·회의소는 그 안쪽, 끝마을은 바깥 방향처럼 보이는지 확인한다.
4. 지도 지점이 겹치거나 작다면 좌표와 카드 크기를 바로 조정한다.
5. 같은 기기에서 G5 `좁은 성문`도 이어서 검수한다.
6. 통과하면 G6 `跟隨 / 帶領` follower를 구현하고, G7에서 두 번째 사용처가 생길 때 follower chain으로 확장한다.

G4~G7 통합 설계는 [GATE-TOWN-G4-G7-DESIGN-v0.1.md](GATE-TOWN-G4-G7-DESIGN-v0.1.md)에 기록했다. G5의 movable entity는 수레 위치, 앞·뒤 이동, 충돌, 목적지 판정만 담당하며 회전·관성·무게 같은 범용 물리 시스템은 도입하지 않는다.

세계관 변경의 상세 기준은 [WORLD-v0.6.md](WORLD-v0.6.md)를 따른다. 기존 `WORLD-v0.5.md`는 구현 당시의 기준선을 설명하는 보존 문서로 취급한다.
