## 1. 결정과 선정 근거

2026-10-25 사용자는 수업에서 `仍然`을 만났다고 말하고, **然 재방문 03B와 而 04A의 구체화를 우선 목표**로 정했다. 仍然은 단순한 장기 비교 후보에서 03B의 중심 표현으로 올라간다. 수업에서 다시 만난 然 표현을 기존 관찰과 연결하려는 개인 학습 질문이 선정 근거다.

복습 사이트에는 별도로 `仍然`이 **4권 9과 어법 `B4-L09-G07`**로 등록돼 있다. 이 등록 위치와 사용자가 실제 수업에서 만났다는 진술을 구별한다. 진술만으로 현재 수업의 교재 권·과·쪽수나 숙달 여부를 확정하지 않는다.

03B는 03A의 목표어와 완료 조건을 늘리는 수정이 아니라, 같은 然을 새로운 질문으로 다시 보는 후속 선택 연구다. `03B`는 이번에 정한 연구 참조 번호다. 화면 제목, 전역 stage/story ID, 실제 선수 조건과 `sideGroup`은 상세 설계에서 정한다.

## 2. 중심 질문과 학술탑에서 맡을 일

> **이 문장을 읽는 동안, 무엇이 여전히 같은 상태로 이어지고 있는가?**

여기서 관찰할 것은 단어가 가리키는 지속의 대상과 범위다. 앞의 어느 대상·상태·행동이 뒤에서도 이어지는지, 주변의 다른 변화까지 없었다고 읽어도 되는지를 살핀다. 원문에 이전 상태가 명시되지 않았다면 문맥의 기준을 확인하고, 없는 과거 사건을 만들어 채우지 않는다.

본선의 예상·실제 비교 경험과 연결하되 같은 판정을 반복하지 않는다. `仍然`은 이전과 같은 상태가 이어짐을 나타낸다. 그 지속이 예상대로였는지, 뜻밖이었는지, 바람직한지는 문맥에서 따로 판단한다. [언어 근거](#8-근거와-편집층의-구분)는 아래에 남긴다.

**변화나 장애가 앞에서 반드시 일어나야 하는 것은 아니다.** 조건 변화가 있는 사례도 사용할 수 있지만, 이를 仍然의 필수 조건으로 가르치지 않는다. 두 절을 잇는 접속어 하나로만 분류하지 않고 문장 안에서 어떤 상태·행동을 수식하는지 관찰한다.

## 3. 표현 구성의 확정 범위

| 역할 | 현재 결정 |
|---|---|
| 중심 표현 | `仍然`을 중심으로 구체화한다. 뜻과 쓰임을 실제 문장의 대상·범위에 적용하게 한다. |
| 기존 표현 재사용 | `然而 / 雖然 / 果然 / 竟然`에서 필요한 비교만 고른다. 모두를 매 단계에 넣거나 재시험하지 않는다. |
| 然의 후속 후보 | `固然 / 不盡然`은 로드맵의 재방문 후보로 유지한다. 이번 03B의 필수 표현으로 자동 편입하지 않는다. |
| 추가 동의어·표본 | `依然 / 仍舊` 등은 사전의 비교 근거일 수 있다. 별도 학습 필요 없이 목표어 수를 늘리지 않는다. |
| 03A의 현재 구성 | `然而 / 果然 / 竟然 / 然後 / 雖然 / 既然 / 不然`의 일곱 표현과 기존 적용·완료 기록을 유지한다. |

한 작업의 신규 중심 표현은 기본 1~3개 원칙을 따른다. 03B를 然 포함어 전체 목록으로 만들지 않으며, 고급 표현을 얼마나 추가했는지를 연구의 완성 기준으로 삼지 않는다.

### 기존 표현과 비교할 지점

| 비교 대상 | 03B에서 확인할 질문 |
|---|---|
| 然而 | 앞뒤 내용의 전환과 특정 상태의 지속은 어떻게 함께 나타나는가? 전환이 있다고 모든 상태가 바뀐 것으로 읽지는 않는가? |
| 雖然 | 앞의 사정을 인정하는 구조 안에서 뒤에 계속되는 상태는 무엇인가? 雖然과 仍然이 서로 다른 역할을 하며 함께 쓰일 수 있음을 읽는가? |
| 果然 | 이전 상태의 지속과 예상의 일치를 혼동하지 않는가? 문맥에 따라 지속이 예상과 일치할 수도 있음을 남기는가? |
| 竟然 | 계속된 상태를 뜻밖이라고 평가할 수 있음을 읽는가? 지속과 놀람을 언제나 둘 중 하나만 고르는 배타적 분류로 만들지는 않는가? |

이 표는 사례를 고를 때의 검토 질문이다. 모든 비교를 독립 단계로 만들거나 같은 문장에서 표현 하나만 유일하게 가능하다고 판정하는 사양이 아니다.

## 4. 이야기와 사례를 고를 때의 질문 — 아직 확정 장면이 아니다

03A를 다시 찾아볼 생활·기록상의 이유를 짧게 만든 뒤, 그 안에서 지속의 대상을 읽을 필요가 생겨야 한다. 연구원의 설명을 또 듣기 위한 방문만으로 이야기를 완결하지 않는다.

| 검토할 장면의 방향 | 의미 판단이 생기는지 확인할 질문 |
|---|---|
| 서로 다른 시점의 기록을 다시 읽는다. | 무엇이 이어졌는지 판단할 이유가 있는가? 앞뒤 시점이 이미 주어졌는데 이를 다시 배치시키기만 하지는 않는가? |
| 주변 조건이 달라진 기록을 읽는다. | 달라진 부분과 여전히 유지된 부분의 대상을 구별하는가? 조건 변화가 없는 사례도 수용하는 설명인가? |
| 지속을 과도하게 넓혀 쓴 메모를 고친다. | 원문은 한 상태의 지속만 말하는데 ‘모든 것이 그대로’라고 적은 추론을 바로잡을 수 있는가? |

이 장면들은 학습용 검토 방향이다. 수로의 새 고장·수리 결과, 바깥길 통행 상태, 표식의 의미 같은 세계 사실은 아직 추가하지 않는다. 04A의 확정된 조사 부록·미확인 결과·다음 질문을 03B에서 먼저 해결하지 않는다.

## 5. 현행 작업대 원칙을 적용한다

- 관찰에는 검토한 글자의 단서와 `仍然` 전체 뜻을 함께 보여 준다. 글자 풀이를 역사적 어원이나 모든 용법의 계산식처럼 제시하지 않는다.
- 然을 이미 알아보았다는 맥락에서 시작한다. 공통 글자 맞히기나 03A의 전체 도입 반복을 새 통과 조건으로 넣지 않는다. 필요한 도입 대사는 공통 이야기 화면을 따른다.
- 관찰 해설은 읽기 전용 면에 놓고, 직접 판단하는 경우에만 원본과 별도의 작업 면을 둔다. 제공한 설명을 사용자가 완성한 답안처럼 표시하지 않는다.
- 원문에서 지속되는 대상이나 고칠 해석을 판단할 필요가 있을 때만 선택을 요구한다. 이미 구분된 전후 기록을 다시 복사·배치시키지 않는다.
- 답을 기억하더라도 해당 구절의 대상·범위를 읽는 판단이 남아야 한다. 같은 뜻을 기호·문법명·번역으로 반복 채점하지 않는다.
- 뜻 조회·되돌리기를 유지한다. 관찰에는 불필요한 확인 단계를 넣지 않고, 판단 문제에서는 선택 수정과 확정을 구별한다. 마지막에는 완전한 중국어 원문을 다시 읽을 수 있게 한다.

## 6. 진행·완료와 다른 연구의 관계

03B와 04A는 현재 함께 구체화할 우선 목표다. 목록 순서나 글자 계보가 실제 잠금 조건을 뜻하지 않는다. **03B 완료를 04A의 새 선수 조건으로 만들지 않는다.** 04A의 기존 본선 04 선수 조건은 유지한다.

03B는 본선 묶음 완료나 후속 본편의 필수 조건으로 넣지 않는다. 03A를 포함한 기존 완료·이야기·아이템은 그대로 보존한다. 03B 자체의 진입 조건은 03A 경험을 어떻게 연결할지 검토한 뒤 명시하며, 이 문서는 잠금을 신설하지 않는다.

중간에 나갔다가 읽던 곳으로 돌아오는 흐름, 첫 플레이와 재플레이의 분리, 원래 진입 화면으로의 복귀는 상세 설계에서 정한다. 현행 저장 구조를 먼저 확인하고 필요한 국소 사양만 추가한다. 현재 03B의 저장·재개 기능이 구현됐다고 기록하지 않는다.

## 7. 다음 구체화 순서와 완료 기준

1. **짧은 스토리라인을 정한다.** 소년이 왜 然 기록을 다시 펼치는지, 어떤 기록을 읽고 무엇을 남기는지 정한다. 확정할 사건과 미확인으로 남길 내용을 구별한다.
2. **사례와 허용 해석을 검토한다.** 지속의 대상·범위, 필요한 이전 문맥, 대표 오독, 자연스러운 대안 표현을 적는다. 조건 변화가 있는 사례만으로 의미를 일반화하지 않는지 확인한다.
3. **의미 판단에 맞는 최소 조작을 정한다.** 실제로 골라야 하는 구절·수정할 해석과 관찰만 하면 되는 부분을 나눈다. 같은 판단을 여러 단계로 반복하지 않는다.
4. **진입·완료·재개 사양을 닫는다.** 화면 제목·ID·선수·옆방 위치·저장·재플레이·복귀를 최신 코드와 대조한다. [개발 표준](REGION-STAGE-DEVELOPMENT-STANDARD-v0.1.md)에 맞춰 구현 준비 상태를 판단한다.

03B 구체화의 완료 기준은 다음과 같다. 구현 완료 기준과 구별한다.

- 짧은 이야기와 연구의 실질적인 결과가 정해져 있고, 기존 사건의 결론·완료 의미를 바꾸지 않는다.
- 仍然의 지속과 예상·평가·양보의 관계를 혼동하지 않는 검토된 사례와 허용 해석이 있다.
- 답을 알아도 대상·범위를 판단하는 조작이 남고, 의미 판단 없는 반복 배치를 제거했다.
- 표현 구성과 선택 연구 계약, 진입·재개·재플레이·복귀 사양을 명시했다. 미확정 사항을 구현된 상태로 표시하지 않는다.

## 8. 근거와 편집층의 구분

- **실제 학습의 출처:** 2026-10-25 사용자의 “수업에서 仍然이 나왔다”는 진술과 03B·04A 우선 목표 지정이다. 특정 교재 권·과 확인이나 학습 효과 검증을 뜻하지 않는다.
- **복습 사이트 등록:** [當代 복습 자료](https://dangdai-five-review.winterrain-lee.chatgpt.site/data.json)의 4권 9과 `B4-L09-G07`이다. 확인 소스는 v7의 `80a9486e574ae5bbbfe07ef791d91924ba9ab0a5`다. 사이트의 한국어 풀이와 예문은 편집된 복습 자료이며, 조건 변화가 있는 예문을 仍然의 전체 정의로 사용하지 않는다.
- **언어 근거:** 교육부 《國語辭典簡編本》 [仍然](https://dict.concised.moe.edu.tw/dictView.jsp?ID=36310&la=1&powerMode=0)을 2026-10-25 확인했다. 이전과 같이 바뀌지 않은 상태를 뜻하며, 주음은 `ㄖㄥˊ ㄖㄢˊ`, 병음은 `réng rán`이다. 사전은 `仍舊 / 依舊 / 依然`을 유사어로 제시하지만, 여기서 그 전체를 목표어로 확정하지 않는다.
- **게임 편집 판단:** 위 연구 질문, 비교 방향, 장면 검토와 조작 원칙은 게임 설계다. 앞으로 작성할 기록·대사는 창작 자료로 표시하며 사전이나 교재의 원문으로 내세우지 않는다.
