# 여관 로비 화풍 비교 v0.1

## 비교 조건

A 회화적 삽화, B 고전 픽셀 RPG, C 그림책형 레트로 RPG를 동일한 4:5 배경, 카운터/주인·게시판·계단·식탁·문 배치로 제작했다. 원본 방의 목재·회벽·오후 빛을 참고했다. 여관 주인은 기존 SVG의 묶은 머리·붉은 작업복·밝은 앞치마를 유지했다. 새 그림의 외형 세부는 세계관 확정이 아니다.

`content.js`의 공통 객체 ID, 화면 앵커, 3개 대사, 조사문을 모든 화풍이 공유한다. 그림 교체로 의미·해금·위치 데이터가 바뀌지 않는다. 위치는 비교 삽화용 백분율이며 실제 지리 좌표가 아니다. 생성 이미지의 실루엣에는 작은 차이가 있지만 동일한 공통 터치 영역 안에 있다.

- 주인: 중국어 3개 대사, 요청 시 한국어 뜻, 이전/다음.
- 게시판: 생활 안내문 조사. 본편 의뢰 게시판 해금과 무관한 시험용 자료다.
- 식탁: 차와 컵 조사. 출입문: 시험용 문앞으로 나갔다 복귀.
- 계단: **변경 없는 `src/world-inn-runtime.js`**를 호출해 기존 방 그림·사물 조회를 연다. 시험 페이지 전용 GameFlow/TacticalGame 어댑터만 로비 복귀와 사물 정보창을 제공한다.
- 집중형 이야기: **변경 없는 `src/story-runtime.js`·`src/story.css`·인물 SVG**로 시험 대사를 보여준다. 본편 사건이나 완료 콜백은 연결하지 않는다.
- 메모리 안에서만 비교 상태를 유지한다. LocalStorage, SessionStorage, 본편 진행·저장 형식, 기존 자산·이야기·해금은 수정하지 않는다. 새로고침하면 초기화한다.

## 미술 제작

내장 image_gen으로 A 제작 → A를 공간 기준으로 B/C 화풍 변환. C 최초 초안은 A와 차이가 부족해 폐기하고 윤곽·큰 색면 중심으로 다시 제작했다. 최종 PNG를 WebP로 인코딩했다. 필터만 씌운 가짜 화풍 전환은 사용하지 않았다.

공통 프롬프트 핵심: 조용한 저판타지 여관, 오후 햇빛, 목재와 회벽, 왼쪽 위 카운터와 여성 주인, 뒤쪽 중앙 게시판, 오른쪽 계단, 왼쪽 아래 식탁과 의자 두 개, 오른쪽 아래 출입문. 같은 시점·물건 크기·위치를 유지하며 소년 아바타·문자·UI·추가 인물은 넣지 않는다.

A: 절제된 회화적 수채/과슈, 생활 재질과 자연스러운 빛.
B: 고전 16비트풍 픽셀 덩어리·계단형 윤곽·제한된 색과 타일 같은 바닥. 정식 타일셋/애니메이션 파이프라인을 구현한 것은 아니다.
C: 갈색 손그림 윤곽·넓은 색면·단순한 음영·둥근 가구와 인물·크림/세이지/테라코타. 사실적인 나뭇결은 줄인다.

## 비교 판단

| 화풍 | 장점 | 한계 |
|---|---|---|
| A | 기존 방과 연결이 가장 자연스럽고, 빛·재질이 머무는 감각을 만든다. | 작은 화면에서 사물과 배경의 경계가 약하다. 사물 상태별 그림 제작·정합성 관리가 필요하다. |
| B | 조작 가능한 게임 공간이라는 인상이 강하고 윤곽이 뚜렷하다. | 기존 지도·방·SVG 초상과 단절이 가장 크다. 이번 그림은 타일셋이 아니므로 실제 제작 효율은 아직 검증하지 않았다. |
| C | 작은 화면에서 사람·사물의 형태가 빠르게 읽히고, 공간의 따뜻함도 남는다. | A의 재질감이 줄며 인물이 더 어려 보인다. 장기 채택 시 성인 비례와 지역별 분위기를 추가 검증해야 한다. |

**우선 추천은 C를 다음 공간 상호작용 실험의 기준으로 삼는 것.** 공간 속 사물의 명료함과 삽화의 온기를 함께 확보한다. 기존 자산과의 즉각적 연결이 더 중요하면 A가 유리하다. 어느 쪽도 본편 교체 승인으로 취급하지 않는다. B는 픽셀 타일셋과 캐릭터 애니메이션까지 시험해야 제작 비용을 공정하게 판단할 수 있다.

## 검증과 남은 사용자 검수

- 로컬 빠른 콘텐츠 게이트 `node tools/verify-content.cjs` 통과.
- Cloud Chrome 고정 375×812 / 375×640 iframe에서 실제 배경·대사·뜻·방 사물 조회·방 문 복귀·집중형 이야기 확인. iPhone 기기 에뮬레이션이나 Safari 실행 결과로 해석하지 않는다.
- 375×640에서 번역 시 다음 버튼이 하단에 걸쳐 장면 높이를 추가로 줄였다. 문장이 더 길거나 화면이 더 짧으면 페이지 스크롤로 접근한다.
- `tests/smoke_inn_style.py`: CI Chromium 모바일/터치 설정, 3화풍 × 4뷰포트(375×812, 375×640, 390×844, 320×568), 스타일 전환의 대사·번역 보존, 방/이야기/출입문 왕복, 사물 조회, 44px 터치 영역, 수평 넘침, 저장 API 쓰기 0회 검증.
- 기존 Pages 워크플로에 비교 검사를 추가했으며 기존 본편 회귀 검사는 유지한다. 실제 CI·배포 결과는 작업 완료 보고에서 별도로 확인한다.
- `inn-style-test/review.html`에서 동일 크기 A/B/C를 나란히 볼 수 있다. `evidence/`는 고정 뷰포트 비교 캡처다.

실제 iPhone Safari 사용자 검수: 손가락으로 사물 발견이 쉬운지, 공간에 머무는 느낌, 대사 읽는 동안 시선 이동, 기존 방과의 화풍 단절, C의 성인 인물 인상이 적절한지 확인한다. 사용자 실기기 검수는 아직 완료하지 않았다.
