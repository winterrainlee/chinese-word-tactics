# 여관 C 통합 시험판 v0.1

기준 main: `5009fde101095fafe7d6f8aea064d134641db3d0`. 기능 브랜치: `feature/inn-c-integration-20261101`.
본편은 그대로 두고 `/inn-integration-test/`에 별도 실행 사본을 배포한다. 실기기 승인 전 본편 병합은 하지 않는다.

## 이동과 사건

- 처음 들어가면 소년의 방, 재방문은 로비다. 방 문·상단 복귀는 로비, 계단은 방, 로비 출입문·상단 복귀는 월드맵이다.
- `innVisited`는 여정 저장에 추가한 선택적 boolean이다. 방/로비 실제 진입에 기록한다. 백업 형식과 논리 키는 유지한다.
- 옛 저장은 방 결말 이야기 또는 큰비 이후의 실제 진행 증거가 있으면 재방문으로 이행한다. 구형 world `visited`의 명시적 `inn`/`innRoom`도 인정한다. M4 해금만으로 방문을 추측하지 않는다. 방문 증거를 저장하지 않았던 초반 사용자는 방을 한 번 더 볼 수 있다. 이야기·보상·완료 상태를 추가하지 않는다.
- 게시판=`FirstFreeQuest.boardUnlocked`, 큰비=`JourneyProgress.hasRainPassed`, 새 의뢰=`NorthForestWorld.hasNewBoardQuest`. 서로 독립적으로 판정하며 새 종이는 게시판이 있을 때만 표시한다.
- 첫 부탁/보고/게시판은 기존 동작을 재사용한다. 지도 진입에서 선점하던 부탁/보고 창은 로비 주인에게 옮긴다.
- 1장 결말 대화는 주인에게 연결하고 마지막에는 기존대로 방에 돌아온다. 큰비 전 방을 나가면 기존 이야기를 재생하고 로비에 도착한다. 부탁은 이후 주인에게 말을 걸어 확인한다.

## 책임과 보존

`inn-layer-test/scene.json`의 안정 ID, 승인 자산, 배치, 조건, 가림, 터치 영역을 사용한다. 원본 C 시험판은 수정하지 않는다. `inn-lobby-runtime.js`가 실제 진행을 표현 상태로 변환하고 기존 의뢰 함수를 호출한다. 원래 시험판의 임시 수건 의뢰 대사는 가져오지 않는다.

## 저장 격리와 배포

`game-storage.js`는 기본 브라우저 저장 어댑터다. 모든 게임 저장 접근은 이 어댑터를 거친다. 시험판은 모든 게임 스크립트보다 먼저 `bootstrap.js`에서 `cwt-inn-integration-v1:` 접두어를 붙이는 어댑터를 제공한다. 브라우저의 Storage API 자체를 덮어쓰지 않는다. 본편 기록을 자동 복사하거나 읽지 않는다. 백업은 기존 논리 키로 만들어지고 시험판에서 가져오면 시험 저장에만 복원된다.

`tools/build-inn-integration-test.py`는 기능 브랜치의 HTML·src·icons·images·data 및 로비 모바일 그림을 자체 경로로 묶는다. 외부 본편 코드로 향하는 base URL을 쓰지 않는다. `version.json`에 기준·기능 커밋, `manifest.json`에 파일 해시를 남긴다. 시험 장면 전환은 시험 기록만 바꾸며 확인 후 실행한다.

main 변경은 시험판 디렉터리와 그 시험판의 브라우저 검사를 호출하는 deploy workflow 단계로 한정한다. root src/index/images 및 기존 시험판은 변경하지 않는다.
