# 아이콘 선택 확정안 v0.1

> 확정일: 2026-09-10
> 제품 기준: v0.5 월드맵이다. 이번 결정으로 게임 버전을 올리지 않는다.
> 승인 근거: A/B/C 비교 시안에 대한 추천표를 검토한 뒤 사용자가 “좋아. 이렇게 가자.”라고 승인했다.
> 승인 범위: 아래 형태 선택과 명시된 수정 방향이다. 완성 자산, 최종 색상값, 실제 크기 가독성, 런타임 적용 또는 실기기 검수의 승인이 아니다.

**그림의 정서는 따뜻하게, 기능의 구분은 엄격하게 만든다.**

## 1. 문서와 시안의 관계

[디자인 원칙](DESIGN-PRINCIPLES-v0.1.md)은 공통 판단 기준이고, [아이콘 시스템](ICON-SYSTEM-v0.1.md)은 코드 실태 목록과 제작·검수 기준이다. 그 문서에 남아 있는 ‘추천 형태’와 ‘시안 전’ 상태는 최초 기획 기록으로 읽는다. 이후 승인된 개별 형태 선택은 이 문서를 우선하고, 현재 진행 상태는 [개발 상황판](DEVELOPMENT-STATUS.md#디자인-준비)에서 확인한다.

기준 이미지는 대화에서 공유한 「번체 중국어 단어 전술게임 — 아이콘 시안 v0.1」이다. A/B/C는 각 항목 안에서 왼쪽부터의 후보를 가리킨다. 이전의 디자인 원칙 포스터와 혼동하지 않는다.

- 원본 파일명은 `a_clean_illustrated_icon_design_sheet_concept_bo.png`다.
- 이미지 크기는 1312×1199px이다.
- 원본 SHA-256은 `2531e2e7140f35bf3bf56a6701ca191318aab03a3f41e258e80f3d9cf7f1a63e`다.

이번 문서 변경에 원본 PNG나 개별 그림 파일을 추가하지 않았다. 원본은 대화의 첨부 이미지이며, 아래 표에 선택한 형태와 수정 조건을 함께 남겨 문자 A/B/C만으로 제작을 지시하지 않도록 한다.

시안 전체를 제품 사양으로 채택한 것은 아니다. 이미지 안의 날짜, 구호, 예시 색상값, 라벨, 제외한 후보는 자동으로 승인되지 않는다. 실제 목표어·주음·지명·예문은 기존 데이터 원문을 유지한다. 수정 조건이 있는 항목은 원본을 그대로 잘라 쓰지 않는다.

## 4. 상태와 표시 선택

| 항목 | 선택 | 채택할 형태와 제작 조건 |
|---|---|---|
| 이동 가능 | B | 방향 꺾쇠 기본형을 상하좌우로 회전한다. 이번 행동에 이동할 수 있는 인접 칸만 나타내며, 정답 경로나 이후 모든 턴의 안전을 뜻하지 않는다. |
| 선택됨 | C, 색 수정 | 네 모서리 표식을 채택한다. 금색 대신 녹색 계열로 바꿔 목표·단어 반응과 분리한다. 인물이나 지형을 덮지 않는다. |
| 위험 범위 | B, 투명도 조정 | 사선무늬 면을 채택한다. 바닥이 비쳐 보이도록 옅게 만들되 위험 경계를 읽을 수 있게 한다. 표시 범위는 실제 판정과 일치시킨다. |
| 목표 / 중요 | B, 용도 제한 | 반짝임은 석비 활성화 등 단어가 세계에 반응하는 순간에 제한한다. 목적지는 깃발, 목표 조건은 텍스트로 구분한다. 모든 중요 정보에 반짝임을 붙이지 않는다. |
| 조사 가능 | C, 배치 제한 | 조작 버튼과 같은 돋보기 의미를 채택한다. 모든 칸에 반복하지 않고 조사 대상이나 모드 표시에 제한한다. |
| 잠김 / 진행 불가 | B, 용도 분리 | 닫힌 자물쇠를 지역 해금 조건에만 쓴다. 기록이 없어 쓸 수 없는 되돌리기는 자물쇠가 아니라 일반 비활성 상태로 나타낸다. |

선택의 모서리, 위험의 사선 면, 이동의 방향 기호는 함께 있어도 서로 다른 정보로 읽혀야 한다. 색만 달리한 사각형으로 통일하지 않는다.

방문과 실제 완료, 선행 추천과 진입 잠금은 계속 구분한다. 현재·다음 위험 예고, 잠금 이유 확인 경로처럼 새로운 정보 표시가 필요한 기능은 아이콘을 골랐다는 이유로 구현 완료 처리하지 않는다.

## 6. 제작 전에 반드시 반영할 수정

1. 용사·늑대의 잔선을 줄여 작은 크기의 형태를 정리한다.
2. 출구 깃발은 목표용 금색 계열, 선택 모서리는 행동용 녹색 계열로 구분한다. 최종 hex 값은 아직 확정하지 않는다.
3. 문은 A 기반의 같은 문틀로 열림·닫힘 쌍을 만든다.
4. 유적 A는 연결된 통로로 읽히도록 중앙과 바닥을 정리한다.
5. 기다리기 A는 제자리의 두 발로 수정하고 문구를 유지한다.
6. 공방 B에는 굴뚝 하나를 더한다.
7. UI의 비교용 배경 상자를 제거하고 선 굵기와 크기를 통일한다.
8. 위험 사선의 투명도와 다른 표시와의 겹침을 확인한다. 금색 반짝임은 단어 반응에 제한한다.

위 조건은 선택안에 포함된 제작 지시다. 수정된 실물이 완성됐거나 작은 화면에서 검증됐다는 뜻은 아니다.

## 7. 적용 범위와 다음 제작 단위

이번 승인으로 비교 이미지의 30개 항목 묶음에 대한 선택 방향을 기록했다. 그러나 첫 런타임 교체 범위를 한꺼번에 늘리지 않는다.

첫 제작은 [아이콘 시스템](ICON-SYSTEM-v0.1.md#10-첫-제작-묶음과-순서)의 기본형 15종을 유지한다. 세계 7종은 용사·늑대·출구·석비·문·유적·가시이고, UI 7종은 메뉴·뒤로·다시 시작·되돌리기·기다리기·살펴보기·닫기이며, 상태 1종은 이동 가능 표식이다. 문 열림/닫힘 등 필요한 변형은 함께 만든다.

수풀·바위, 추가 상태, 다음/확인, 지역 표식은 후속 묶음이다. 시안에 바위나 다음 버튼이 있다는 이유로 새 지형 규칙이나 불필요한 조작을 추가하지 않는다.

다음 제작 산출물은 이 선택과 수정 조건을 반영한 개별 자산 및 실제 크기 비교판이다. UI 20 CSS px, 사물은 기존 칸 크기 안에서 비교하고 흑백·겹침 상태도 함께 확인한다. SVG를 우선 검토하되 그림의 따뜻한 인상과 필요한 실루엣을 보존한다. 다른 형태나 상태 의미로 바꾸는 변경은 새 결정으로 기록한다.

최종 선택 후의 화면 작업은 자산 교체 → 튜토리얼 회귀 확인 → iPhone 13 mini Safari 검수 순서로 진행한다. 아이콘 교체와 전체 레이아웃 개편을 한 번에 섞지 않는다. `legacy/tutorial-v03.html`, 게임 판정, 단어 데이터와 진행 저장 키는 유지한다.
