# 아이콘 자산 제작 v0.1

제작일은 2026-09-10이다. [선택 확정안](ICON-SELECTION-v0.1.md)의 첫 기본형 15종을 수정 가능한 SVG로 재제작했다. 승인한 것은 선택과 수정 방향이며, 이번 개별 제작본의 외형은 아직 사용자 검토 전이다. 게임은 v0.5를 유지한다.

## 산출물

[아이콘 폴더](../icons/)에 개별 SVG 16개, 동일한 16개 심벌을 묶은 `sprite.svg`, `manifest.json`, [사용 안내](../icons/README.md), [검토 페이지](../icons/preview.html)가 있다. 문 열림·닫힘 두 파일이 하나의 기본형이므로 기본형은 15종이다. SVG 배경은 투명하며 단어·주음·지역 이름을 그림 안에 넣지 않았다.

| 계열 | 이번 제작 내용 |
|---|---|
| 세계 | 용사 B, 늑대 B, 금색 깃발 B, 석비 C, 같은 문틀의 문 A 열림·닫힘, 연결 통로용 유적 A, 가시 A를 제작했다. |
| UI | 메뉴 A, 뒤로 C, 재시작 A, 되돌리기 A, 제자리에 나란히 선 두 발 A, 돋보기 A, 닫기 A를 제작했다. |
| 상태 | 이동 가능 B를 오른쪽 기본형으로 만들었다. 검토 페이지에서 상하좌우 회전을 보여준다. |

수풀·바위·지역 건물·별도의 잠금·위험 범위 아이콘은 이번 제작 묶음에 없다. 석비의 반응과 유적 통과 흔적은 동일 자산 위의 별도 검토용 표시이며 새 게임 기능이 아니다.

## 시안에서 제작본으로 옮긴 기준

큰 비교 이미지의 수채 질감과 작은 장식을 그대로 옮기지 않고, 32px에서 구분할 윤곽과 주요 색 면을 벡터로 다시 구성했다. 자동 추적이나 포스터 조각이 아니다. SVG 제작은 선택 방향을 구현한 첫 해석이며 원본과 픽셀 단위로 동일한 결과를 보장하지 않는다.

용사는 초록 망토와 얼굴을, 늑대는 정면 윤곽과 밝은 주둥이를 남겼다. 출구는 돌 받침이 없는 금색 깃발이다. 문은 두 상태의 문틀이 XML 수준에서 동일하며 열린 중앙이 투명하다. 유적은 낮은 기둥과 빈 중앙을 사용하고, 여러 칸의 연결은 별도 바닥 층으로 보여준다. 기다리기는 걷는 순서나 모래시계가 아닌 나란한 신발 밑창 형태다. UI는 배경 없는 `currentColor` 기호로 제작했다.

임시 색상값을 SVG 안에 제공했지만 제품 전체의 최종 색 토큰을 확정하지 않았다. 석비의 각인색은 심벌 또는 인라인 사용 시 `--cwt-rune`으로 바꿀 수 있다. `出口` 같은 필요한 글자는 사용 코드에서 별도로 유지한다.

## 검토 페이지

검토 페이지는 게임 화면을 대체하지 않는다. 세계 아이콘을 32px·64px, UI를 20px·40px로 나란히 놓는다. 흑백과 어두운 바탕을 전환할 수 있고 48px 칸에서 출구·유적 위의 용사, 문 상태 쌍, 석비 반응, 연속 유적 바닥을 비교한다.

기본 칸 크기, 바닥 연결, 반응 표시와 버튼 행은 정적 검토용이다. 기존 엔진과 연결된 시뮬레이션이 아니며, 이동 가능 표시나 통과 완료를 임의로 판정하지 않는다. 이 페이지의 흑백/어두운 바탕 전환은 완성된 게임 접근성 또는 다크 모드의 구현을 뜻하지 않는다.

## 확인한 것과 남은 것

`python3 tools/validate_icons.py`로 SVG XML·해시·기본형 수·파일 수·심벌 중복·개별 파일과 심벌 일치·문틀 동일성·외부 리소스와 스크립트 부재·검토 페이지의 모든 아이콘 참조를 검사한다. `node --check icons/preview.js`로 검토 스크립트 문법을 검사한다.

렌더 확인은 같은 심벌을 인라인으로 넣은 휴대용 검토 페이지에서 Chromium으로 수행했다. 375×660, 390×844, 1100×900 뷰포트에서 페이지의 가로 넘침, 최소 44px 버튼 영역, JS 오류, 흑백·바탕 전환을 확인했다. 이는 iPhone 실기기 검수와 다르다. 투명 PNG 내보내기는 SVG 제작본에서 렌더한 보조 산출물이며 Git 원본은 SVG다.

컨테이너의 로컬 HTTP 주소 접근이 브라우저 정책으로 차단되어, 이 환경에서는 실제 HTTP 경로의 외부 `sprite.svg` 로딩을 확인하지 못했다. 파일 참조의 존재와 심벌 ID는 검사했지만 실제 GitHub Pages 외부 심벌 로딩·Safari 호환성은 별도 확인해야 한다.

| 단계 | 상태 |
|---|---|
| 개별 SVG와 심벌 제작 | 1차 제작본을 만들었다. |
| 구조 검사·인라인 Chromium 렌더 | 실행했다. 검사 결과는 `icons/validation.json`에 기록한다. |
| 사용자 외형 검토 | 아직 하지 않았다. |
| 실제 Pages 외부 심벌 로딩 | 아직 하지 않았다. |
| 게임 연결·튜토리얼 회귀 검수 | 아직 하지 않았다. |
| iPhone 13 mini Safari 검수 | 아직 하지 않았다. |

## 유지한 범위

`index.html`, `src/`, 단어·스테이지 데이터, 저장 키와 `legacy/`는 변경하지 않았다. 외부 프레임워크·아이콘 세트·폰트 파일을 추가하지 않았다. 다음 단계는 제작본을 검토한 뒤 자산만 연결하고 튜토리얼과 실기기를 별도로 검수하는 것이다.
