## 상태와 검수

기존 본선 상태·ID는 유지한다. 03A는 `ran-observation` 스키마 1로 발견 선택, 비교 배치, 적용 선택, 방문 시점을 저장한다. 잘못된 선택은 지우지 않고 해당 조작에 포커스를 돌린다. 선택·뜻 조회는 무료이며 되돌리기와 재플레이 분리를 유지한다. 처음 들어온 04에서는 03A 완료 여부에 따른 짧은 문맥 안내를 표시한다.
