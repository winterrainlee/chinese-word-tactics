## 파일별 책임

- `journey-content.js`에는 자체 작성한 번체·한국어 대사와 장/지역의 노드 참조만 둔다.
- `journey-progress.js`는 진행 판정, 기존 완료 기록의 합치기, 별도 저장 키를 담당한다.
- `story-runtime.js`와 `journey-runtime.js`는 화면을 그린다.
- `flow-runtime.js`가 화면 이동과 최초 진행/replay의 연결을 맡는다.
- `app.js`는 기존 전술 규칙을 유지하고 `TacticalGame`으로 실행·복귀·완료를 연결한다.
- 새 프레임워크와 서버는 추가하지 않는다. 모든 자원은 상대 경로로 연결한다.

## 저장과 잠금의 구체 규칙

기존 두 키는 삭제하지 않는다. 새 키 `chinese-word-tactics-journey-v1`에 실제 본 이야기, 완료 판, 확인한 노드, 본편 위치만 기록한다. 목록은 중복 제거하며 잘못된 JSON/필드/저장소 접근 실패에도 앱은 메모리에서 계속 동작한다.

`lastLocation`은 현재 탐색 화면이 아니라 **본편 이어가기 위치**다. 재독과 재플레이는 새 저장 및 기존 튜토리얼 저장을 쓰지 않는다. 여정에서 아직 완료하지 않은 열린 판을 연습해도 본편 완료로 바꾸지 않는다. 본편을 진행하려면 여정의 `이어서 여행하기`를 사용한다.

튜토리얼 판은 앞 판의 완료로 열린다. 도입 이야기를 읽지 않았다는 이유로 stage-0을 잠그지 않는다. 기존 완료 사용자에게 새 이야기를 읽었다고 표시하지 않으며, 이미 완료한 판은 이어가기에서 건너뛴다. 지역 방문과 핵심 의뢰 완료는 구분한다. 세 핵심 milestone이 모두 있어야 주인공 역할을 용사로 계산한다. 대용사 조건은 아직 만들지 않는다.

## 중도 이탈과 완료 처리

이야기는 대사 위치를 보존하되 번역 열림 상태는 보존하지 않는다. 마지막 대사를 표시한 것만으로 완료 처리하지 않고, 마지막 진행 버튼을 눌러야 seen을 기록한다. 처음 보는 이야기에는 장면 스킵을 보여주지 않으며 메뉴로 나갈 수 있다.

전술 완료 지연 callback은 화면 이동·다른 판 시작·되돌리기로 취소한다. 완료 직후 연속 탭으로 중복 기록하거나, 여정 위에 이전 판의 완료 시트가 뜨지 않게 한다.

1. Node 기본 테스트: 마이그레이션, 잘못된 저장, replay 불변성, 노드 잠금, 다음 노드, 역할 계산을 검사한다.
2. 실제 브라우저 자동 검사: 신규/기존 사용자, 이야기 번역·중단·재독, 필터, 여섯 판 해법, 위험 거부·기다리기·살펴보기·되돌리기·단어 카드, 새로고침 및 중복 완료를 검사한다.
3. 375×812와 좁고 낮은 세로 화면에서 버튼·넘침을 검사한다. `/chinese-word-tactics/` 경로로 정적 자원을 로드한다.
4. iPhone 13 mini Safari 실기기는 별도 검수한다. 자동 검사를 실기기 통과로 기록하지 않는다.

## 결과

0A~0D 및 1을 구현했다. 단계 2는 미착수다. 원래 기획서와 전술 콘텐츠/아이콘/실험판은 변경하지 않았다. 지역 간 자동 진행은 `nextSectionId`로 명시한 연결에만 허용하며, 세 병렬 지역을 강제로 순서대로 진행시키지 않는다.

검증 결과:

- `node --test tests/journey-progress.test.cjs`: 12개 통과했다.
- `BROWSER_TEST_MODE=memory python tests/smoke_journey.py`: 13개 시나리오를 통과했다. 기존 6판을 실제 DOM 클릭으로 최초 진행 및 재플레이에서 각각 해결했다.
- `python tools/validate_icons.py`: 기존 SVG 검사에 통과했다.
- 모든 `src/*.js`의 문법 검사에 통과했다.
- 375×812, 360×640, 375×667, 390×844 화면을 검사했다. 긴 대사 15개짜리 테스트 장면에서도 하단 조작이 유지됐다.

중요한 검증 경계: 실행 환경에서 HTTP 탐색이 차단되어 Chromium의 메모리 HTML 렌더링과 테스트용 Storage를 사용했다. 새로고침은 저장 fixture를 새 페이지에 복원하는 방식으로 검사했다. 실제 HTTP 자원 전달, 네이티브 localStorage 지속성, iPhone Safari 실기기 통과를 의미하지 않는다. 테스트 스크립트의 기본 모드는 일반 환경용 로컬 HTTP이고, `memory` 모드는 네트워크 없는 보조 검사다.
