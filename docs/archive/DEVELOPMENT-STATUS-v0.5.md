### 영 스크린 레이아웃 보정 원칙

- 3갈래 월드 트리 구조는 유지한다.
- 세 칸짜리 노드 안에서는 아이콘과 제목을 가로로 놓지 않는다.
- 지역 노드는 **상태 → 아이콘 → 한글 이름 → 한자 → 짧은 설명** 순으로 읽힌다.
- 지역 이름은 카드 폭에 맞추려고 의미를 축약하지 않는다.
- 390px 이하에서는 아이콘·글자·간격을 한 단계 줄이고, 360px 이하에서 한 번 더 줄인다.
- 카드 밖으로 콘텐츠가 삐져나가지 않게 노드 내부 폭을 100%로 고정한다.
- 2026-09-10 iPhone Safari 재검수에서 카드 경계, 연결선, 이름, 아이콘 정렬을 확인했다.

## 지역별 기획 깊이

세부 서사는 `TIER1-STORYLINE-v0.1.md`를 기준으로 한다.

### 길목（關口鎮）— 길을 읽는 곳

상태: **1차 스토리라인·학습 축 기획 완료 / 구현 전**

첫 묶음:

1. `문 안쪽` — `進入 / 退出`
2. `종소리가 닿는 곳` — `距離 / 範圍`
3. `두 갈래 길` — `路線 / 經由`
4. `바퀴가 걸린 자리` — `位置 / 周圍 / 障礙`
5. `좁은 성문` — `移動 / 前進 / 後退`
6. `길을 잃은 짐수레` — `跟隨 / 帶領`
7. `해 지기 전` — 종합

지역 결말: 북쪽 길을 다시 열고 **끝마을**을 다음 추천 목적지로 연결한다.

첫 판 핵심 판정:

- 밖 → 영역 안: `進入`
- 영역 안 → 밖: `退出`
- `通過`과 달리 같은 입구로 되돌아 나와도 `退出` 성립
- 정답 이동 순서를 강제하지 않고 목표 상태만 판정

### 장인골（工坊村）— 상태를 바꾸는 곳

상태: **1차 스토리라인·학습 축 기획 완료 / 구현 전**

주요 축:

- `改變 / 保持`
- `增加 / 減少 / 調整`
- `集中 / 分配`
- `條件 / 允許 / 禁止`
- `維持 / 出現`
- `破壞 / 消失 / 恢復`
- 중심 장치 종합 스테이지

지역 결말: 오래된 장치의 제작 흔적을 발견해 **학술도시**를 실제 해금한다.

아직 장치 UI, 수치 규칙, 실제 맵은 만들지 않았다.

### 장터（市集鎮）— 자원을 고르는 곳

상태: **1차 스토리라인·학습 축 기획 완료 / 구현 전**

주요 축:

- `需求 / 足夠 / 缺少`
- `資源 / 數量 / 剩下`
- `交換 / 取得 / 獲得`
- `價值 / 效果 / 費用`
- `價格` 중심 일반 어휘형 의뢰
- `分配 / 公平 / 付出 / 負擔`
- 장날 종합 스테이지

영구 경제나 반복 파밍은 만들지 않는다. 자원은 판 안의 퍼즐 상태로만 사용한다.

지역 결말: 분배 규칙과 부담 문제를 **회의소**의 첫 본격 의뢰로 넘긴다.

### 끝마을（邊境村）

상태: **방향 기획만 완료**

- 입장은 처음부터 가능하게 둘 수 있음
- 길목을 선행 추천하지만 강제하지 않음
- 위험 범위·손실·경로 퍼즐 중심
- 구체 스테이지 순서와 맵은 아직 없음

### 회의소（議會鎮）

상태: **방향 기획만 완료**

- 입장은 처음부터 가능하게 둘 수 있음
- 장터 완료 후 본격적인 첫 의뢰가 생기는 흐름
- `接受 / 拒絕 / 支持 / 反對 / 公平` 등 관계·판단 어휘 중심
- 전술 격자 + 대화/정보 확인 혼합 예정
- 구체 스테이지 순서와 UI는 아직 없음

### 학술도시（研究城）

상태: **역할과 해금 조건만 기획**

- 장인골 핵심 시험 완료 후 해금
- 초기 단계의 첫 큰 이정표
- 이전까지의 단어를 비교·조건 판단·추론 도구로 확장
- 실제 스테이지는 아직 설계하지 않음

### v0.6-1 — 프롤로그에서 「세 갈래 길」로

완료 조건:

### v0.6-2 — 길목 `문 안쪽` (`進入 / 退出`)

완료 조건:

- 길목 첫 방문 story에서 길지기의 부탁을 받는다.
- 이야기 종료 후 `문 안쪽` 스테이지가 바로 시작될 수 있다.
- 지정 영역의 외부→내부 이동을 `進入`으로 기록한다.
- 내부→외부 이동을 `退出`으로 기록한다.
- 같은 입구로 되돌아 나와도 `退出`이 성립한다.
- `通過`과 다른 판정이라는 점이 플레이로 드러난다.
- 단어 뜻은 언제든 조회할 수 있다.
- 정답 이동 순서를 강제하지 않는다.
- 클리어 후 짧은 결과 이야기가 다음 스테이지 이유를 만든다.
- iPhone 13 mini Safari에서 한 화면 플레이가 가능하다.
