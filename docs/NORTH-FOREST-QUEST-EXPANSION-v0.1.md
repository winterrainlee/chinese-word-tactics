핵심 목표는 두 가지다.

1. 소년이 물길마을 사람들과 주변 생활권에 더 익숙해진다.
2. 1장에서 배운 단어를 반복하면서, 이후 장에서 쓸 수 있는 B1 중심 어휘를 충분히 늘린다.

## 1. 북쪽 숲의 역할 변경

현재 C08에서 북쪽 숲은 첫 자유 의뢰를 가르치는 장소다.

- 여관 주인의 부탁
- 월백버섯 3개 채집
- 귀환·보고
- 의뢰 게시판 설치

이 첫 의뢰의 학습어는 모두 1장 어휘의 재사용이다.

`範圍 / 數量 / 不足 / 足夠 / 獲得 / 退出`

이 구조는 그대로 유지한다.

이후 북쪽 숲은 단순한 채집 장소가 아니라 **물길마을 사람들이 실제로 이용하는 주변 생활권**으로 확장한다.

- 북쪽 숲을 오가는 채집인은 숲길과 표식의 현재 상태를 안다.
- 장인골에서는 숲에서 얻는 재료가 필요하다.
- 장터 사람은 숲길을 통해 물건과 수레를 오간다.
- 여관은 가까운 식재료를 얻는다.

소년이 이 부탁들을 하나씩 경험하면, 물길마을이 더 이상 “처음 도착한 마을”이 아니라 **누가 무엇을 하는지 알고, 어디로 가면 되는지 아는 장소**가 된다.

## 2. 전체 분량

북쪽 숲 묶음은 F1을 포함해 **8판으로 구현되었다.**

| 의뢰 | 실제 의뢰 출처 | 판 수 | 역할 |
|---|---|---:|---|
| FQ01 북쪽 숲의 버섯 | 여관 주인 | 1 | 기존 C08. 자유 의뢰 루프와 1장 어휘 재사용 |
| FQ02 숲길의 표식 | 여관 게시판에서 소개받은 채집인 | 2 | 방향·표식·확인의 언어 |
| FQ03 장인이 찾는 재료 | 장인골 장인 | 2 | 특징 비교와 용도에 맞는 재료 판단 |
| FQ04 사라진 꾸러미 | 채집인 | 2 | 흔적을 따라 잃어버린 물건을 찾는 언어 |
| FQ05 오늘의 숲길 | 채집인과 장터 수레 | 1 | 숲 생활권의 길 상황과 안전을 판단하는 종합 의뢰 |

총 8판이다.

북쪽 숲을 본편의 네 번째 지역으로 바꾸지는 않는다.  
여전히 `자유 의뢰 · 물길마을 주변 → 북쪽 숲` 아래에 독립된 의뢰들이 누적된다.

## 3. FQ01 — 북쪽 숲의 버섯

현재 구현을 유지한다.

### 이야기 역할

- 소년은 숲 전문가가 아니다.
- 여관 주인이 생활형 심부름 하나를 처음 맡긴다.
- 처음으로 기존 길에서 조금 벗어나 북쪽 숲 바깥쪽을 살펴본다.
- 완료 뒤 의뢰 게시판이 설치된다.

### 학습 역할

새 목표어를 넣지 않는다.

기존 단어를 다른 문맥에서 다시 사용한다.

- 範圍
- 數量
- 不足
- 足夠
- 獲得
- 退出

이 판은 이후 확장을 위한 **복습과 자유 의뢰 시스템의 기준선**이다.

## 4. FQ02 — 숲길의 표식

### 의뢰인

여관 게시판에 메모를 남긴 북쪽 숲 채집인.

여관 주인이 메모와 채집인을 소개하고, 소년은 여관 창가에서 채집인에게 직접 확인 범위를 묻는다. 새로운 사람이 소년의 평판을 듣고 찾아오는 구조가 아니라, 게시판과 기존 생활권을 통해 실제 의뢰인을 만나는 흐름이다.

### 사건

숲길의 방향 표식 몇 개가 기울거나 가려져 있다.

소년은 표식을 무조건 고치는 것이 아니라 먼저:

- 어느 방향을 가리키는지
- 실제 길과 맞는지
- 무엇을 확인해야 하는지

를 판단한다.

### F2 확정 핵심어

- `標記` — 표식
- `方向` — 방향
- `確認` — 확인하다

기존 재사용:

- 位置
- 路線
- 經由
- 距離

### F3 확정 핵심어

- `正確` — 정확하다 / 올바르다
- `指示` — 가리키다 / 지시

앞 판의 `標記 / 方向 / 確認`을 다시 사용한다.

### 학습 포인트

1장에서는 “어느 길로 가는가”를 배웠다면, 여기서는 **길에 있는 정보가 올바른가**를 확인한다.

특히 `確認`은 이후 북쪽 숲과 끝마을에서 계속 재사용할 핵심 연결어로 삼는다.

## 5. FQ03 — 장인이 찾는 재료

### 의뢰인

장인골의 기존 장인.

소년은 공방 일을 이미 도왔고 수리패도 받았다.  
장인이 숲 가까이에서 구할 수 있는 작은 재료를 부탁하는 것은 기존 관계의 연장이다.

### 사건

겉보기에는 비슷한 식물이나 재료 후보가 여러 개 있다.

목표는 이름 맞히기 퀴즈가 아니라 **특징과 쓰임에 맞는 대상을 구별하는 것**이다.

예:

- 잎 모양이 비슷하지만 줄기의 특징이 다르다.
- 같은 종류처럼 보이지만 한쪽만 작업에 적합하다.
- 특정 환경에서 자란 재료만 필요한 성질을 가진다.

F4는 잎의 `深綠色 / 長 / 尖` 세 특징을 비교하고, F5는 물가에서 자란 길고 가는 덩굴 두 개를 재료로 고른다.

### F4 확정 핵심어

- `特徵` — 특징
- `相似` — 비슷하다
- `不同` — 다르다
- `分辨` — 구별하다

`相似 / 不同`은 하나의 대비 묶음으로 제시한다. 비슷해 보이는 후보에서 어느 특징이 다른지 말한 뒤 구별하게 한다.

기존 재사용:

- 條件
- 符合
- 周圍
- 數量

### F5 확정 핵심어

- `材料` — 재료
- `適合` — 적합하다
- `生長` — 자라다 / 생장하다

앞 판의 `特徵 / 相似 / 不同 / 分辨`을 다시 사용한다. F5에서는 정답 견본 그림 없이 `長 / 細 / 生長在水邊 / 兩根`의 텍스트 작업 지시만 제공한다.

### 학습 포인트

“모양이 비슷하다”와 “조건에 맞는다”를 분리한다.

단순한 사물 이름보다 B1에서 활용도가 높은:

> 특징을 보고 비교한다 → 구별한다 → 용도에 맞는 것을 고른다

의 사고 언어를 익힌다.

## 6. FQ04 — 사라진 꾸러미

### 의뢰인

북쪽 숲 채집인.

채집인은 북쪽 숲을 나오기 전까지 갖고 있던 파란 천끈 꾸러미가 장터에 도착했을 때 사라진 것을 알아차린다.

### 사건

짐의 정확한 위치는 처음부터 주어지지 않는다.

소년은 길을 따라가며:

- 마지막으로 본 장소
- 주변에 남은 흔적
- 어느 방향으로 이동했는지
- 가까운 장소

를 확인한다.

### F6 확정 핵심어

- `遺失` — 잃어버리다
- `尋找` — 찾다
- `痕跡` — 흔적

기존 재사용:

- 位置
- 周圍
- 距離
- 路線

FQ02의 `方向 / 確認`도 재사용한다.

1판은 꾸러미 발견으로 끝나지 않는다. 관련 흔적이 이어지는 다음 수색 구역에 도달하고, “꾸러미는 아직 보이지 않는다”는 상태를 확인하는 데까지다.

### F7 확정 핵심어

- `發現` — 발견하다
- `附近` — 부근 / 근처
- `留下` — 남기다

앞 판의 `痕跡 / 尋找`을 다시 사용한다.

2판에서 꾸러미를 발견해 챙긴 뒤에는 채집인이 기다리는 숲 바깥쪽 길로 돌아가 건넨다. 발견만으로 끝내지 않는 이유를 목표와 이야기에서 명시한다.

### 학습 포인트

이 의뢰에서는 “정답 위치를 찾아 클릭한다”보다:

> 정보 확인 → 흔적 발견 → 다음 탐색 범위 좁히기

가 중요하다.

이 구조는 훗날 학술탑의 기록·근거·추론 학습으로 발전시킬 수 있지만, 여기서는 아직 생활형 탐색에 머문다.

## 7. FQ05 — 오늘의 숲길

### 의뢰인

북쪽 숲 채집인. 장터로 가져갈 작은 수레를 함께 살핀다.

이 시점의 소년은 북쪽 숲 바깥쪽을 여러 번 오갔다.

따라서 부탁의 근거는 “소년이 유명해졌다”가 아니라:

> **요즘 이 길을 몇 번 다녀와서 주변을 알고 있다.**

이다.

### 사건

북쪽 숲 주변에서 주민들이 이용하는 길의 현재 상태를 한번 확인한다.

위험한 모험이나 던전이 아니라 생활권의 길 상태 조사다.

서쪽은 마르고 넓지만 굵은 가지가 막고 있어 치운 뒤 수레가 지날 수 있다. 동쪽은 조금 멀지만 마르고 넓어 처음부터 안전하다. 가운데는 젖고 좁아 소년은 지나갈 수 있어도 현재 수레에는 위험하다.

### F8 확정 핵심어

- `情況` — 상황
- `安全` — 안전하다
- `危險` — 위험하다

재사용:

- 確認
- 方向
- 痕跡
- 路線
- 障礙
- 通過
- 避開
- 範圍

### 학습 포인트

이 판은 북쪽 숲 확장의 종합판이다.

소년은 단순히 목적물을 가져오는 것이 아니라, **길의 상태를 보고 다른 사람이 지나가도 되는지에 필요한 정보를 가져온다.**

아직 `允許 / 禁止 / 限制` 같은 끝마을의 규칙 어휘는 본격적으로 가르치지 않는다.

대신:

> 상황을 확인한다 → 안전/위험을 구별한다 → 필요한 경우 피한다

까지 경험한다.

이후 다른 지역의 규칙·통행 문제에서도 이 어휘를 재사용할 수 있다.

다만 **이 의뢰의 지리적 진행이 끝마을로 직접 이어지는 것은 아니다.**

중요한 목표는 **새 단어 수 자체보다 새 단어가 다음 의뢰에서 다시 살아나는 구조**다.

## 9. 재등장 원칙

북쪽 숲 확장에서는 처음부터 재등장을 설계한다.

### 핵심 연결어

`確認`

- FQ02에서 처음 목표어로 소개
- FQ03에서 특징 확인
- FQ04에서 흔적 확인
- FQ05에서 길 상태 확인
- 이후 끝마을에서 허가·조건 확인으로 확장

`方向`

- FQ02 표식 방향
- FQ04 흔적이 이어지는 방향
- FQ05 안전한 경로 방향

`特徵 / 分辨`

- FQ03에서 직접 학습
- FQ04에서 서로 다른 흔적을 구별하는 표현으로 재사용 가능

`痕跡 / 發現`

- FQ04에서 직접 학습
- FQ05에서 길 상태를 파악하는 단서로 재사용 가능

`情況 / 安全 / 危險`

- FQ05에서 직접 학습
- 끝마을의 통행 제한이 왜 생기는지 이해하는 기반으로 재사용 가능

### 기존 1장 어휘

북쪽 숲 전반에 다음 단어를 반복한다.

- 進入 / 退出
- 距離 / 範圍
- 路線 / 經由
- 位置 / 周圍 / 障礙
- 到達 / 避開 / 通過
- 條件 / 符合
- 數量 / 足夠 / 不足
- 獲得

따라서 북쪽 숲은 “새 단어만 더하는 장소”가 아니라 **1장 단어를 다른 생활 문맥에서 두 번째로 익히는 장소**가 된다.

## 10. 게시판과 실제 해금 흐름

첫 의뢰 완료 뒤 게시판이 생기는 기존 구조는 유지한다.

현행 해금 흐름:

```text
FQ01 월백버섯
  ↓
게시판 설치
  ↓
FQ02 숲길의 표식 ─┐
                    ├─ 둘 다 완료
FQ03 장인이 찾는 재료 ─┘
  ↓
FQ04 사라진 꾸러미
  ↓
FQ05 오늘의 숲길
  ↓
후일담 · 낯설지 않은 주변
  ↓
north-forest-familiar
```

FQ02와 FQ03을 동시에 열어, 게시판이 단순한 선형 스테이지 목록처럼 보이지 않게 한다.

FQ05는 북쪽 숲 생활권 자체를 마무리하는 종합 의뢰로 둔다.

## 11. 소년의 관계 변화

북쪽 숲 확장의 서사적 보상은 명성 수치가 아니다.

실제 부탁의 출처가 변한다.

### FQ01

여관 주인이 직접 처음 부탁한다.

> “이 아이가 여러 곳을 다녀왔으니 작은 일을 한번 맡겨 보자.”

### FQ02

여관 게시판의 메모를 통해 채집인을 소개받는다. 여관 주인이 의뢰 내용과 채집인이 있는 위치를 알려 주고, 소년이 여관 창가의 채집인에게 직접 세 표식의 확인 범위를 묻는다.

### FQ03

장인골 장인이 부탁한다.

> 공방을 도운 경험이 있으므로 필요한 재료의 이유를 설명해 줄 수 있다.

### FQ04

채집인이 장터에 도착한 뒤 파란 끈 꾸러미가 사라진 것을 알아차리고 부탁한다.

> 소년은 이제 장터와 북쪽 길 양쪽을 아는 사람이다.

### FQ05

채집인이 달라진 세 길의 상태를 함께 확인하고 장터까지 수레를 안내해 달라고 부탁한다. 소년이 북쪽 숲을 여러 차례 오가며 이 주변 생활권에 실제로 익숙해졌기 때문에 가능한 부탁이다.

이 과정을 모두 경험하면 소년은 더 이상 “물길마을에 막 도착한 여행자”가 아니다.

여관에 방이 있고, 세 구역에 아는 사람이 있으며, 북쪽 숲도 여러 번 다녀왔다.

북쪽 숲 묶음의 서사적 결말은 **다음 지역을 발견하는 것**이 아니라, 소년이 물길마을과 그 주변을 이제 제법 익숙한 곳으로 느끼게 되는 것이다.

## 12. 끝마을과의 관계

월드맵에서 **북쪽 숲과 끝마을은 서로 다른 방향의 장소**다.

- 북쪽 숲은 물길마을 가까이의 별도 생활권이다.
- 끝마을은 `길목 → 관문 바깥길` 축을 따라 이어지는 다음 정착지다.

따라서 북쪽 숲 확장은 끝마을로 가는 지리적 전초가 아니다.

북쪽 숲의 역할은 소년에게 다음 경험을 충분히 쌓아 주는 것이다.

- 물길마을 사람들에게 반복해서 부탁받는다.
- 같은 주변 장소를 여러 차례 오가며 익숙해진다.
- 길과 상태를 직접 확인하고 돌아와 설명한다.
- `確認 / 情況 / 安全 / 危險` 같은 판단 언어를 경험한다.

그 뒤 끝마을 이야기는 **길목 쪽에서 별도로 출발**한다.
소년이 다시 관문에 갔을 때 바깥으로 계속 이어지는 길과 사람·수레의 이동을 보며, 이제 익숙해진 물길마을을 잠시 떠나 더 먼 곳도 보고 싶다는 동기가 생길 수 있다.

즉 연결은 지리가 아니라 **소년의 성장과 학습 난도**에 있다.

---

## 13. 남은 결정과 검수

- 채집인의 이름·성별·나이·최종 외형
- 끝마을을 열기 위해 북쪽 숲 의뢰 완료를 필수로 요구할지 여부
- 길목에서 별도로 시작할 끝마을 출발 사건의 정확한 대사
- 이후 북쪽 숲 의뢰, 보상 물품 또는 방 장식 추가 여부

특히 **끝마을 메인 진행을 자유 의뢰 완료로 강제로 잠글지는 아직 결정하지 않는다.**
