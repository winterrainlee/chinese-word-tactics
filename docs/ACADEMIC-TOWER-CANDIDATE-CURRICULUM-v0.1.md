# 학술탑 담화 표지 후보·선수 관계 v0.1

> 상태: 후보 풀·기능 분류·선수 관계·우선순위 승인본 / 첫 연구 묶음 설계 연결
> 작성일: 2026-09-25
> 적용 범위: 학술탑의 문장 분할, 연결, 전환, 추론 학습 콘텐츠

## 1. 결정

학술탑은 정해진 판 수를 모두 끝내는 격파형 지역이 아니다.

- 전체 스테이지 수를 고정하지 않는다.
- `학술탑 완료`, `학술탑 격파` 같은 영구 상태를 만들지 않는다.
- 개별 방은 완료할 수 있다.
- 서로 연결된 학습 묶음은 `연구 묶음` milestone으로 기록할 수 있다.
- 새 접속 표현이나 복문 구조가 필요해지면 기존 저장의 의미를 바꾸지 않고 방을 추가한다.

따라서 층 수를 먼저 정하지 않고 **전체 후보 풀과 선수 관계**를 고정한다. 이후 후보 우선순위를 매기고 선수 그래프에서 작은 연구 묶음을 하나씩 꺼내 설계한다.

## 2. 공식 원자료 범위

원자료와 게임 편집층을 다음처럼 분리한다.

| 공식 추출층 | `data/tbcl-discourse-candidates-2025-04.json` | 공식 표제, 급수, 문법점 번호, 전수검토 범위 보존 |
| 게임 편집층 | `data/academic-tower-discourse-candidates-v0.1.json` | 기능 분류, 기초 선수 표현, 학습 순서, 학술탑 진행 정책 |

공식 추출 범위:

- [2025-04 공식 TBCL 어휘표](https://coct.naer.edu.tw/file/files/14452%E8%A9%9E%E8%AA%9E%E8%A1%A8202504.pdf)의 `4급 690 + 4*급 739 + 5급 2,641 = 4,070`개 표제

- 전수검토 뒤 남긴 후보: 단어 91개, 문법점 130개, 총 221개 원자료 기록

## 3. 후보 포함 기준

다음 중 하나를 충족하면 후보로 남겼다.

1. 절·문장·문단 사이의 관계를 직접 표시한다.
2. 다음 덩어리의 역할을 예측하거나 이미 만든 예측을 수정하게 한다.
3. 주제·관점·근거·예시·재진술·결론의 경계를 명시한다.
4. 단어 하나가 아니라 짝표현 전체가 조건·양보·대조·인과 관계를 만든다.

같은 글자가 들어 있어도 일반 명사·동사·형용사 용법뿐이거나, 위치·대상만 표시하는 전치사 용법, 덩어리 관계를 만들지 않는 순수 강조·감탄·금지 표현은 제외했다.

이 후보 풀은 “학술탑에서 모두 목표어로 써야 한다”는 목록이 아니다. 누락 없이 설계 선택지를 확보하기 위한 상한선이다.

## 4. 기능 분류

각 원자료 후보에는 하나의 주 기능을 배정했다. 실제 문맥에서 여러 기능을 가질 수 있지만, 최초 방 설계에서 무엇을 먼저 조작하게 할지 기준을 하나로 고정하기 위한 분류다.

| 기능 | 후보 기록 수 | 플레이어가 하는 처리 |
|---|---:|---|
| 순서·시간 전환 | 19 | 앞 덩어리를 닫고 다음 시점·단계로 이동 |
| 첨가·병렬·강화 | 27 | 현재 방향을 유지하며 정보나 강도를 추가 |
| 선택·대안·선호 | 8 | 대안을 분리하고 우선순위를 표시 |
| 원인·결과·귀결 | 23 | 근거와 결과를 방향성 있게 연결 |
| 조건·예외·반사실 | 26 | 명제를 확정하지 않고 적용 범위 안에 보류 |
| 비교·관점 | 8 | 기준이나 관찰 위치를 분리해 비교 |
| 대조·제한·정정 | 24 | 앞에서 만든 중심이나 범위를 뒤에서 변경 |
| 양보·결론 유지 | 12 | 반대 조건을 인정해도 유지되는 결론 확인 |
| 예상 확인·이탈·역전 | 25 | 예상 방향을 확인·수정·반전 |
| 주제·범위·초점 전환 | 13 | 뒤 덩어리를 읽을 프레임 설정 |
| 예시·재진술·정의 | 10 | 같은 내용을 예나 다른 말로 다시 펼침 |
| 근거 출처·화자 관점 | 8 | 명제와 판단 출처를 분리 |
| 추론·요약·결론 | 12 | 앞 덩어리에서 새 결론이나 요약을 만듦 |
| 목적·예방 | 6 | 행동과 원하는 결과·피할 결과를 연결 |

합계는 221개다. 같은 교육 단위를 이루는 단어표 표제와 문법점은 이후 하나의 방에서 함께 사용할 수 있다. 예를 들어 `反而` 표제와 `(不但)不/沒……反而……` 문법점은 원자료 기록은 둘이지만 하나의 역전 연구 묶음으로 연결한다.

### 4.1 후보 우선순위

221개 원자료 기록은 게임 편집층에서 세 우선순위로 나눈다.

| 우선순위 | 기록 수 | 의미 |
|---|---:|---|
| `core` | 110 | 복문 분할과 방향 갱신의 필수 뼈대. 여러 연구 묶음에서 반복 사용 |
| `secondary` | 65 | 핵심의 다른 말투·문체·관점 또는 다음 묶음 확장 후보 |
| `later` | 46 | 사용 맥락이 좁거나 비슷한 핵심 표현 뒤에 다룰 장기 후보 |

판정 기준은 구조 활용도, 선수 관계 중심성, 비슷한 표현과의 대조 필요, 전술 조작 가능성, 사용 문체의 폭이다. 여러 복문을 여는 구조이면서 플레이어가 분할·연결·예상·갱신 상태를 직접 만들 수 있을수록 `core`에 가깝다. 쓰임이 좁거나 먼저 익힐 유사 표현이 있고 별도 조작 차이가 아직 약하면 `later`로 미룬다.

`core`가 곧바로 110개의 방을 뜻하지 않는다. 같은 표현의 단어표·문법점 기록, 짝표현, 같은 조작을 공유하는 표현은 한 방이나 한 묶음에서 함께 다룰 수 있다. 전체 목록은 편집 데이터의 `priorityPolicy`가 기준이며, 명시한 `core`와 `later` 어느 쪽에도 없는 기록은 `secondary`로 계산한다.

## 5. 선수 관계

선수 관계는 **기초 표현 → 기능 → 고난도 학습 묶음**의 세 층으로 관리한다.

```text
기본 순서 ───────────────┬─> 원인·결과 ─> 조건·예외 ─> 양보
                         │                  └──────────> 목적·예방
기본 비교 ─> 대조·정정 ──┴────────────────────────────> 예상 갱신

기본 주제 ─> 주제·범위 ──┬─> 근거·관점 ─> 추론·요약
                         └─> 예시·재진술 ──────────────┘
```

기초 선수 표현에는 `因為／所以`, `如果／就`, `但是／可是／不過`, `雖然／但是`, `而且`, `或者`, `例如`처럼 TBCL 1~3급에서 먼저 만나는 표지를 둔다. 이들은 학술탑의 새 목표어라기보다 복잡한 구조를 받치는 조작 기준이다.

### 5.1 핵심 학습 사슬

`然而` 사슬:

```text
但是／可是／不過
→ 卻
→ 而／則／然而
→ 話說回來／反之
```

`反而` 사슬:

```text
因為／所以로 기본 예상 만들기
→ 果然／難怪로 예상 확인
→ 竟然／居然／不料로 예상 이탈
→ 反而로 결과 방향 자체를 반전
```

양보 사슬:

```text
如果……就……
＋ 雖然……但是……
→ 即使／就算……也……
→ 儘管……還／但是……
→ 양보절 안에 조건절이나 역전 표지 중첩
```

글 조직 사슬:

```text
例如
→ 就是說／換句話說
→ 可見／由此可知
→ 總之／總而言之／簡言之
```

### 5.2 첫 연구 묶음

첫 묶음은 두 갈래를 병렬로 익힌 뒤 역전에서 합친다.

```text
卻
├─> 然而 ───────┐
└─> 果然／竟然 ─┴─> 反而 ─> 종합
```

- `卻`: 뒤 덩어리로 중심을 옮긴다.
- `然而`: 한 문장보다 넓은 기록 사이에서도 앞을 인정하고 뒤로 중심을 옮긴다.
- `果然 / 竟然`: 원인에서 만든 예상과 실제가 일치하는지 이탈하는지 구분한다.
- `反而`: 단순한 이탈을 넘어 실제 결과의 방향 자체가 반대임을 표시한다.
- 종합: 새 목표 표현 없이 다섯 표현을 긴 수로 기록에서 능동 재사용한다.

안정 ID, 저장, 방별 문장·조작·오답·복구·모바일 acceptance는 `ACADEMIC-TOWER-FIRST-RESEARCH-BUNDLE-v0.1.md`를 따른다.

## 6. 준비도 묶음

준비도 묶음은 영구 층 번호가 아니다. 실제 방을 설계할 때 앞선 처리 능력이 필요한지 확인하는 작성용 단계다.

1. **기초 확장** — TBCL 4급 표현으로 익숙한 연결을 더 긴 덩어리에 적용한다.
2. **짝관계 유지** — TBCL 4*급 중심으로 조건·양보·대조의 앞뒤 표지를 함께 유지한다.
3. **예상 갱신·문어 연결** — TBCL 5급 표현으로 논지의 방향과 화자의 예상을 갱신한다.
4. **문단 조직** — `話說回來`, `換句話說`, `由此可知`, `總而言之`처럼 여러 문장을 묶거나 다시 나눈다.

새 방은 이 준비도를 참고하되 한 판의 신규 목표 표현은 원칙대로 1~3개만 둔다. 나머지는 이미 익숙한 내용어와 앞선 연결 표현을 능동 재사용한다.

## 7. 후속 연구 묶음 설계 계약

첫 묶음과 이후 방을 설계할 때 다음을 지킨다.

- 후보 수가 많다는 이유로 층마다 표현 하나를 기계적으로 배정하지 않는다.
- 같은 인지 동작을 공유하는 표현을 비교 가능한 작은 묶음으로 고른다.
- `그러나를 고르시오` 같은 문법 객관식이 아니라 실제 문장을 끊고 관계를 갱신하게 한다.
- 원자료 등급은 수정하지 않는다. 게임 난도·추천 순서·방 배치는 편집층에만 기록한다.
- 방 완료와 연구 묶음 완료는 가능하지만 전체 학술탑 완료는 만들지 않는다.
- 최초 수직 slice 전에는 해당 후보의 공식 표제, 선수 표현, 기존 게임 노출, 예문 내용어 난도를 다시 검토한다.

## 8. 자동검증

후보 데이터만 검사하려면 다음을 실행한다.

```bash
node tools/academic-tower-candidate-audit.cjs
```

전체 콘텐츠 게이트에도 같은 감사가 포함된다.

```bash
node tools/verify-content.cjs
```

감사는 원자료 수·ID·급수 경계, 221개 후보의 기능·우선순위 누락과 중복, 선수 그래프 순환, 첫 연구 묶음의 방·목표어·선수 관계, 학술탑의 무제한·무격파 정책을 검사한다.
