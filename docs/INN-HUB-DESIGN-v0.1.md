# 1. 한 줄 방향

> **처음 갈 곳이 없던 소년에게 생기는 첫 ‘돌아올 곳’. 방 안의 물건을 직접 만지며 생활 행동과 생활 단어를 익힌다.**

여관은 또 하나의 전술 지역이 아니다.

길목·장인골·장터가 마을의 문제를 해결하는 곳이라면, 여관은 **소년 자신이 하루를 살아가는 곳**이다.

여기서는 격자 이동과 경로 퍼즐보다 다음 경험을 우선한다.

- 방 안 사물을 발견한다.
- 사물에 맞는 생활 행동을 해본다.
- 행동과 동시에 중국어 단어가 나타난다.
- 여러 행동을 묶어 아침·밤·청소 같은 짧은 생활 루틴을 만든다.
- 여행이 진행될수록 방과 생활 흔적이 조금씩 쌓인다.

---

# 2. 세계 안에서의 역할

물길마을은 소년이 고향 밖의 세계에 익숙해지는 첫 번째 큰 정착지다.

고향 `小村`에서는 먹고 자는 일이 생활의 일부로 이미 주어져 있었지만, 물길마을에서는 처음으로 소년이 스스로 다음 일을 결정해야 한다.

튜토리얼 뒤 소년은 세 갈래 길에서 길목·장인골·장터 가운데 원하는 곳부터 둘러볼 수 있다.

여관은 처음부터 선택지로 주어지는 네 번째 지역이 아니다.

소년은 장터에서 사람들과 관계를 맺고 일을 돕다가 자신에게 아직 **먹을 곳, 잘 곳, 돌아올 곳이 없다는 사실**을 구체적으로 깨닫는다.

M4에서 여관 주인의 저녁거리를 구해 준 뒤 인연이 생기고, 해금 이야기가 끝나면 월드맵 장터 옆에 작은 여관 표식이 새로 나타난다.

이 순간의 보상은 새로운 전투 능력이나 수치보다 다음 감각에 가깝다.

> **“이제 나도 이 마을에 돌아올 곳이 하나 생겼다.”**

# 3. 해금 방식

## 3.1 기본 원칙

여관은 처음부터 월드맵에 주요 목적지로 표시하지 않는다.

물길마을 첫 도착 시 플레이어가 알아야 하는 중심 구역은 기존대로 다음 세 곳이다.

- 길목
- 장인골
- 장터

여관은 **장터 안에서 발견되는 하위 생활 장소**다.

장터 M4의 해금 이야기 완료에서 `inn-unlocked` milestone을 기록하고, 그때 장터 옆에 작은 `客棧` 아이콘이 나타난다.

M5 진행은 여관 첫 방문을 요구하지 않는다. 해금 뒤에는 여관으로 들어가도 되고 장터 일을 계속해도 된다.

## 3.2 확정된 해금 사건

장터 M4 `오늘 저녁거리`를 기준으로 한다.

1. 여관 주인이 오늘 저녁에 필요한 채소와 빵을 구하지 못한 상태다.
2. 소년이 장터 좌판에서 필요한 식재료를 사서 가져온다.
3. 여관 주인이 `你今天住哪裡？`라고 묻는다.
4. 소년은 `我還沒決定。`라고 답한다.
5. 여관 주인이 빈방 하나를 소개하고 오늘은 우선 머물라고 한다.
6. 해금 이야기가 끝나면 `inn-unlocked`가 기록되고 월드맵에 `客棧`이 나타난다.

첫 해금은 **돈이 없으면 길바닥에서 자야 하는 생존 압박**으로 만들지 않는다.

여관은 생활 시스템을 여는 사건이지 실패 조건이 아니다.

## 3.3 숙박비·경제 시스템

장터 M4의 돈은 구매 개념을 보여주기 위한 **스테이지 내부 자원**이다. 장터 1차 묶음에서는 소지금을 영구 저장하지 않는다.

장인골에서 받는 **수선패（修繕牌）와 첫 품삯**은 이후 소년의 생활 경제가 시작되는 서사적 근거로 남긴다.

향후에는 품삯을 밥, 여관, 여행 준비물처럼 소년의 생활이 이어지고 있음을 보여주는 데 사용할 수 있다. 그러나 이 경제 시스템은 장터·여관 MVP와 분리한다.

거점이 열린 뒤 매일 숙박비를 못 내면 기능이 잠기는 구조는 피한다. 돈이 부족해 이야기 진행이 막히거나 같은 일을 반복해야 하는 구조도 만들지 않는다.

즉 현재 확정은 다음과 같다.

- M4 구매용 돈: 판 안에서만 존재
- 첫 방: 돈 부족으로 막히지 않음
- 영구 소지금: v1.0 장터·여관 MVP 범위 밖
- 반복 숙박비·생존 압박: 도입하지 않음

# 4. 월드맵에서의 위치와 위계

여관은 장터 옆에 붙는 **작은 보조 장소 표식**으로 둔다.

```text
                         회의소
                           ↑
                        장터 ─ 客棧

장인골 ─ 학술탑           │
                           │
                         길목
                           ↓
                       끝마을 방면
```

정확한 화면 좌표는 실제 아이콘과 겹침을 보며 정한다.

중요한 것은 여관이 길목·장인골·장터와 동급의 구역처럼 보이지 않는 것이다.

### 지도 표현 원칙

- 장터보다 작은 아이콘을 사용한다.
- 처음에는 보이지 않는다.
- M4 해금 이야기 뒤 새 표식이 생긴다.
- 해금 뒤에는 언제든 들어갈 수 있다.
- 메인 지역처럼 `권장 경로`를 표시하지 않는다.
- 필요하면 현재 거점임을 작은 집/열쇠/침대 계열 표식으로 나타낸다.

첫 구현의 일반명은 `客棧`을 사용한다. 별도 고유 이름은 이후 실제 외관·주인 NPC 성격이 정해질 때 붙일 수 있다.

# 5. 여관의 세 가지 기능

## 5.1 단어 발견

방 안의 사물을 직접 누르면 관련 중국어가 나타난다.

예:

- 침대를 누른다 → `床`, `睡覺`
- 빗자루를 누른다 → `掃把`, `掃地`, `打掃`
- 창문을 누른다 → `窗戶`, `開窗`, `關窗`
- 등불을 누른다 → 불을 켜고 끄는 표현

처음에는 **“저게 중국어로 뭐지?”**를 사물과 직접 연결하는 경험을 준다.

## 5.2 생활 루틴

발견한 사물을 실제 상황에서 다시 사용한다.

예:

밤에 방으로 돌아왔을 때:

> 이제 잘 준비를 하자.

방은 하나의 작은 상태 공간이 된다.

- 창문이 열려 있다.
- 등불이 켜져 있다.
- 짐이 흐트러져 있다.
- 침대가 있다.

플레이어는 사물을 눌러 상태를 바꾼다.

`關窗 → 整理 → 關燈 → 睡覺`

다음 날 아침에는 다른 흐름이 된다.

`起床 → 洗臉 → 整理行李 → 出門`

정해진 순서를 외우게 하는 것이 목적은 아니다.

의미상 순서가 꼭 필요한 행동만 조건을 둔다. 그 외에는 여러 순서를 허용한다.

## 5.3 거점과 여행 흔적

여행이 진행될수록 방은 소년의 생활 흔적을 담는 장소가 될 수 있다.

후보:

- 장터에서 산 컵이나 작은 물건
- 장인골에서 받은 도구
- 길목에서 얻은 통행증이나 기념물
- 여행 중 받은 편지
- 이야기상 의미 있는 작은 물건

물건을 누르면 이전 사건이나 단어를 다시 떠올릴 수 있다.

이 기능은 장기 확장 방향이며 첫 MVP에는 필수가 아니다.

# 6. 핵심 플레이 문법: 사물 → 행동 → 단어 → 변화

기존 전술판의 공통 구조는 다음과 같다.

> 행동/사건 → 조건 판정 → 상태 변화 → 피드백

여관에서도 이 원칙을 유지하되 격자 이동 대신 **사물 상호작용**을 사용한다.

예를 들어 불을 끄는 행동은 다음과 같다.

1. 플레이어가 등불을 누른다.
2. 현재 등불이 켜져 있는지 판정한다.
3. `lightOn = false`가 된다.
4. 그림 속 불빛이 사라진다.
5. 화면에 목표 표현이 잠깐 나타난다.
6. 필요하면 짧은 한국어 뜻을 열어볼 수 있다.

즉 단어를 버튼으로 눌러 효과를 발동하는 것이 아니라, **세계의 사물을 조작했더니 그 행동의 중국어가 이름을 얻는 것**이 핵심이다.

# 7. 자유 탐색과 과제 모드

같은 방을 두 방식으로 사용한다.

## 7.1 자유 탐색

목표가 없는 상태다.

플레이어가 관심 있는 물건을 마음대로 누른다.

처음 누른 사물은 사물 이름과 대표 행동을 보여준다.

예:

```text
床
침대

睡覺
자다
```

여기서는 정답·오답이 없다.

단어를 찾아보는 행동에도 페널티가 없다.

## 7.2 생활 과제

이야기 상황 때문에 짧은 목표가 생긴다.

예:

- 방을 정리하자.
- 이제 잘 준비를 하자.
- 아침에 나갈 준비를 하자.
- 비를 맞았으니 젖은 것을 정리하자.

이때는 관련 사물만 은근하게 상호작용 가능 상태가 된다.

플레이어가 사물을 눌러 목표 상태를 만들면 완료된다.

생활 과제는 보통 **30초~2분 안에 끝나는 짧은 장면**을 목표로 한다.

전술 스테이지 사이의 호흡을 바꾸는 역할도 한다.

# 8. 방 안 사물과 생활어 후보

아래 목록은 어휘 확정안이 아니라 **설계 후보군**이다.

실제 목표어는 이후 단어 진행 계획과 대만 번체 사용 빈도를 확인한 뒤 고른다.

| 사물/공간 | 사물어 후보 | 행동어·표현 후보 | 활용 장면 |
|---|---|---|---|
| 침대 | `床` | `睡覺`, `起床`, `休息` | 취침, 기상, 휴식 |
| 빗자루 | `掃把` | `掃地`, `打掃` | 청소 |
| 창문 | `窗戶` | `開窗`, `關窗` | 아침 환기, 취침 준비, 비 오는 날 |
| 문 | `門` | `開門`, `關門`, `出門`, `進來` | 외출, 귀환 |
| 등불 | `燈` | `開燈`, `關燈` 또는 세계관에 맞는 켜기/끄기 표현 | 취침 전, 밤 귀환 |
| 세면 공간 | 미정 | `洗手`, `洗臉` | 아침 준비, 귀환 후 씻기 |
| 옷 | `衣服` | `穿`, `脫`, `換衣服` | 아침, 비 맞은 뒤 |
| 짐 | `行李` | `整理`, `收拾`, `整理行李` | 외출·여행 준비 |
| 책상/탁자 | `桌子` | `放`, `拿`, `收好` | 물건 정리, 여행 기록 |
| 화장실 | `廁所` | `上廁所` | 공간 발견, 생활어 |
| 변기/설비 | `馬桶` 등 | 필요 시 확장 | 자유 탐색용 세부 어휘 후보 |

`馬桶`처럼 웃기지만 실제 생활에서 유용한 단어도 자유 탐색에는 들어갈 수 있다. 다만 핵심 루틴을 모든 방 안 물건으로 채우지는 않는다.

# 9. 판타지 세계와 현대 생활어의 충돌 처리

이 게임은 가벼운 로우 판타지 세계를 사용하지만, 학습 목적은 실제 번체 중국어 어휘 습득이다.

따라서 여관에서는 **세계관 분위기 때문에 지나치게 고풍스러운 단어만 선택하지 않는다.**

예를 들어 그림에는 현대 전등 대신 등불이 있어도, 학습 목표가 실제 생활에서 매우 자주 쓰는 `開燈 / 關燈`이라면 이를 우선할 수 있다.

반대로 시각과 단어가 너무 어색하게 충돌하면 `點燈 / 熄燈` 같은 표현을 함께 비교하는 방식을 검토한다.

기준은 다음과 같다.

1. 실제 학습 효용을 우선한다.
2. 세계관 그림은 현대 가전제품처럼 만들지 않는다.
3. 표현 차이가 학습 가치가 있을 때만 동의어·시대 차이를 설명한다.
4. 분위기를 지키기 위해 실용성이 낮은 희귀어를 핵심 단어로 강제하지 않는다.

# 10. 시각·상호작용 설계

## 10.1 방 자체가 먼저 보여야 한다

기존 디자인 원칙대로 **세계는 버튼처럼 보이지 않아야 한다.**

방에 들어오면 처음부터 모든 물건에 큰 카드와 라벨을 붙이지 않는다.

첫인상은 `학습 메뉴`가 아니라 **소년의 방**이어야 한다.

## 10.2 추천 렌더링 구조

월드맵과 같은 방향을 재사용할 수 있다.

```text
innRoom
├─ roomBackgroundImage
├─ roomAtmosphereLayer
├─ objectHotspotLayer
│   ├─ bed
│   ├─ broom
│   ├─ window
│   ├─ lamp
│   ├─ washArea
│   └─ ...
└─ feedbackLayer
```

배경은 손그림 방 이미지 한 장으로 두고, 실제 상호작용 지점만 HTML/SVG 오버레이로 얹는다.

### 핫스폿 원칙

- 보이는 아이콘보다 터치 영역을 넓게 둔다.
- 최소 44px 터치 영역을 확보한다.
- 평소에는 투명하거나 매우 조용하다.
- 눌러볼 수 있는 상황에서만 얇은 빛, 흔들림, 작은 윤곽 등으로 알린다.
- 계속 반짝이는 마커를 모든 물건에 붙이지 않는다.

## 10.3 단어 피드백

사물을 누르면 화면 중앙을 가리는 큰 팝업부터 띄우지 않는다.

우선 사물 가까이에 짧게 단어가 나타나고 실제 상태가 변한다.

예:

```text
      關窗
    창문을 닫다
```

더 자세한 뜻·발음·예문은 다시 누르거나 별도 상세층에서 확인한다.

**행동 변화가 먼저, 설명은 그 다음**이다.

# 11. 생활 루틴 예시

## 11.1 첫날 밤 — 처음 자는 곳

서사 목적:

- 여관을 단순 메뉴가 아니라 실제 거점으로 인식한다.
- `睡覺 / 休息` 계열을 처음 경험한다.

예시 흐름:

1. 주인이 방을 보여준다.
2. 플레이어가 자유롭게 몇 가지 물건을 눌러본다.
3. 밤이 되었음을 알린다.
4. 필요한 최소 행동을 한다.
5. 마지막에 침대를 눌러 `睡覺`한다.
6. 화면이 어두워지고 다음 날로 넘어간다.

첫날부터 열 개의 생활어를 한꺼번에 가르치지 않는다.

## 11.2 다음 날 아침 — 밖으로 나갈 준비

후보 목표어:

- `起床`
- `洗臉`
- `整理`
- `出門`

침대를 눌러 기상하고, 간단한 준비를 한 뒤 문을 누르면 물길마을로 돌아간다.

## 11.3 청소를 도와달라는 날

후보 목표어:

- `打掃`
- `掃地`
- `整理`
- `乾淨`

빗자루와 흐트러진 물건을 이용해 방 상태를 바꾼다.

`打掃`과 `掃地`처럼 범위가 다른 표현을 실제 행동 차이로 보여줄 수 있다.

## 11.4 늦게 돌아온 날

후보 목표어:

- `回來`
- `休息`
- `關燈`
- `睡覺`

전술 스테이지 뒤의 짧은 정리 장면으로 쓰기 좋다.

## 11.5 비를 맞고 돌아온 날

후보 목표어:

- `濕`
- `換衣服`
- `擦`
- `晾` 계열

같은 방이 이야기 상황에 따라 다른 어휘를 자연스럽게 재사용하는 예다.

# 12. 진행과 반복 학습

여관의 반복은 **매일 같은 체크리스트를 수행하는 방식**으로 만들지 않는다.

`起床 → 洗臉 → 關燈 → 出門`을 매번 의무적으로 눌러야 하면 금방 숙제가 된다.

대신 생활 루틴은 이야기에 필요할 때 짧게 등장한다.

같은 단어도 상황을 조금 바꿔 재등장시킨다.

예:

- 첫날: 그냥 `睡覺`
- 며칠 뒤: 창문을 닫고 `睡覺`
- 여행 전날: `整理行李` 후 `睡覺`
- 늦게 귀환: `關燈` 후 `休息`

반복의 목적은 버튼 순서 암기가 아니라 **상황과 중국어 표현의 연결을 강화하는 것**이다.

---

# 13. 여관에서의 실패와 정답

생활 공간에서는 실패 비용을 특히 낮게 둔다.

예를 들어 잘 준비를 하는 장면에서 침대를 먼저 눌렀다고 즉시 실패시키지 않는다.

필요하면 소년이 짧게 반응한다.

> `窗戶還開著。`  
> 창문이 아직 열려 있네.

그 뒤 플레이어가 창문을 닫고 다시 잘 수 있다.

잘못된 행동은 **다음에 무엇을 보면 좋을지 알려주는 정보**가 되어야 한다.

순서 퍼즐을 만들더라도 생활 상식상 이유가 이해되는 경우에만 사용한다.

# 14. 전술 지역과의 차이

| 항목 | 길목·장인골·장터 등 | 여관 |
|---|---|---|
| 기본 공간 | 격자/전술판 | 한 방 또는 작은 실내 장면 |
| 핵심 판단 | 위치, 거리, 경로, 상태 | 사물, 행동, 생활 순서 |
| 조작 | 이동·살펴보기·대상 조작 | 사물 직접 탭 |
| 단어 역할 | 판의 관계를 읽는 말 | 내가 하는 생활 행동의 이름 |
| 길이 | 수분 단위 스테이지 | 30초~2분의 짧은 루틴 가능 |
| 분위기 | 문제 해결 | 귀환, 생활, 정리, 발견 |

그러나 둘은 같은 게임 문법을 공유한다.

> **단어를 외워서 정답 버튼을 누르는 것이 아니라, 세계에서 그 의미가 성립하는 행동을 만든다.**

# 15. 장기적인 거점 기능 후보

여관이 충분히 자리 잡은 뒤 다음 기능을 검토할 수 있다.

## 여행 흔적

방 안에 기념품이나 이야기 물건이 늘어난다.

## 단어 회상

이전에 발견한 생활 물건을 다시 눌러 단어를 확인할 수 있다.

## 옷과 짐

여행 준비와 관련된 단어군을 자연스럽게 확장한다.

## 편지·기록

책상에 편지나 여행 기록이 쌓이며 읽기 어휘와 연결할 수 있다.

## 인물 방문

친해진 NPC가 여관에 들르거나 메시지를 남길 수 있다.

이 기능들은 **거점의 정서적 가치가 먼저 생긴 뒤** 추가한다.

처음부터 기능 메뉴를 잔뜩 넣어 `홈 화면`처럼 만들지 않는다.

# 16. 하지 않을 것

초기 여관에는 다음을 넣지 않는다.

- 매일 강제되는 배고픔·피로 수치
- 숙박비 부족으로 진행이 막히는 생존 시스템
- 의미 없이 반복해야 하는 매일 청소 퀘스트
- 방 안 모든 사물에 항상 떠 있는 단어 라벨
- 누르기만 하면 단어 수집률이 올라가는 도감형 반복
- 복잡한 인테리어 배치·하우징 시스템
- 별도 전투 스탯 회복을 위한 필수 숙박 루프

여관은 **생활어를 세계 속 행동으로 경험하고 돌아올 곳을 만드는 공간**이지, 관리 부담을 추가하는 시스템이 아니다.

# 17. MVP 범위

첫 구현은 작게 잡는다.

## 반드시 필요한 것

1. 장터 M4 해금 이야기 뒤 `inn-unlocked`
2. 월드맵 장터 옆 작은 `客棧` 아이콘 표시
3. 여관 방 한 장
4. 클릭 가능한 사물 5~7개
5. 자유 탐색
6. 첫날 밤 생활 루틴 1개
7. 다음 날 아침 생활 루틴 1개
8. 단어 등장 + 짧은 상태 변화
9. 저장 후 다시 여관에 들어올 수 있음

## MVP 사물 후보

- 침대
- 창문
- 등불
- 빗자루
- 세면 공간
- 문
- 짐 또는 옷

## MVP 목표어 수

처음부터 방에 있는 모든 명사·동사를 학습 목표로 삼지 않는다.

핵심 행동어 **약 6~10개**를 우선하고, 사물 명사는 보조 발견 어휘로 둔다.

정확한 목록은 실제 방 상호작용을 구현하면서 확정한다.

---

# 18. 구현 구조 가안

기존 월드맵의 `배경 이미지 + 오버레이 좌표 + 상태 UI` 패턴을 그대로 재사용하는 것이 가장 단순하다.

데이터는 다음 정도로 분리할 수 있다.

```js
innRoom = {
  objects: [
    {
      id: 'bed',
      x: 72,
      y: 58,
      noun: '床',
      actions: ['睡覺', '起床']
    },
    {
      id: 'broom',
      x: 18,
      y: 74,
      noun: '掃把',
      actions: ['掃地', '打掃']
    }
  ]
}
```

실제 행동은 `현재 상황 + 물건 상태 + 선택한 대상`으로 결정한다.

예:

```text
object: window
state: open
context: bedtime
→ action: 關窗
→ state: closed
```

두 번째 이상의 실내 상호작용 공간이 생기면 이 구조를 여관 전용 코드에서 공통 `scene interaction` 기믹으로 일반화한다.

---

# 19. 아직 결정할 것

장터와의 연결에서 결정할 항목은 이제 대부분 닫혔다.

확정됨:

- 해금 시점 → M4 `오늘 저녁거리` 뒤
- 해금 저장 → `inn-unlocked`
- 지도 위계 → 장터 옆 하위 생활 장소
- 첫 구현 일반명 → `客棧`
- 첫 숙박 → 돈 부족으로 막지 않음
- M4 구매 돈 → 스테이지 내부 자원, 영구 소지금 아님

아직 결정할 것:

- 여관 주인의 고유 이름과 성격 세부
- 여관 고유명 여부
- 첫날 밤의 정확한 핵심 목표어
- 현대 생활어와 로우 판타지 시각의 세부 표현
- 방의 시점과 배경 이미지 스타일
- 생활 루틴 완료 뒤 시간 경과를 실제 진행 시스템에 얼마나 연결할 것인가

# 20. 현재 결론

여관은 물길마을의 네 번째 대형 지역이 아니다.

**장터 M4를 살아보다가 발견하는 작은 생활 장소이며, 이후 소년의 첫 거점이 된다.**

전술 지역이 바깥세상을 읽는 법을 가르친다면, 여관은 자기 생활을 꾸리는 말을 가르친다.

그리고 가장 중요한 보상은 시스템 해금 자체보다 다음 변화다.

> 처음 물길마을에 왔을 때 소년은 어디로 가야 할지도 몰랐다.  
> 이제는 하루를 마치고 돌아올 곳이 있다.

이 감각을 여관 설계의 중심에 둔다.
