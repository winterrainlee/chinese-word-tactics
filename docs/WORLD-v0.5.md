# v0.5 월드 연결 메모

기준: `INITIAL-PROGRESSION-PLAN-v0.1.md`, `POST-TUTORIAL-WORLD-v0.1.md`, `WORLD-NAMING-PRINCIPLES-v0.1.md`

이번 단계는 튜토리얼 이후 월드 선택 구조를 실제 UI에 연결한다.

## 화면 이름

월드맵에서는 한국어 이름을 크게 보여주고, 원래 번체 지명은 작은 보조 표기로 유지한다.

한국어 이름은 번체 지명의 직역이 아니라 플레이어가 지도에서 자연스럽게 받아들이는 현지화 이름을 사용한다.

- `고향 마을` — `出發`
- `길목` — `關口鎮`
- `장인골` — `工坊村`
- `장터` — `市集鎮`
- `끝마을` — `邊境村`
- `회의소` — `議會鎮`
- `학술도시` — `研究城`

각 장소에는 서로 다른 실루엣의 지역 아이콘을 사용한다. 아이콘은 장소를 빠르게 구분하는 보조 정보이고, 지명 텍스트를 대신하지 않는다.

지역의 이름과 아이콘은 같은 세계를 가리켜야 한다. 현재 세계는 밝고 소박한 중세풍 모험 판타지를 기본으로 하며, 현대 행정기관이나 현대 연구시설처럼 읽히는 형태는 피한다.

## 진행 구조

- `길목 / 장인골 / 장터`: 자유 선택
- `끝마을 / 회의소`: 입장 가능하지만 권장 선행 지역 표시
- `학술도시`: `장인골` 핵심 시험 완료 전 잠금
- 월드 방문 상태는 `chinese-word-tactics-world-v1`에 저장
- 튜토리얼 저장 키 `chufa-tutorial-v03`는 유지
- 실제 지역 의뢰는 다음 단계에서 추가

`src/content.js`는 현재 실행에 필요한 튜토리얼/월드 콘텐츠 정의를 담고, `src/app.js`는 진행과 상호작용을 담당한다. `src/world-runtime.js`는 한글 이름·번체 보조 표기·지역 아이콘을 화면에 연결한다.
