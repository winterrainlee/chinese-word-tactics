# v0.5 월드 연결 메모

기준: `INITIAL-PROGRESSION-PLAN-v0.1.md`, `POST-TUTORIAL-WORLD-v0.1.md`

이번 단계는 튜토리얼 이후 월드 선택 구조를 실제 UI에 연결한다.

## 화면 이름

월드맵에서는 한국어 이름을 크게 보여주고, 원래 번체 지명은 작은 보조 표기로 유지한다.

- `출발 마을` — `出發`
- `관문 마을` — `關口鎮`
- `공방 마을` — `工坊村`
- `시장 마을` — `市集鎮`
- `변경 마을` — `邊境村`
- `의회 마을` — `議會鎮`
- `연구 도시` — `研究城`

각 장소에는 서로 다른 실루엣의 지역 아이콘을 사용한다. 아이콘은 장소를 빠르게 구분하는 보조 정보이고, 지명 텍스트를 대신하지 않는다.

## 진행 구조

- `관문 마을 / 공방 마을 / 시장 마을`: 자유 선택
- `변경 마을 / 의회 마을`: 입장 가능하지만 권장 선행 마을 표시
- `연구 도시`: `공방 마을` 핵심 시험 완료 전 잠금
- 월드 방문 상태는 `chinese-word-tactics-world-v1`에 저장
- 튜토리얼 저장 키 `chufa-tutorial-v03`는 유지
- 실제 마을 의뢰는 다음 단계에서 추가

`src/content.js`는 현재 실행에 필요한 튜토리얼/월드 콘텐츠 정의를 담고, `src/app.js`는 진행과 상호작용을 담당한다. `src/world-runtime.js`는 한글 이름·번체 보조 표기·지역 아이콘을 화면에 연결한다.
