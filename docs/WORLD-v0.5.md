## 화면 이름

월드맵에서는 한국어 이름을 크게 보여주고, 원래 번체 지명은 작은 보조 표기로 유지한다.

한국어 이름은 번체 지명의 직역이 아니라 플레이어가 지도에서 자연스럽게 받아들이는 현지화 이름을 사용한다.

- `고향 마을` — `出發`
- `길목` — `關口鎮`
- `장인골` — `工坊村`
- `장터` — `市集鎮`
- `끝마을` — `邊境村`
- `회의소` — `議會鎮`
- `학술도시` — `研究城`

각 장소에는 서로 다른 실루엣의 지역 아이콘을 사용한다. 아이콘은 장소를 빠르게 구분하는 보조 정보이고, 지명 텍스트를 대신하지 않는다.

지역의 이름과 아이콘은 같은 세계를 가리켜야 한다. 현재 세계는 밝고 소박한 중세풍 모험 판타지를 기본으로 하며, 현대 행정기관이나 현대 연구시설처럼 읽히는 형태는 피한다.

## 상위 화면 구조

장기 기본 메뉴는 다음 세 축으로 정한다.

- **월드맵** — 앞으로 어디로 갈지 고른다.
- **여정** — 지금까지의 이야기와 스테이지를 다시 본다.
- **단어장** — 지금까지 만난 단어를 복습한다.

스토리와 스테이지의 최초 진행은 메뉴에서 따로 찾아 들어가게 하지 않는다.

`이야기 → 스테이지 → 결과 이야기`가 자연스럽게 이어지고, 이미 열린 콘텐츠를 다시 볼 때만 `여정`을 사용한다.

세부 규칙은 `STORY-JOURNEY-SYSTEM-v0.1.md`를 따른다.

## 진행 구조

### 프롤로그

기존 `出發` 튜토리얼 6판을 **프롤로그 · 고향 마을**로 여정에 포함한다.

튜토리얼은 별도 도움말이 아니라 용사의 첫 모험으로 취급한다. 완료한 판은 여정에서 언제든 다시 플레이할 수 있다.

### 1장 — 세 갈래 길

튜토리얼 마지막 `「救命！」` 이후 길가의 행상인과 만나는 짧은 이야기 장면을 거쳐 월드맵이 열린다.

- `길목 / 장인골 / 장터`: 자유 선택
- `끝마을 / 회의소`: 처음부터 방문 가능하게 둘 수 있지만 앞 지역을 완료하면 본격적인 다음 의뢰가 자연스럽게 이어진다.
- `학술도시`: `장인골` 핵심 시험 완료 후 실제 해금

1차 지역 세부 스토리는 `TIER1-STORYLINE-v0.1.md`를 따른다.

## 다음 지역 연결의 의미

다음 지역은 단순히 잠금 아이콘이 사라지는 방식보다 **용사가 그곳으로 갈 이유를 얻는 방식**을 우선한다.

- 길목 완료 → 북쪽 길이 정리되어 **끝마을**이 강한 추천 목적지가 된다.
- 장인골 완료 → 오래된 장치에서 단서를 찾아 **학술도시**를 방문할 이유와 수단을 얻는다.
- 장터 완료 → 분배와 공정성 문제를 넘기기 위해 **회의소**에 새 의뢰가 생긴다.

월드맵의 상태 표시는 `추천 / 새 의뢰 / 잠금 해제`처럼 의미를 구분할 수 있다.

## 현재 코드 역할

- `src/content.js` — 현재 실행에 필요한 튜토리얼/월드 콘텐츠 정의
- `src/app.js` — 진행과 전술 상호작용
- `src/world-runtime.js` — 한글 이름·번체 보조 표기·지역 아이콘과 월드 상태

v0.6에서는 여기에 이야기 데이터, 여정 순서, 스토리 장면 렌더러를 분리해 추가하는 것을 우선한다.

권장 방향:

- `STORIES` — 이야기 장면 내용
- `STAGES` — 전술판 규칙과 승리 조건
- `JOURNEY` — story/stage가 어떤 순서로 이어지는지

정확한 파일 분리는 구현 단계에서 결정한다.
