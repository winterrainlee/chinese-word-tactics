새 의미 행동과 실제 재사용 경계는 [재사용 가능한 게임 규칙·기믹 도감 v0.2](REUSABLE-MECHANICS-v0.2.md)에 기록한다. 두 번째 실사용처가 생기면 필요한 부분만 일반화하고, 자동검사·Pages·실기기 승인 증거는 개발 상황판에 별도로 남긴다.

세계관 판단에서는 `WORLD-v0.6.md`를 우선한다. 런타임 월드 화면도 물길마을（三溪鎮） 그림지도로 전환했다. 기존 `gate-town / workshop-town / market-town` 같은 내부 식별자는 저장·여정 호환용 안정 ID로 유지하며 세계관의 실제 장소 이름과 구분한다.

장터 전체는 `MARKET-DESIGN-v0.1.md`와 `MARKET-STAGES-M1-M8-DESIGN-v0.1.md`를 상위 기준으로 삼는다. 실제 구현 세부사항은 M1~M3의 `MARKET-M1-M3-IMPLEMENTATION-v0.1.md`, M4의 `MARKET-M4-IMPLEMENTATION-v0.1.md`, M5~M8의 `MARKET-M5-M8-IMPLEMENTATION-v0.1.md`를 각각 우선한다. `公平`과 부담 분담은 장터가 아니라 후속 회의소에서 다룬다.

스토리와 스테이지는 처음 진행할 때 하나의 흐름으로 이어지고, 이미 열린 콘텐츠를 다시 볼 때는 `여정`에서 각각 찾아본다.
