새 공통 규칙은 [재사용 가능한 게임 규칙·기믹 도감](REUSABLE-MECHANICS-v0.1.md)에 먼저 추가한다. 실제 두 번째 사용처가 생겼을 때 스테이지 전용 구현을 공통 기믹으로 일반화하고, 구현 뒤에는 개발 상황판을 갱신한다.

현재 main은 v0.6 스토리·여정 기반과 길목 G1 `문 안쪽`까지 구현했다. 다음 신규 전술 기믹은 길목 G2 `종소리가 닿는 곳`의 `距離 / 範圍`다.

스토리와 스테이지는 처음 진행할 때 하나의 흐름으로 이어지고, 이미 열린 콘텐츠를 다시 볼 때는 `여정`에서 각각 찾아본다.
