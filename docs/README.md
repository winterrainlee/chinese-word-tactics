# 문서 색인

`chinese-word-tactics`의 기획·디자인·개발 운영 문서를 모아둔다.

- [디자인 원칙 v0.1](DESIGN-PRINCIPLES-v0.1.md) — 화면·전술판·단어·월드맵의 공통 시각/상호작용 판단 기준
- [세계관 및 이름짓기 원칙 v0.1](WORLD-NAMING-PRINCIPLES-v0.1.md) — 중세풍 세계의 최소 설정, 지역/스테이지 역할 구분, 번체·한국어 작명 기준
- [아이콘 선택 확정안 v0.1](ICON-SELECTION-v0.1.md) — 2026-09-10에 승인한 A/B/C 선택과 필수 수정 조건이다. 개별 아이콘 형태는 이 결정을 우선한다.
- [아이콘 자산 제작 v0.1](ICON-ASSETS-v0.1.md) — 기본형 15종·개별 SVG 16개, 사용 안내와 검사 범위다. [실제 크기 검토 화면](../icons/preview.html)을 함께 제공한다.
- [아이콘 시스템 v0.1](ICON-SYSTEM-v0.1.md) — 실제 코드의 아이콘 목록, 최초 형태 제안, 첫 제작 15종과 교체·검수 기준이다. 시안 전 상태와 추천 형태는 초기 기획 기록으로 읽는다.
- [용사 위험 표정 반응 v0.1](HERO-REACTION-PLAN-v0.1.md) — 가시·늑대 위험 행동을 시도했을 때 `으악!` 표정으로 짧게 반응하는 기능의 범위, 상태 분리, 자산·코드 연결과 검수 계획이다.
- [개발 상황판](DEVELOPMENT-STATUS.md) — 기획 / 구현 / 실기기 검수 상태
- [월드맵 v0.5](WORLD-v0.5.md) — 현재 월드 구조와 지역 배치
- [이전 계획 v0.1](MIGRATION-PLAN-v0.1.md) — 독립 저장소 이전 계획 기록

새로운 공통 규칙은 기능 코드보다 먼저 해당 문서에 기록하고, 구현 뒤에는 개발 상황판의 상태를 갱신한다. 아이콘 선택 승인, 수정 자산 제작, 게임 화면 적용과 실기기 검수는 별도 단계로 기록한다.
