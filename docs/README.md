새로운 공통 규칙은 기능 코드보다 먼저 해당 문서에 기록하고, 구현 뒤에는 개발 상황판의 상태를 갱신한다.

현재 다음 구현 기준은 다음 순서다.

1. `v0.6-0` 스토리 모드 + 여정 기반
2. `v0.6-1` 프롤로그 → `세 갈래 길` 연결
3. `v0.6-2` 길목 첫 스테이지 `문 안쪽` (`進入 / 退出`)

스토리와 스테이지는 처음 진행할 때 하나의 흐름으로 이어지고, 이미 열린 콘텐츠를 다시 볼 때는 `여정`에서 각각 찾아본다.
