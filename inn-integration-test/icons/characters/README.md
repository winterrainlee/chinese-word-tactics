# 스토리 인물 아이콘

스토리 대사 화면의 40px 표시를 기준으로 그린 32×32 SVG다. 기존 소년과 같은 먹색 외곽선, 투명 배경과 따뜻하고 낮은 채도의 면 색을 사용한다.

## 고정 인물과 역할

- `character-merchant.svg` — 중년 여성 행상인. 머릿수건과 가방.
- `character-gatekeeper.svg` — 젊은 남성 길지기. 가벼운 경비 장비와 창.
- `character-artisan.svg` — 노년 여성 장인. 은빛 올림머리, 앞치마와 망치.
- `character-marketkeeper.svg` — 성인 남성 장터지기. 장부.
- `character-innkeeper.svg` — 성인 여성 여관 주인. 앞치마와 방 열쇠.
- `character-driver.svg` — 성인 남성 수레꾼. 모자와 고삐.
- `character-resident.svg` — 성별과 직업을 특정하지 않는 공용 주민 실루엣.

고정 및 반복 인물은 여성 3명, 남성 3명으로 배분했다. 공용 주민은 성별화된 머리 모양, 체형과 직업 소품을 사용하지 않는다.

인물 이름과 화자 정보는 이미지 안에 넣지 않고 HTML 텍스트로 유지한다. 내레이터와 정체가 드러나지 않은 목소리에는 인물 아이콘을 표시하지 않는다.
