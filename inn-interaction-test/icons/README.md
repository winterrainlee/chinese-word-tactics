# 아이콘 자산 v0.1

초기 제작본은 2026-09-10에 만들었고, 2026-09-12에 스토리 인물 7종을 추가했다. [선택 확정안](../docs/ICON-SELECTION-v0.1.md)을 작은 표시 크기용 벡터로 다시 그린 자산이며, 원본 비교 포스터를 잘라 쓴 것이 아니다. NPC 묶음은 스토리 화면에 연결했으며 iPhone 실기기 검수는 남아 있다.

## 구성

기본형 15종이며, 문의 열림·닫힘을 별도 파일로 제공하므로 개별 SVG는 16개다. 세계 7종, UI 7종, 이동 표시 1종을 포함한다. 수풀·바위·월드 지역 그림과 추가 상태 아이콘은 이번 묶음에 없다.

- `world/`에는 용사, 늑대, 출구, 석비, 닫힌 문, 열린 문, 유적, 가시가 있다.
- `ui/`에는 메뉴, 이전 화면, 다시 시작, 되돌리기, 1턴 기다리기, 살펴보기, 닫기가 있다.
- `status/`에는 이동 방향 기본형이 있다.
- `characters/`에는 행상 아주머니, 길지기, 장인, 장터지기, 여관 주인, 수레꾼과 공용 주민이 있다.
- `tactical/gate-town/`에는 길목 전술 격자용 수레, 상자, 바위, 종루, 초소, 여닫이 문, 길표지와 좁은 길 SVG가 있다. 기존 384px PNG는 비교 원본으로 보존하고 런타임은 작은 표시 크기에 맞춰 다시 그린 SVG를 사용한다.
- `sprite.svg`에는 개별 SVG와 같은 16개 심벌이 있다. `manifest.json`에는 이름, 경로, 선택 근거, 크기와 해시를 기록했다.
- [검토 화면](preview.html)은 실제 크기·확대·흑백·어두운 바탕·상태 겹침을 확인하는 전용 페이지다. 게임이 아니다.

스토리 인물과 길목 전술 SVG는 초기 15종 묶음 이후 추가했기 때문에 `manifest.json`과 `sprite.svg`에는 포함하지 않는다. `story-runtime.js`와 `icons-runtime.js`가 각각 개별 파일을 직접 불러온다.

## 사용

프로젝트의 루트 HTML에서 사물 하나를 사용할 때는 다음처럼 표시한다. 정보의 이름은 HTML에서 제공한다.

```html
<img src="./icons/world/world-hero.svg" width="32" height="32" alt="용사">
```

UI는 텍스트 버튼 옆에 심벌로 배치한다. `currentColor`는 아래 래퍼의 색을 사용한다. 개별 SVG를 `<img>`로 사용할 때는 부모 HTML의 색 변경이 안쪽 아이콘으로 전달된다고 가정하지 않는다.

```html
<button type="button" style="min-width:44px;min-height:44px;color:#292620">
  <svg width="20" height="20" aria-hidden="true">
    <use href="./icons/sprite.svg#ui-undo"></use>
  </svg>
  되돌리기
</button>
```

이동 기본형은 오른쪽을 향한다. 위는 `rotate(-90deg)`, 아래는 `rotate(90deg)`, 왼쪽은 `rotate(180deg)`로 돌린다. 표시 여부와 방향은 기존 게임의 실제 이동 판정에서 받아야 한다. 이 파일에 경로 탐색이나 정답 표시 기능은 없다.

석비 심벌의 `--cwt-rune`은 기본 각인색을 바꾸는 제작용 변수다. 기본값은 `#746c5c`다. 반응 상태는 문구나 별도 모양과 함께 표시해야 하며 색만으로 판정 상태를 전달하지 않는다. `preview.html`에서는 같은 석비에 각인색과 작은 반응 표시를 얹어 비교한다. 바깥 SVG 이미지의 변경 없이 각인색을 조절하려면 심벌 또는 인라인 사용 방식을 별도로 검수한다.

출구의 `出口`, 목표 단어, 주음, 버튼 이름은 이미지에 새기지 않는다. HTML 텍스트와 접근성 이름으로 유지한다. 시트 포커스와 기존 동작도 그대로 보존한다.

## 검토와 경계

`preview.html`의 세계 그림은 32px·64px, UI는 20px·40px이며 겹침 예시는 48px 칸이다. 비교용 바탕 면은 SVG에 들어 있지 않다. 문 두 파일은 동일한 문틀을 사용하고 중앙의 문짝만 달라진다. 유적의 연속 바닥과 통과 흔적은 검토 페이지의 별도 층으로 표현했다.

구조 검사는 다음 명령으로 실행한다.

```sh
python3 tools/validate_icons.py
```

XML·해시·심벌 일치·문틀 일치 검사는 자동화했다. 동일한 자산을 인라인으로 넣은 검토 페이지를 Chromium에서 렌더해 확인했다. 실제 GitHub Pages 외부 심벌 로딩과 iPhone 13 mini Safari 검수는 별도로 남긴다. [제작 기록](../docs/ICON-ASSETS-v0.1.md)을 함께 확인한다.

초기 아이콘 문서가 말하는 “게임 미적용”은 2026-09-10 제작 당시의 기록이다. 현재 초기 아이콘과 스토리 인물 아이콘은 런타임에 연결되어 있다. 단어·스테이지 데이터, 저장 키와 `legacy/`는 아이콘 때문에 변경하지 않았다.

외부 아이콘 세트, 아이콘 폰트, 폰트 파일, CDN 의존성을 추가하지 않았다. 현재 색상값은 이 제작본의 시작값이며 제품 전체의 최종 색 토큰을 확정한 것은 아니다.
